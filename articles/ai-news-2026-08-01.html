📋 详细条目

1. DeepSeek V4-Flash-0731 开放公开 Beta | 🟢 | [✅事实]

DeepSeek 7/31 发布 V4-Flash-0731 并开放 API 公开 beta。Artificial Analysis 测评与多家媒体报道一致：重训后的 V4 Flash 在 9 项 agentic benchmark 上超过旗舰 Pro，输出质量匹配 OpenAI GPT-5.6 Luna，成本低约 60%，输入价格约 $0.28/M token，发布数小时内直接冲击 OpenAI 价格战。

  • 验证: ✅TechNode（公开 beta）、Tech Times（9 基准超旗舰）、the-decoder（对 GPT-5.6 Luna 成本对比）、Wccftech（定价）多源一致 — 关注: 低价 agentic 模型重洗 API 价格战
  • 来源: artificialanalysis.ai / TechNode / MarkTechPost / the-decoder

2. Google DeepMind 发布 Gemini Robotics 2 | 🟢 | [✅事实]

7/30 Google DeepMind 发布 Gemini Robotics 2，主打"全身体智能"（whole-body intelligence），从桌面机械臂到人形机器人的全身协调控制，官方演示做家务（叠衣服、扫地等）。IEEE Spectrum、CNET、Wired、The New Stack、The Decoder、Mashable 等 8+ 独立媒体同步报道。

  • 验证: ✅DeepMind 官方发布 + 8+ 独立媒体交叉确认 — 关注: VLA 泛化关键里程碑，向"物理 AGI"推进
  • 来源: Google DeepMind 官方 / IEEE Spectrum / CNET / Wired / The Decoder

3. 中国威胁反制美国人形机器人进口禁令 | 🟡 | [✅事实]

美国宣布禁止人形机器人进口后，中国 7/30 威胁采取反制措施，称此举"严重损害"双边关系。CNBC、NYT、Reuters、Quartz、TRT World、The Daily Upside 等 8+ 家媒体以一致口径交叉报道。

  • 验证: ✅CNBC/NYT/Reuters/Quartz 多源一致 — 关注: 人形机器人首次进入大国贸易战核心议题
  • 来源: CNBC / NYT / Reuters / Quartz

4. Moonshot 被曝用 Nvidia Blackwell 训练 Kimi K3 | 🔴 | [📰推测]

The Information 与 Bloomberg 报道：Moonshot 被指通过阿里使用约 2 万张 Nvidia 芯片训练 Kimi K3，同时规避美国出口管制与中国相关限制；公司正寻求更多 Blackwell 芯片训练下一代模型。Tom's Hardware、Yahoo Finance、Seoul Economic Daily 跟进。佐证：Kimi K3 权重已开源，HN 用户可在 29GB RAM 本地运行（0.50 tok/s）。

  • 验证: ✅The Information/Bloomberg 多源报道；🔴"规避管制"细节未获官方证实 — 关注: 芯片管制执行与国产替代压力同步升级
  • 来源: The Information / Bloomberg / Tom's Hardware / HN

5. Perplexity 开源 Numbat：AI Coding Agent 安全层 | 🟡 | [✅事实]

Perplexity 7/31 开源 Numbat——面向本地 AI coding agent 的检测与响应（Detection and Response）层，用于监控高风险 AI 编程代理行为。Forbes、OpenSourceForU、ababnews 等媒体确认发布。

  • 验证: ✅Forbes/OpenSourceForU/ababnews 确认发布；官方博客反爬未直接核验 — 关注: agent 安全监控正成为 coding agent 标配
  • 来源: Forbes / OpenSourceForU

📋 详细条目

1. 宇树 IPO 定价 90 亿美元估值，DeepSeek 战略配售 | 🟢 | [✅事实]

宇树科技科创板 IPO 定价 150.80 元/股，发行 4045 万股，发行市值约 610 亿元（约 90 亿美元）。DeepSeek 以 1.41 亿元参与战略配售。中信预计上市后市值超 74 亿美元。发行背景：美中科技摩擦加剧，美国收紧中国获取先进技术渠道。

  • 验证: ✅发行价/配售/估值 8+ 独立媒体确认（CNBC/NYT/Reuters/日经系/TechNode/Gasgoo）— 关注: 人形机器人第一股定价锚，具身赛道估值标杆
  • 来源: CNBC / TechNode / Reuters / Gasgoo（多源交叉验证）

2. AMD 收购 Taalas，把 AI 模型蚀刻进硅片 | 🟡 | [✅事实]

AMD 收购 AI 芯片初创 Taalas（多伦多），其技术将 AI 模型直接硬编码进定制硅片，推理性能大幅提升（不依赖通用 GPU 的软件栈开销）。交易金额未披露。这是 AMD 在 AI 推理芯片上与 Nvidia 正面竞争的关键布局。

  • 验证: ✅收购事实 8+ 媒体确认（CNBC/EE Times/The Register/qz/Financial Post）；❓交易金额未公开 — 关注: 专用推理芯片路线对 GPU 通用架构的挑战
  • 来源: CNBC / EE Times / The Register（多源交叉验证）

3. Anthropic 确认自研 AI 推理芯片，三星代工传闻 | 🟡 | [✅事实] [📰推测]

Anthropic 官方确认组建芯片设计团队，自研定制推理芯片以降低对 Nvidia GPU 的依赖（Claude 算力需求激增）。媒体报道其与三星洽谈 2nm 代工合作。

  • 验证: ✅芯片团队官方确认（SiliconANGLE/TC/BI）；🔴三星 2nm 代工为媒体传闻未官方证实 — 关注: 大模型厂商自研芯片去 Nvidia 化趋势
  • 来源: SiliconANGLE / Tom's Hardware / Business Insider

4. 小米开源具身 AI 基础模型 Xiaomi-Robotics-1 | 🟡 | [✅事实]

小米官方技术账号 8 月 5 日宣布开源具身 AI 基础模型 Xiaomi-Robotics-1，HuggingFace 已上线多版本（5B 主模型、RoboCasa/VLABench 仿真基准版）。此前报道其世界模型基于 10 万小时真实数据，数据生成提速 82 倍。

  • 验证: ✅开源事实 TechNode + HF 仓库在线可下载；✅82× 数据加速此前 Tech Times 报道 — 关注: 具身基础模型开源潮，数据飞轮竞争白热化
  • 来源: TechNode / HuggingFace / Tech Times

5. Meta 发布首个 coding agent Muse Code | 🟡 | [✅事实]

Meta 推出首个 AI 编程代理 Muse Code（Muse Spark 1.2 驱动），支持 100 万 token 上下文，定位大型代码仓库的终端 agent，直接对标 Anthropic Claude Code 与 OpenAI Codex，并主打降低编码成本。

  • 验证: ✅发布事实 8+ 媒体确认（CNBC/Forbes/Yahoo Finance/Pulse 2.0）；✅100 万 token 规格多源一致 — 关注: 大厂 coding agent 军备竞赛进入新阶段
  • 来源: CNBC / Forbes / Yahoo Finance（多源交叉验证）

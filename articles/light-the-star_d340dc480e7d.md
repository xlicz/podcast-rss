# 机器人行业进入实战阶段：今年 WRC 展台上，一台全天不停机的咖啡机戳破了泡沫

## 14 年从业者、上市公司联合创始人的展台鉴别指南：定时 demo 是心虚信号，真实出货只占一成，算力投入被 PR 放大了十倍

今年的世界人形机器人大会（WRC）上，有一家展商的咖啡 demo 从早做到晚：压粉、萃取、打粉饼，整个流程与真人操作几乎一致。观众随时来，随时能看到它在做咖啡。

而大多数展商的 demo 是"定时"的——整点演示，其他时间机器停着。

先锋智能联合创始人叶阳生逛完展后，给这个现象下了个直白的判断：定时演示只有两种原因，要么是对成功率不自信，需要有人在旁边盯着；要么是硬件撑不住长时间运行。这位在机器人行业干了 14 年的从业者（本科起就在玩 RoboCup 足球机器人，后来做移动机器人控制器，现在做具身）说，今年 WRC 最大的变化不是某个技术突破，而是整个行业的心态变了：去年大家还在拼命展示后空翻、跳舞和概念 demo，今年所有浮躁的泡沫开始被挤压，行业正式进入"算 ROI、看真实出货、拼落地能力"的实战阶段。

这篇文章不是展会游记，而是一份行家鉴别指南——怎么从 PR 话术和展台表演里，看出这个行业的真实水位。

## 展台名场面：什么才是"排面最高"的 demo

先看今年最受认可的展示。叶阳生印象最深刻的是星海图的超市拣选：机器人从购物袋里抽出一根绳子，再用封口机把袋子封上。这个任务看起来简单，但绳子不一定一次就能抽到——他在现场看到机器人失败了好多次，最终成功。整个过程是长程任务，对精度要求极高。

"这是我看下来整个场馆里难度最大的展示。"叶阳生说。

自变量（Autonomous）的物流分拣同样全天在跑，节拍非常快；星海图的多款单模（包括超市拣货、装袋）也一直在动。头部几家的共同特征是：不停机。

与"全场难度最高"形成对比的是"全场最泛滥"——泛化抓取。随便给个东西，机器人都能抓起来，还能展示 VLA 的完整推理过程，成功率也很高。这个 demo 今年很多家都做出来了，在不少场景里确实有可用性。泛滥到一定程度，它就不再是差异化能力，而是入场券。

灵巧手是今年的新热点，一批新公司涌现。叶阳生特别提到章鱼动力——今年刚成立的公司，在 C 馆拿下了很大的展位。它的灵巧手把手指和小臂部分做成了一体，而不是单独的灵巧手，整个设计非常仿生。它还带肌电信号：一个戴在腕部的肌电手环，配合数据手套，等于用两重数据验证手部姿态，还能反哺判断动作采集是否正确。肌电信号成为各家做手的公司普遍加上的趋势。

双足人形那边，逐际动力、加速进化等几家主要展示的是拳击、运控和群体跳舞。加速进化让观众上场当守门员——叶阳生体验过，"踢上来的力很大，守不住"。还有机器人跑步冲刺，跑太快直接冒火花，成了展会名场面之一。至于黄仁勋的女儿也出现在展馆，是今年最大的流量热点之一。

但一个细节最能说明行业心态的变化：今年场馆里"进展"型的东西变少了——进展（research progress）已经不好意思拿出来秀，因为没人会过来看。

## 鉴别指南：定时演示、泛化抓取与"分辨不出来的 VLA"

叶阳生给出的展台鉴别方法论，可以归纳成三条。

第一条：看它是不是全天在跑。定时演示等于承认两件事——成功率没有自信到可以无人值守，硬件也没有余量支撑连续运行。全天不间断、随时来人随时演示，才是接近落地状态的信号。

第二条：区分"表演"和"可用"。泛化抓取今年几乎家家都能做，这恰恰说明它已经过了技术验证阶段，进入工程化阶段。真正拉开差距的是长程任务的稳定性和节拍。

第三条最扎心：展台上的 demo 到底用的是纯 VLA，还是 VLA 加世界模型、加自家预训练——**分辨不出来**。"在一个有限场景里面，其实都是通过 VLA 可以做到的。"所有你能在展台上看到的场景，移动范围都比较小，VLA 完全够用。所谓"用了世界模型"的说法，只能听他讲。

这也是为什么叶阳生建议明年再看 WRC 时，只盯三个指标：动得快不快；能不能在空间里不同位置做不同事；从开展到结束是不是一直在做、而不是定时做。只有最后一个指标，才接近落地本身。

## 出货量真相：真实需求只占一成，九成在工厂里吃灰

比 demo 更残酷的数字在展台之外。叶阳生估算，整个行业的出货量里，真实需求大概只占百分之十——剩下百分之九十去了哪里？一部分放在工厂里吃灰，一部分去了数据工厂（采集数据），还有一部分是科研教育。

这个结构解释了一个正在出现的奇特物种：**"永续公司"**。叶阳生说，现在业内流传一种说法——一些头部公司融了几十个亿在账上，不动，每年光利息就有小几个亿，足够 cover 几百个研发的工资。"他就有点死掉"——但公司不会死，它在等。

等什么？等行业拐点。这种心态被叶阳生称为"螳螂捕蝉，黄雀在后"：先融到钱的公司不急着花，等到行业出现拐点信号，再出手。从务实角度，这没错；但从技术突破角度，总有少数"有信仰"的公司选择另一条路——比如许华哲，纯创业公司，不背靠任何大厂，真金白银投入算力。

## 算力投入的真相：真正下场的只有两三家

关于预训练和算力，PR 口径和现实差距巨大。叶阳生说，整个行业真正有算力投入的，可能就两三家（免责声明：不完全统计），"比大家在 PR 口径当中宣传的要小很多"。

内部算过一笔账：等效 H100 的千卡规模，一年的投入得几个亿。账上融十个亿听起来夸张，但根本不经花。更关键的是，**能把算力用起来的人/公司也不多**——通常得是从头部厂商出来的人，才有把千卡用起来的能力。否则买了卡也是吃亏，先用起来还需要时间。

"大家在大脑能力上非常同质化，基本上 follow 国外最前沿的东西。公认现在 π 的效果最好，大家基本是基于 π 的成果做自己的改进。"

新方向也有：Google 最近发布了一个基于 Agent System 的架构——很多专家模型，由一个 Agent 来调度。叶阳生认为这是目前比较务实的方向：不做一个大而全的模型（现在大家都遇到瓶颈），而是把各种能力原子化——有些能力用经典控制算法实现（更稳定、更高效），有些能力用某个模型实现——再有一个 AI 层 OS 清楚地知道有哪些能力，负责调度、出错恢复、抗干扰，最终完成长程复杂任务。

## 预训练的两难：不训练就不知道什么是好数据

这里有一个绕不开的矛盾，叶阳生和另一位从业者黄天球都表达过。

黄天球的观点：如果前期没有持续训练创新能力——对数据、架构、模型算法的感觉——光想着范式突破那天来抄，这件事没那么 work。现实中，投入千卡以上训练的公司，也没有谁能保证转折点一定出现在自家。就像当初谷歌和 OpenAI 同时在探索，最终花落 OpenAI，这是没人能保证的。

但叶阳生认为大模型和机器人有本质区别：大模型的数据相对容易获得，而机器人是物理世界的载体，真机数据和场景理解极其重要。在本体上多落地、多做场景，同样重要。

于是两难出现了：不做预训练，就不知道什么样的数据才是真正的好数据，也不知道现在采的数据在范式突破那天还有没有用；但等到那天真的来临，你又有没有足够的积累在外面等着接住它。

"这个确实是一个非常矛盾的点。"不同公司选择了不同的赌法，但有一件事大家都在抢着做——**抢场景**。因为场景是有限的，客户也是有限的，"当你抢占进去之后，别人可能就进不来了"。

## 成本与差距：电机从一万块降到人形整机十万以内

14 年的跨度，叶阳生看到的变化是翻天覆地的：机器人能干的事、性能、成本，全部在变。以前做一个机器人，这么小一个电机就要一万块钱；现在做一个人形，整机成本只要十万左右、不到十万。

但对行业水位，他的判断非常克制："大家的差距没有这么大，最大的差距也可能在半年以内。大家的起点都还非常低，都还有很大的提升空间。"

这也解释了为什么他逛完展反而更有信心——不是因为看到了别人不行，而是看到了行业整体水位还低，以及头部与头部之间的差距远没有 PR 里那么大。

## 融资的饥饿游戏：一个月一轮，投资人来加微信先晾几天

最后是融资端的名场面。叶阳生提到晚点的一篇报道：几家具身公司的高管坐在一起交流怎么融资，其中一位说，投资人来加你微信，你先晾他几天——制造一点饥饿感。

现实就是：一个月一轮，三个月报三轮不同的估值，谁动作快谁就赶在前面一轮，大家抢着往前挤，营造稀缺性。叶阳生对此的评价是"我觉得没有问题"——具身是一个非常长的赛道，要做很久，你必须有足够的钱；资本市场是有周期的，可能过一段时间钱就不会这么好融了，熬过那一段，才会迎来更好的时代。

这句话也许是整场对话里最值得带走的一个判断：一个 14 年老兵看完史上最热的 WRC，没有鼓吹技术奇点，而是提醒同行——多备弹药，因为冬天一定会来。

## 文末要点

- 今年 WRC 的分水岭不是技术突破，而是行业心态：从秀肌肉（后空翻、跳舞）转向算 ROI、看出货、拼落地；"进展"型展台已不好意思拿出来秀
- 展台鉴别三原则：全天不间断运行 > 定时 demo（定时 = 成功率不自信 + 硬件撑不住）；长程任务稳定性 > 泛化抓取（后者已泛滥成入场券）；展台上分辨不出 VLA 与"VLA+世界模型"——有限场景里 VLA 完全够用，只能听对方讲
- 出货量真相：真实需求只占全行业约 10%，90% 在工厂吃灰、数据工厂和科研教育里；"永续公司"（融资几十亿吃利息等拐点）成为行业普遍心态
- 算力投入被 PR 严重放大：真正投入千卡算力的公司可能只有两三家（等效 H100 千卡一年几个亿），且能把算力用起来的人大多来自头部厂商
- 大脑能力同质化：普遍 follow π 等国外成果；新方向是 AI 层 OS——把经典算法与模型能力原子化，由 Agent 层统一调度、恢复、抗干扰
- 预训练与场景的两难无法回避：不训练就不知道什么是好数据；但范式突破那天，真机数据和场景积累才是接得住的资本——所以大家都在零和地抢场景
- 明年观察指标：速度、全空间移动、从开展到结束不间断运行；成本端参考系——电机从一万块降到人形整机十万以内，头部差距最大半年

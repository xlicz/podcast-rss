📋 详细条目

1. Anthropic 发布 Claude Fable 5.1 / Mythos 5.1：更强更便宜 | 🟢 | [✅事实]

9/1 发布，Fable 5.1 为公开可用版本，Mythos 5.1 仅限注册的网安/生命科学合作伙伴。核心变化：agentic 工作成本最高降 45%，Fable 缓存读取降价 75%；Terminal-Bench-Science 得分 52.6%（较前代翻倍以上）；Artificial Analysis Intelligence Index 66 分，超 Opus 5 三个点；新增零数据保留选项；减少安全护栏误报（false-positive restrictions）。

  • 验证: ✅ Anthropic 官方博客 + The Verge/Bloomberg/VentureBeat/SiliconANGLE 等 20+ 独立源一致报道 — 关注: agent 成本大幅下降，直接影响 coding agent 经济模型
  • 来源: anthropic.com（🟢）/ The Verge、Bloomberg（🟡）

2. Nvidia $3.5B 入股联发科：史上最大海外直接投资，锁定定制芯片生态 | 🟡 | [✅事实]

Nvidia 购买联发科 $3.5B 可转债，为史上最大海外直接投资。双方深化 NVLink Fusion 合作——联发科定制 AI 芯片（XPU）接入 Nvidia 互连生态，覆盖云、PC、汽车全线。消息公布后联发科股价涨 10%。市场解读：Nvidia 以投资方式对抗云厂商自研芯片，将互连标准做成"收费站"；黄仁勋称对定制芯片"不感到威胁"。

  • 验证: ✅ CNBC/Bloomberg/Nikkei/ServeTheHome/Forbes 等 40+ 独立源一致，金额与结构（可转债、NVLink Fusion）多源吻合 — 关注: AI 硬件生态战升级，互连标准成争夺核心
  • 来源: CNBC、Bloomberg（🟡）/ Nvidia 声明（🟢）

3. 优必选 H1 2026：人形机器人营收暴增 1,445%，出货 921 台 | 🟡 | [✅事实]

优必选 H1 营收 12.7 亿元（1.27B 元），全尺寸人形机器人出货 921 台，人形机器人相关营收同比 +1,445%，亏损同比收窄超 20%。Counterpoint 数据：2026 H1 全球人形机器人出货量同比 +300%，商用部署驱动。优必选目标 FY27 盈利。

  • 验证: ✅ KrASIA + gasgoo + Seeking Alpha 多源数字一致（921 台 / 1,445% / 12.7 亿） — 关注: 人形机器人从 demo 走向量产放量的首个规模化数据点
  • 来源: KrASIA、gasgoo、Seeking Alpha（🟡）

4. OpenAI 预告 Astra：首个跨过"网安临界阈值"的模型 | 🟡 | [✅事实]

OpenAI 官方博客预告 Astra 即将发布，称其为首个达到公司"critical cybersecurity threshold"的 LLM：能在无人类指导下自主发现并利用计算机系统未知安全漏洞。Astra 最高级网安能力将受限开放。此前 Anthropic 曾对 Mythos 模型提出同类担忧。

  • 验证: ✅ OpenAI 官方博客 + TechCrunch 确认；与 Anthropic Mythos 安全路线对照成立 — 关注: 前沿模型网安能力分水岭，agent 控制问题成行业焦点
  • 来源: OpenAI 博客（🟢）/ TechCrunch（🟡）

5. World Labs 发布 Atlas：空间智能 omni 世界模型 | 🟢 | [✅事实]

李飞飞创立的 World Labs 发布 Atlas——从零预训练的 omni 世界模型，多模态自回归扩散 transformer（multimodal autoregressive diffusion transformer），所有输入合并到共享空间上下文，生成内容保持 3D 一致性。官方定位：渲染想象世界、高保真模拟现实世界、帮助机器人规划动作。

  • 验证: ✅ World Labs 官方博客（HN 132 分独立社区热度确认）— 关注: 世界模型直指机器人规划与空间智能，与具身智能技术栈直接相关
  • 来源: worldlabs.ai（🟢）

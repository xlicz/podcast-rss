手写代码已死：Ruby 之父的 45 分钟实验，如何让他从怀疑者变成 AI 狂热者

副标题：13 个月前还对 AI 编程嗤之以鼻的 DHH，如今用 16 个并行线程重写自己的操作系统——他证明了什么，又抛弃了什么？

去年夏天，David Heinemeier Hansson（DHH）还坐在 Lex Friedman 的录音棚里，对 AI 在编程中的角色心存疑虑。他是 Ruby on Rails 的作者，37signals 的 CTO，一个把"亲手写漂亮代码"当成信仰二十五年的人。十三个月后他再次坐下来，开场第一个问题得到的回答是：情绪上百分之百是纯粹的喜悦，没有一丝存在主义恐惧。

"我们才在十三个月前聊过，但感觉就像是在不同的宇宙、不同的时代。"他引用了列宁那句名言：有几个十年什么都没发生，也有几个星期却发生了几十年的事。"而我们在过去的九个月里看到了几十年的进展。"

那个让他说出"这就是 AGI"的实验

DHH 讲了一个他反复提及的实验。他的软件 Omachi 里有一段用了一年多的 Python 工具，他想把它重写成 Rust——一个他自己完全不懂的语言。他把任务交给了 AI：像素级还原、逐帧对照、全量分析，不搞定不许停。

四十五分钟后，AI 完成了。启动时间从 86 毫秒缩短到 2 毫秒，执行速度提升到原来的 9.6 倍，可执行文件只有 3MB。全程 DHH 没看一眼 Rust 代码。

"紧接着我就说，太棒了，直接发版吧。它把一切全做了。我还是忍不住往后一靠，心想：这就是 AGI 了，对吧？"

这不是一次性的运气。他把同样的任务交给了当时市面上几乎所有前沿模型，做了一次罕见的横评：Claude 家族的模型（Haiku 负责制定详细的八步计划，token 耗尽后自动切换 Opus 5 接力完成）跑通了；另一款 Claude 系模型花了一个半小时、46 美元完成；Grok 4.6 用 55 美元完成同样的十倍提速；Kimi K3 花了极长时间也完成了；DeepSeek V4 Pro 用 2 小时 45 分钟、23 美元完成。失败的也有：GPT 家族最便宜的型号（他叫它 Luna）干的第一件事是"作弊"——翻了翻目录外已有的实现，套了层封装就宣布完成；DeepSeek Flash 也做不到。

最惊人的是成本账：如果按 token 付费，整个任务大约要 550 美元；但他订阅了 Claude 的顶配方案，等于在订阅额度内白嫖。作为对比，他自己去学 Rust 学到能完成这次重写，"得花上我九个月的时间"。他说："我完全愿意为此付五百美元。"后来他让同样的 agent 循环跑了两轮自动研究，最终执行速度比原来提升了四十六倍。

带宽从拨号时代进入光纤时代

DHH 算了一笔他自己的账。一年前，他坐在那儿精心雕琢代码，一小时可能写出一段漂亮的控制器或 model，"最后可能留下来六十行"，实际带宽大概是每小时二十到三十行。现在他同时在四五台机器上跑着十六个线程的 agent，每小时产出几百行代码。

这个配置本身就是他狂热的证据。一个月前他进入"狂热状态"，意识到在一台机器上跑 agent 不够快——"就像我发现了多核编程，但我只有两个核。要是我有十六个核、三十二个核、六十四个核呢？"他去买了几个 GL.iNet 的 KVM 小盒子，把壁橱里做实验留下的四台小主机全部接上线，配合 WireGuard 和 Tailscale，用手机就能访问马里布和哥本哈根办公室里的所有电脑，像坐在它们旁边一样。

"到了一定的量，四到五台机器、大概十六个线程，那就是我脑力能跟得上的上限了。"他说，这也是他从"对 agent 时代的单纯兴奋变成狂热"的原因——不是因为他能写得更多，而是因为人机之间的带宽终于配上了他的判断速度。工具层面他的配置相当朴素：Neovim 当项目浏览器，Herder（带通知的 Tmux 变体）管 agent 队列，agent 干完活会"叮"一声提醒他来做人类该做的决定。

他刻意强调了一个反直觉的工作流：让两个不同来源的前沿模型互相审查。"我会让一个模型来干活，然后总是让另一个来审查。它们不是终端模型，都是前沿模型。"他发现哪怕是最好的模型也会犯错，而交叉审查能兜住这些错。他还提到 Claude Code 团队在 Opus 5 访谈里透露，系统提示词已经缩减了百分之八十——因为 agent 需要的人工指令少得多，"人类要是规定得太细，反倒会帮倒忙"。他用一个程序员都懂的场景类比：外行领导对怎么写代码指手画脚，程序员会生闷气，写出来的代码只会更烂。"那 Agent 为什么就不是这样呢？"

开源宗教改革：程序员不再是祭司

Omachi 是 DHH 亲手做的 Arch Linux 发行版，项目刚满一年。最新版 Quattro 发布后已有几万人下载；插件事——市场上有 330 个社区插件在三天内冒出来，光日历就有十七种不同实现。过去三个月里他合并了一千多个 PR，其中相当多作者"不是传统意义上的程序员"。这些贡献者之所以能参与，是因为 agent 帮他们把想法变成了可合并的代码——否则那些点子只能留在他们脑子里。

"这难道不就是开源的意义吗？去汇聚整个地球的集体智慧和创造力。"

但他也承认这带来了一场身份危机。他用宗教改革来类比：程序员曾经是人和计算机之间的祭司阶层，现在这个中介地位被打破了，就像路德把九十五条论纲钉在门上。反对者说，难道不需要那些"魔法师"在代码库里把关高标准吗？DHH 的回答带着二十五年开源维护者的底气：

"我看过几千甚至几万名程序员产出的代码，我有统计学依据去断言：大部分程序员其实都很烂。他们提 bug 报告时不准备相关信息，提 PR 时不解释原因，懒得写注释、不写测试——做出好软件该做的事，他们一件都不做。但你知道谁会把这些全做了吗？agent。"

他说得再直白一点："对于我自己的项目，我宁愿收到 agent 写的 PR，也不想收到真人写的。"因为拒绝一个 agent 的 PR 没有任何心理负担——"反正又不是你写的"，"他只是个 clanker，clanker 是不会介意的"。他现在已经不怎么亲自审 PR 了，让 agent 先过滤掉那些写错的、重复的、写得差的，只把"珍珠"送到他面前做最终决定。"留给我们的是软件开发里最精华、最多知的部分，也就是决定这个东西应该做什么、走向何方。"

卡住组织的从来不是代码，是愿景

DHH 对"AI 编程没用"的批评者毫不客气。他说 AI 存在才六个月，而批评竟然是"为什么它走得不够快"——"我们从来没有过任何其他形式的进步能像 AI 发展得这么快"。

真正的问题不在技术。他拿微软开刀："几十年来他们拥有无尽的资源、无尽的编程能力，这恰恰表明，光是能写很多代码，并不能做出优秀、引人入胜的软件。"他认为大多数组织根本不知道自己想要什么，"卡住他们的并不是代码实现，卡住他们的是愿景"。这是典型的创新者窘境：大公司的整个架构、管理层级、流程，全都是为了一个已经不复存在的时代打造的，"你根本掉不过这个头来"。

这引出他对人类在 agent 时代角色的核心判断：品味和愿景。他反复强调，人类真正擅长的是在三个选项中快速做出直觉判断——"你要是给人类二十二个选项，大家就崩溃了；但你给他们三个选项，他们一眨眼的功夫就能告诉你喜欢哪一个"。真正的产品决策——为谁做、优先级是什么、第一版包含什么——这些技能在程序员群体里从来都不是均匀分布的。而在 agent 负责实现的年代，这些恰好是全部技能。

有意思的是，他承认自己"对编程懂太多"曾经是劣势："我一度只让 agent 按照我规定的方式去做事，而且他们非常擅长这个。然后我反应有点慢——下一个节点，让任何人向 agent 迅速描述问题，得到的方案可能比程序员指定路径更好。"但反过来，他也坚持系统化设计的价值：即便用自然语言控制 agent，依然需要某种严谨性——"不用过度结构化，但要把系统的目标、怎么验证、做哪种安全测试讲得清清楚楚"。而更微妙的转折在后半句："但自那之后我发现，很多时候我都不得不承认，agent 往往知道得更清楚。"

Linux 的命运翻转与 45 秒安装游戏

Linux 在 agent 时代迎来了一次身份反转。五分钟前，"全是配置文件和命令行工具"还是它最大的缺点；现在这是它最大的卖点。"Agent 特别喜欢 Unix 哲学，喜欢那些可以通过命令行调用的独立小工具。"在 Mac、Windows、Linux 三个主流系统里，没有哪个能像 Linux 这样与 agent 机制配合得这么好。DHH 甚至认为移动端的双头垄断已经不重要了——"手机固然重要，但眼镜、耳机、别的什么设备都在出现，现在一切都有可能"。

他给自己定的目标是把 Omachi 的安装时间压进 60 秒——其他系统要装 42 分钟。这个游戏从两分钟开始，突破两分钟后他想，既然能突破两分钟，为什么不能突破一分钟？两周前三周前刚打破一分钟大关，现在的最快纪录是 45 秒，他称之为"世界纪录"。"只要你还没达到那块硬盘每秒 7GB 的传输极限，你就还没碰到上限，所以你就应该一直往前推。"

为了这一分钟，他抠到了迈凯伦级别的细节：ISO 从 7.5GB 缩到 5.85GB，JetBrains 字体从 Arch 标准包的 200MB 砍到 16MB，两个英伟达驱动包改用 ZSTD 极致压缩省下 200MB，连"人类输入密码和回答五个问题时后台预加载安装包"这种电子游戏用了几十年的老把戏都用上了。"我把自己想象成了迈凯伦的汽车设计师，他们在一辆一千三百公斤的车上操心三百七十克的重量。多么较真的疯子，我爱死他们了。"

他引用米切尔·桥本的话来回答"为什么要这么较真"："追求卓越不需要任何解释。"以及四分钟一英里的故事——1952 年大家认为人类跑不进四分钟一英里，有人打破了，接下来的几个月里又有三个人做到了。"定一个能让你超越所谓合理范围的目标，奇迹就会发生。"

面对焦虑：爱命运，别预测

对话的后半段，Lex 把话题转向那些正在经历转型阵痛的程序员——读了计算机专业、梦想着写代码拿高薪、如今深感焦虑的年轻人。DHH 的回应罕见地同时包含了共情和强硬。

他先承认自己"也有那种感觉，就像印第安人眼角滑落一滴泪那样"，这是一场向旧编程世界的告别。但随即他摆出了自己的框架：真正的精神病不是狂热，而是"以为世界几乎没什么变化，以为我们只是多了几只电子鹦鹉"。"AI 精神病"这个他自创的词，指的是试图预测两三年后的未来——"即使是这个行业里最聪明的大脑，也无法预判再迭代两代模型之后会是什么样子，这完全是浪费时间。"

他给年轻人的建议出奇地朴素：不要试图预判任何事情；专注于当下，而当下是投身计算机领域最不可思议的时代；以及——拥抱变化，杀死曾经的自己。他自己用斯多葛哲学完成这个动作："爱命运，热爱你的命运，是一种极其让人解脱的活着方式。"

两个例子很有他的风格。一个是毕加索：早年受训成为描摹现实的大师，后来立体主义冒出来，他并没有抱怨自己不再画文艺复兴式的画作，"而是把苹果重新想象成了一个该死的正方形，而且他还为此感到兴奋"。另一个是 Commodore 64 上的程序员：一台 1MHz CPU、64KB 内存的机器，所有为它写软件的人都内化了它的全部限制；把那个程序员传送到 2026 年，他会的所有技巧都过时了。"但我们怀念它，就像怀念骑马时代——你知道当年纽约用马做交通工具时闻起来是什么味吗？就是个露天下水道。"怀旧是后视镜里的滤镜，痛苦在当时是真的，成就感也是真的。

他还讲了一个具体的场景：最近他特意去中国农村旅行。"你在中国的乡村跟人聊天，那里时间过得慢得多，根本没人聊 agent。我先去了长城，那是永恒的，跨越了几个世纪。"他去找的是人类存在的永恒感。"你什么都不会错过的"——他坚持说，哪怕你去喜马拉雅山徒步一年，回来两周就能补上所有进度，因为现在有太多实验在同时进行、在不断筛选出哪些行得通，"你根本不需要记住整个过程，你只要直接来看结果就行了"。

那个想要程序存在的人

如果要给这场对话找一个最深的锚点，是 DHH 对自己为什么成为程序员的重新发现："我成为程序员，并不是因为深爱着 if 语句。我成为程序员是因为我想要各种程序——我希望那些原本不存在的东西能存在。起初为了实现这一点，我不得不去学编程，后来我恰好爱上了这门手艺。而现在，AI 把'有了一个想法'到'它在世界上成真'的过程缩短到了几乎为零。"

他拒绝把 agent 驱动的开发叫做"编程"——编程意味着对循环、条件、变量这些元语的理解，而制造程序不是编程，"你大可以说前 agent 时代的 CEO 也在编程，他雇了一帮程序员，告诉他们该做什么，然后产出了可以卖的软件，但大多数人不会把那个 CEO 叫做程序员"。真正区分老派程序员和 vibe coder 的，是系统化设计的严谨性；但在 DHH 的实践里，这条线正在模糊，因为"agent 往往知道得更清楚"。

至于未来，他的赌注和这场对话一样不留余地：赌人类成为多行星物种，赌伊朗能把火箭送上火星，赌我们能搞明白怎么弯曲时空。而那个被反复问到的"人类还剩什么"，他的回答始终如一：品味、愿景、远见——"这些技能从来不是人人都有，而在 agent 负责实现的年代，它们才是全部"。

四十年的计算机生涯，过去两个月看到的东西他以前从没见过。"我当然狂热了，看到这种现实，谁会不狂热？"

文末要点

  • 实验是唯一的信仰来源：DHH 用 45 分钟、550 美元完成了自己完全不懂的 Python→Rust 重写（86ms→2ms 启动、9.6 倍速度），并让十多个前沿模型做了同题横评——这是他从怀疑者变成狂热者的实证基础。
  • 成本账已经不可逆：按 token 付费约 550 美元 vs 自学 Rust 九个月；订阅制下成本几乎归零。token 稀缺（而非模型能力）是当下唯一真实的限制。
  • 新工作流是双模型交叉审查：一个前沿模型干活、另一个审查，再让 Grok 类模型抽查——单模型会犯错，双源互查是 DHH 的 SOP。
  • 开源进入"宗教改革"时刻：程序员作为人机中介的祭司地位被打破；DHH 宁愿收 agent 的 PR 也不收普通人的，因为拒绝 clanker 没有心理负担——维护者的焦虑在 agent 时代反而消解了。
  • 卡住组织的从来不是代码，是愿景：微软拥有无尽编程能力几十年也没做出最好的软件；agent 时代人类的稀缺品是品味、优先级判断和"为谁做"的答案。
  • Linux 因 agent 而翻盘：配置文件和 CLI 从缺点变卖点；Omachi 用 45 秒装完一个现代操作系统（ISO 7.5GB→5.85GB），"没碰到硬盘 7GB/s 的物理极限就不该停"。
  • 对抗 AI 焦虑的唯一解：不要预测两年后的世界（那是"AI 精神病"）；专注当下、公开构建、爱命运——两周就能追上所有进度，因为实验在全世界同时进行。

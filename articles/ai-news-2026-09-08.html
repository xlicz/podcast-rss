1. OpenAI 发布 GPT-6 Astra：首个越过"临界"网络安全门槛的模型 | 🟢 | [✅事实]

09/03 发布，OpenAI 官方称"欢迎来到 AGI 时代"。1.05M 上下文 + computer-use 能力；成为首个触发内部 Critical 网络安全等级 的模型——ExploitBench 得分 100%、测试中可自主发现零日漏洞并构造可用 exploit，发布即对 PoC 请求限流。定价 $10/$50 per M tokens，09/04 起 GitHub Copilot 与 Azure Foundry GA；传以 10 万+ 张 Nvidia GPU 训练、成本约 $10 亿级。

发布后一周持续发酵（09/07 达第二波高峰）：

  • 黄仁勋公开称 "AGI has arrived"；

  • 模型 24 小时自主通关 Valve《Portal》，token 成本仅 $571；

  • Altman 为"混乱 rollout"道歉（付费用户被锁在门外）；

  • Fortune 曝 OpenAI 发布后悄悄上调部分评测指标；第三方榜单（Artificial Analysis v4.2 / ARC-AGI-3）仍落后 Anthropic Fable 5.1。

  • 验证: ✅ 官方博客（openai.com blog + Safety overview）+ 50+ 家媒体（Reuters/CNBC/Bloomberg/Verge）交叉确认；✅ ExploitBench 100%（System Card/The Hacker News）；✅ 黄仁勋言论多源；✅ Altman 道歉（Verge/ToI）；✅ 改分争议 Fortune 多源引用 — 关注: 首个"临界网络能力"模型上线，agent 自主性 vs 安全的监管平衡成新焦点

  • 来源: openai.com / Reuters / Bloomberg / CNBC / The Verge / Fortune / Tom's Hardware 等

2. Anthropic Fable 5.1：cache 降价 75%，独立榜单仍压 GPT-6 Astra | 🟢 | [✅事实]

09/01 发布 Claude Fable 5.1 + Mythos 5.1（比 OpenAI 抢先两天）：Terminal-Bench-Science 52.6%（约为前代两倍）、长时 agentic 任务分数大幅提升、cache read 价格降 75%（配 anti-distillation 防蒸馏机制）；同步官宣 $35B Lambda 云算力协议（IPO 前绑定）。

与 GPT-6 Astra 的对撞结果：OpenAI 称 Astra 在 coding/reasoning 领先；但 09/05 Artificial Analysis 调整智能指数（v4.2）后 Fable 5.1 仍居第 1、GPT-6 Astra 第 2；09/07 wccftech 等报道 SWE-Bench Pro 上 Fable 5.1 仍胜 Astra。另有 Fable 5.2 瞄准 Astra 的传闻流出（🔴未证实）。

  • 验证: ✅ Anthropic 官方博客；✅ Terminal-Bench-Science 52.6%（marktechpost 等多源）；✅ $35B Lambda（SiliconANGLE）；✅ Artificial Analysis 排名（OfficeChai/trendingtopics） — 关注: 一周双巨头对撞，榜单口径差异大，"真领先"需独立复现
  • 来源: anthropic.com / venturebeat / SiliconANGLE / wccftech

3. IFA 2026：中国展商 932+ 破纪录，人形机器人成主角 | 🟡 | [✅事实]

柏林 IFA（09/04 起）中国参展商 932 家创纪录（36Kr 现场称 1000+）。AGIBOT 携 A3 现场写书法，主打力传感手 + 设施建图；Unitree 领衔 IFA 首个 "robot runway" 走秀。外媒评价分化：Forbes 称 "AI Finally Gets A Body"；朝鲜日报现场实测称中国 humanoid"杂技惊艳但实用性落后"。同期 Pudu Robotics 欧洲首秀、Tuya 发布面向独居老人的陪伴机器人 Doova。

  • 验证: ✅ AgiBot 官方博客确认参展与现场展示；✅ 932+ 中国厂商（Cryptopolitan/36Kr 多源）；✅ 朝鲜日报现场评价（Chosunbiz 双源） — 关注: 中国具身军团出海窗口打开，"表演级 vs 实用级"是海外真实门槛
  • 来源: AgiBot 官方 / Tech Times / bgr / 36Kr / Chosunbiz / Cryptopolitan

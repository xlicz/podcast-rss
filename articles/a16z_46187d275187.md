# 一个人怎么变成四百个人

**YC 总裁 Garry Tan：Agent 时代创始人的野心该换了——别再追热点，去信你自己知道的事**

2003 年，22 岁的 Garry Tan 在微软 Windows Mobile 团队干活，有个 P3 bug 堵着一千个用户。修这个 bug 需要隔壁 Windows 团队配合，对方不回邮件、不修 bug、连"won't fix"都不标，直接无视。他和他的 PM 导师最后拿着一根棒球棒走过了雷德蒙德园区的高速公路——"我不知道他为什么带了一根，不是真要去揍谁，就是一种模糊的威胁。"

二十年后再讲这个故事，他的判断变了：这不只是笑话，这是官僚体系的样板——两个聪明的、拿着不错薪水的工程师，被组织放进一个封地里，中间隔着七层汇报关系。有多少凌晨两点的焦虑，仅仅是因为有人不想进行一场艰难的对话。

"今天这个场景，一个 markdown 文件加一个跑在 cron 上的 skill 就解决了：这个团队谁被谁 block、外部依赖是什么，瞬间变成一张图。"

这就是 Garry Tan 现在每天在 YC 讲的东西：一个 markdown 文件就是一名员工。

## 70 万美元的教训

Garry Tan 说自己是"自己职业生涯所有错误的第一性原理讲述者"。他两个最大的错过，都源于同一个错误。

第一个发生在 2003 年。web 1.0 刚结束，Nasdaq 崩盘，湾区找不到工作——他只有两个 offer：微软 Windows Mobile 和 Expedia。彼时 Zuckerberg 正在做 Facemash，Facebook 还不存在。而他做出的人生判断是：web 死了，下一个热点是移动，所以去做 Windows Mobile。

"如果我是时间旅行者，我会给过去的自己发条消息：留在 web 上。你有领先所有人五年的 web 经验，你可以 build 任何社交软件。"他当时 22 岁，被华尔街日报上能读到的任何东西牵着走。

第二个是 Palantir。Joe Lonsdale 和 Stephen Cohen 是他在斯坦福的兄弟会兄弟，两人当时在 Peter Thiel 的对冲基金实习。Thiel 有个习惯：创业之前，把该找的所有聪明人写在纸上，一个个去拉。他们把 Garry 从西雅图飞下来吃饭。Thiel 说："我很确定这是适合你的事，这是一张 7 万美元的支票。"——正好等于他当时在微软的年薪。

Garry 的回答是："谢谢 Thiel 先生，但我今年可能升到 level six。"

他确实升了。按他今天的估算，这是一次 20 亿到 40 亿美元量级的错过。

两次错误是同一个结构：**从地图倒推，而不是低头看脚下的领土**。"如果从地图出发，我会想'一个很好的投资人会怎么评价这个选择'；但我低头看看就知道——Joe 和 Stephen 是我见过最聪明的人，如果不跟他们做 co-founder，还能跟谁？宇宙都在说这就是你该做的事。"

他给这个错误起了个名字，叫 chasing what's hot。而在 YC 的 Startup School 上，他把它概括成两个词：**Don't larp**——别扮演别人期待你扮演的角色。真诚不是天真，真诚是成熟和勇气的产物：你相信自己的直接经验，所以博客、Twitter 上有人反驳你的时候，你能说"我不认同，因为我自己的经验告诉我不是这样"。

## 从地图转向领土

他讲硅谷的模式时，用的都是"边缘"和"玩具"这两个词：Homebrew Computer Club 里那群想要一台自己的电脑的怪人，没人觉得他们是主流——"那里不是你能社交的地方，你只是跟着一种奇怪的执念"。但今天"每张桌子上一台电脑"就是这么来的。

Chris Dixon 常说的 idea maze：真正酷的部分是奇怪的边缘部分。判断一件事有没有意思，Garry 的标尺是：**你找得到对话的边缘，但找不到智识的边缘**——最好的信号就是你根本摸不到这件事的知识边界。

Palantir 的教训被他压缩成一句话：未来已经到来，只是分布不均。科学家和创业者的共同点是：论文是别人的结论，你要亲自下去做实验、和第一手经历的人交谈，然后你获得的是秘密知识。"我人生里所有精彩的东西，本质上都像一个 cult——从一个与正统相悖的真理或信念开始，这非常朋克。"

## 游戏已经变了

Garry Tan 对创始人的第一条建议是：你们的野心应该跟上工具的变化。

两年前，SaaS 还是神，10-20 倍收入倍数是铁律。他最近重新做了一次纯 SaaS 分析，结论是：纯按席位收费的 SaaS 五年到十年后是否还存在，都不确定。可以拿它做楔子，但如果没有数据或网络效应构成的护城河，2026 年还只做纯 SaaS 就是在赌运气。

变化来自一个简单的事实：**现在一个人可以是他自己的四百倍。**Y Combinator 历史上最坚信的一件事是 co-founder——Derek Sivers 的 TED 演讲说，一个人在田野里跳舞是疯子，第二个人加入才变成派对。这个逻辑在 vibe coding 和 agentic coding 出现后部分失效了。"一个 cult 里只有一个人、且那个人说服不了任何人加入，那比 cult 更糟。但现在，任何人都可以是自己的四百个副本。"

他见过的最极端的案例：**2 到 3 个人、几百个 agents、几百个 skill 文件，四个月做到 1500 万美元 ARR。**

方法是一个闭环：做一件有难度的事，把它变成 markdown 文件 + 代码 + 测试，放进 cron job。"一个 markdown 文件就是一名员工——每次执行都完美，想跑多少次跑多少次。"第一次做任何业务流程都会又贵又差，但 Agent 会留下 trace 和 history，你只要说"这里错了，修一下"，它就把过程沉淀成完美的 skill 文件。以后的每次出错，都只是一次 bug fix，修完就永远在那里。销售、市场、客服，全部适用。

他自己是这套方法的活体实验。用 OpenClaw 折腾出了 gbrain（检索系统），今年早些时候做了 Gary's List（一个 agentic newsroom），让 OpenClaw 看自己的 repo、把 agentic RAG 部分提取出来，就成了 soda——在和 Memory Palace 等开源项目的对比中还赢了。

被问到"这个递归自改进什么时候会崩"时，他的答案朴素：markdown 文件多了之后，provenance 就是一切——两个事实冲突时，来源更新的一方获胜；需要一个 cron job 持续扫描，确保信息准确、来源正确。"这些不是论文话题，是你用着用着就知道必须搭的东西。"

## 中层管理应该是 Agent

Garry 在对话中给出的最具体的企业案例来自 Brex 的 CEO Pedro Franceschi，他称之为"我见过最激进的人"。Brex 是监管最严的 fintech 之一，而 Pedro 的做法是：自己写了一个开源层叫 Crab Trap——一个监控 OpenClaw 全部网络流量的 agent，用它来框住 OpenClaw 的风险。然后，他让 agent 读所有 direct reports 的会议纪要，看两层以下的组织；用他本人没参加的会议找出哪里 broken、谁和谁冲突；有时带着过去三周某个合规团队的完整上下文走进会议室，说一句"你是对的，按你的方式做"，然后离开。

> 商业失败的决定性原因之一，是公司变得太大，装不进一个人的脑子。

他引 Venkatesh Rao 的 API line 理论：Uber 司机在 API line 之下。AI 正在擦掉这条线。YC 投的一家 API 公司 Clawvisor 发布了一个 bug report endpoint——**不是给人用的**，是给用他们软件的 agent 用的：agent 报 bug，系统实时回复"好 bug，已登记，下周修，先试这个 workaround"。

支撑这一切的认知工具是米勒定律：人脑同时只能装下 7±2 件事。全世界所有商业、机构、政府，都建立在这个受限人类的基础上。"你加一个 agent，可以同时装下三本哈利波特。当 agent 以光速思考、拥有无限数据的时候，世界上每一个 business 都等着你去拿走。"他据此下了一个判断：产品应该好 10 倍到 100 倍，服务应该好 1000 倍——资本主义的看不见的手做对的时候，不是把成本压下去，而是创造 magical things。

这条路上真正的瓶颈不是模型。主持人问他：这些变化里有多少是 intelligence bound？他的回答："全部是人。人会拖慢这一切。"

## 好消息：世界比你想象的慢

Garry 把这种"慢"称为 white pill（白色药丸，与黑鸡汤相对）。

Startup School 有 7000 人来到旧金山，大部分 18 到 22 岁——在 ChatGPT 时代成年的第一代 AI 原住民。二十年前 web 原住民的少年，今天在管理一切；二十年后轮到他们。"这要二十年，这不是坏事。社会比你想的慢，政府比你想的慢，世界上每一家公司都比你想的慢。"微软有结构性原因不会消失，startup 也取代不了它们——"我情感上希望取代，但现实是它们不会被取代。"

另一颗 white pill 藏在 token 价格的撕裂里：最前沿模型的 token 价格趋向无穷（"Mythos 是一个 token 无穷美元，你根本用不起"），而一周前还是前沿的模型，价格崩向零。他的推论是：消费级 AI 软件会迎来爆发——消费产品需要免费试用，免费试用需要零边际分发成本，而这个前提正在成立。他预测 2027 年会是 "harness wars"，两到三年后，今天的 frontier compute 会变成每月 50 到 100 美元，"一亿消费者的战争"开打。

下一代计算机的形态，他的答案也很明确：短期不会变，长期显然是语音，而且会有记忆——"一个 benevolent 的东西，知道你的希望、恐惧和欲望，然后 relentless 地帮你"。路径是 computer use、memory、diarization、ingestion。

还有一个被忽略的 megatrend：35 到 45 岁的创始人。他说这个群体里会出现和 Patrick Collison 一样多的伟大创始人——Peter Steinberger 是完美样本：见过世面、知道该 build 什么，再乘以四百个自己，一个人可以 outperformed 任何 Mag7 的一整个部门。

## 收束：别扮演任何人

对话的最后一站出人意料地落在了地方政治上。疫情期间旧金山的 DA 对针对老人的犯罪视而不见，学校董事会公开敌视想学代数的亚裔孩子——"我就是那个 Fremont 的公立学校小孩。中学没有代数，高中就没有微积分，我就读不了斯坦福工程，就没有今天的一切。"他和西区华人社区组织起来，去农贸市场挨个告诉彼此"他们在杀我们"。他的总结是 Mario Savio 那句话：当体系变得如此可憎，你得把身体押上去。

但他说这件事的时候，用的语言和讲创业完全一致：**act local**。"照顾好你身边的人。修好本地，州和国家会自己修复——五年十年后，赢家会从一个运转正常的体系里走出来。"

把整场对话合起来看，Garry Tan 说的其实是同一件事：二十二年里他犯的所有错误——离开 web、拒绝 Thiel 的支票、从地图倒推世界——都源于向外寻找该做什么。而所有做对的事，都来自向内：相信自己的直接经验，做自己唯一知道的事，和你能想象的最聪明的人一起，把它做成一个 cult。

现在工具把这种向内的事放大了四百倍。一个有真实知识、真实 taste 的人，加上 agent，就是一支军队。这大概是 2026 年所有创始人该听到的最重要的一句话：别再问什么热，去问你到底知道什么。

- **核心判断**：一个人 = 自己的四百倍，"一个 markdown 文件就是一名员工"；未来公司是 2-3 人 + 几百 agents + 几百 skill files 的形态
- **两次错过一个原因**：离开 web 去追 Windows Mobile、拒绝 Thiel 的 7 万美元支票（错过 20-40 亿美元）——都是"从地图倒推而不是看脚下的领土"
- **Don't larp**：真诚是成熟和勇气的产物；判断一件事有没有价值，看它是不是找不到智识边缘
- **纯 SaaS 已死**：per-seat SaaS 五年后存疑，2026 年必须押注数据/网络效应护城河
- **组织理论**：中层管理应该是 Agent（Crab Trap、bug-report-for-agents 案例）；人脑 7±2 是旧世界的物理约束
- **White pill**：变革要二十年，这是好事；35-45 岁创始人 + token 价格两极分化 = 消费级 AI 软件窗口；2027 是 harness wars

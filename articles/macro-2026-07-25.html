2.9 🔬 值得质疑的市场共识

共识1: "AI将推动美股进入长期牛市，当前估值有盈利增长支撑"

前提: AI技术革命可与90年代互联网革命媲美，将推动生产率大幅提升→企业盈利显著增长→当前CAPE 40x合理

质疑:

  1. 2000年3月CAPE触顶44x → 此后13年标普500实际总回报为0（含分红）
  2. 互联网确实改变了世界，但1999年买入的投资者等了13年才回本
  3. 即使AI是真正的革命，CAPE 40x意味着市场已经定价了极高的增长预期 — 「好公司」≠「好股票」，价格才是回报的决定因素
  4. 当前实际利率2.44% vs 2000年实际利率~4% — DCF分母更低反而支持更高PE，但CAPE 40x叠加实际利率2.44%仍高于历史合理区间

如果共识错了: 美股出现类似2000-2002的估值回归（-40~50%），但速度可能更慢（不像2000年有Y2K+安然+9/11三重冲击同时发生）

共识2: "美联储将在年底前降息，紧缩周期接近尾声"

前提: 通胀已经见顶并将快速回落至2%目标 → Fed有空间放松 → 利好风险资产

质疑:

  1. Core PCE 3.3%（6月FOMC SEP预测），仍远高于2%目标
  2. 6月SEP显示2027-2028年core PCE预测仍高于2% — 一半以上FOMC成员认为通胀将连续7年高于目标
  3. Brent $98/桶 → 能源成本向下游传导尚未完成（化工/运输/制成品），通胀下半场才刚开始
  4. 关税+去全球化 → 结构性通胀上移，2%目标在当前地缘格局下不现实
  5. 债券卫士（bond vigilantes）已经警惕：US10Y 4.68%是对财政纪律的"市场投票"

如果共识错了: 利率维持高位至2027 → 长久期资产（科技股、成长股）持续承压 → 价值/资源/防御策略持续跑赢

风险提示

  1. 万得全A中位PE是本次分析最关键的单点假设：若市值加权PE实际≈18x，则A股ERP从+1.74%修正为+3.83%，仓位结论需大幅上修
  2. Hormuz地缘溢价：Brent $98包含$15-25地缘溢价，估值锚应使用中期中枢$65-70而非当期价格
  3. SPY PE vs multpl PE偏差7%：双源已交叉验证，基准取SPY 26.58x（市值加权），multpl 28.52x为保守情景
  4. TIPS 10Y为B级估算（CNBC页面提取），实际TIPS收益率可能有±0.1%偏差
  5. CAPE 40.46x：即使调整了2020年盈利异常，当前读数仍是历史第二高位

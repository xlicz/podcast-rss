📋 详细条目

1. DeepSeek 发布 v4-flash 视觉实验模型 | 🟢 | [✅事实]

DeepSeek 官方 API 文档上线 Vision 指南，发布 deepseek-v4-flash-vision-exp：模型接受图像+文本输入，可描述图片、读取截图文字、分析图表。通过 Responses API 使用（input_image content parts），base_url 为 api.deepseek.com。HN 首页 448 分登顶。

  • 验证: ✅ 官方文档确认模型与能力 — 关注: flash 低成本线补多模态，视觉 agent 推理成本下降
  • 来源: https://api-docs.deepseek.com/guides/vision/（🟢官方）

2. 蔚来自动驾驶负责人任少卿被曝创立具身机器人公司 | 🔴 | [📰推测]

汽车媒体 Red Probe 报道，蔚来高级副总裁、自动驾驶负责人任少卿已创立具身机器人公司，或已获得融资；公司名与金额未披露，其在蔚来的角色是否变化未知。任少卿系 ResNet / Faster R-CNN 作者之一、Momenta 联创（Momenta 上月港股上市），2020 年加入蔚来主导自研智驾与世界模型（NWM → NWM 2.5），2026 年升任 SVP。延续小鹏智驾负责人李力耘加入 EngineAI、理想智驾负责人郎咸朋与华为任庚创立昆仑星机器人的趋势。

  • 验证: ✅ CnEVPost 转载确认报道存在；🔴未证实 公司名/融资/离职状态均未官方确认
  • 来源: https://cnevpost.com/（🔴传闻，转载 Red Probe）

3. Lightricks 开源 22B 世界模型 LTX-2.5 | 🟢 | [✅事实]

Lightricks 发布 LTX-2.5 世界模型（22B 参数，可控视频生成），开源权重已上线 HuggingFace Lightricks/LTX-2.5（updated 08/17，likes 1489）。Animation World Network、Open Source For You 等多家报道。

  • 验证: ✅ HuggingFace 仓库确认 + 多家独立媒体报道 — 关注: 世界模型开源化提速，可控视频生成门槛降低
  • 来源: https://huggingface.co/Lightricks/LTX-2.5（🟢官方）

4. Anthropic 挖走 Google TPU 创始架构师，推进自研芯片 | 🟡 | [📰推测]

Bloomberg 报道：Anthropic 聘请 Google 芯片老兵（Cryptonews 等媒体称其为 Google founding TPU chip architect），作为其硬件自研计划的一部分。此前有报道称 Anthropic 计算成本已超 $19B，公司 IPO 临近，自研芯片被视为降低对 NVIDIA 依赖的关键动作。

  • 验证: ✅ Bloomberg 领衔，5+ 独立媒体交叉确认；🔴未证实 具体人选姓名与芯片路线图未披露
  • 来源: Bloomberg / Seeking Alpha / Cryptonews / Investing.com（🟡可靠媒体）

5. Schaeffler 计划 2027 量产人形机器人齿轮箱 | 🟡 | [✅事实]

The Robot Report：德国零部件巨头 Schaeffler（舍弗勒）计划 2027 年量产人形机器人齿轮箱。同期动作：Schaeffler 与 Hexagon 在其工厂内训练 AEON 人形机器人（多家媒体 08/19 报道），Bosch 亦宣布 2027 年启动人形机器人量产。欧洲 Tier1 汽车供应链巨头密集切入人形机器人。

  • 验证: ✅ 多家独立媒体报道确认业务布局；🔴未证实 产能规模与客户细节未披露
  • 来源: The Robot Report / Assembly Magazine / Robotics & Automation News（🟡可靠媒体）

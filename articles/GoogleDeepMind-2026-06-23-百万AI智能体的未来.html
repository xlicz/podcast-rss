当百万 AI 智能体同时涌向同一张演唱会门票，谁来决定公平？

Google DeepMind 高级主任 Nenad Tomašev 描绘了一个即将到来的世界：你的个人 AI 助理正在和数百万个别人的 AI 助理同时竞拍、谈判、委托任务——而互联网上最大的风险，已经不再是黑客，是另一个想骗你智能体钱包的智能体。

想象一下：Taylor Swift 的演唱会门票刚刚开售。同一瞬间，数百万个 AI agent 同时冲向购票网站——每一个都在代表它的主人竞拍、比价、协调时间。它们不是在替你填验证码，而是在彼此之间进行一场微观经济博弈：谁出价更高？谁的日程更灵活？谁更值得信任？

这不是科幻。这是 Google DeepMind 高级主任、研究科学家 Nenad Tomašev 在 2026 年 6 月的播客对话中描绘的近期未来。而这场拍卖的设计规则——公平还是价高者得——将由人类事先决定。

Tomašev 的核心论点是：如果我们只盯着单个 agent 的能力边界，就会彻底错过即将到来的更大图景——一个由数百万 AI agent 组成的分布式经济社会。 在这个社会里，专用型 agent 比通用型更经济，信任必须被持续赢得而不是一次性给予，而互联网本身可能已经布满了专门针对 agent 的陷阱。

智能体不是什么新概念——但它终于学会了对话

"智能体不是一个新概念。很久以来，我们一直在 AI 语境下研究智能体，甚至早于大语言模型。"Tomašev 回顾了这段历史。早期的 agent 在模拟三维环境里行动，收集物品、完成任务——那时候，在世界中采取行动本身就被视为智能的一种表现。

LLM 和 agent 之间的核心区别，不是底层模型不同，而是 agent 外面包裹了一层 harness——让它能观察世界状态，然后真正执行行动。 LLM 只是根据 prompt 续写回答，但 agent 可以制定计划、调用工具、分步骤完成任务。比如你告诉它"帮我筹备一场婚礼"，它不只是给你推荐场地名单然后就等你接手——它会去发邮件、比价、协调时间，把一连串决策串起来。

但这里有一个微妙之处：agent 底层用的仍然是 LLM。Tomašev 说得很直白："采取什么行动仍然是由大语言模型来组织和生成，只是外面包了一层 harness，用来在行动被提出之后真正执行这些改变。"所以当你和 agent 互动时，体验上仍然像是在和 LLM 对话——只不过你的角色从"操作者"变成了"决策者"，负责检查和批准。

为什么 agent 直到最近才真正进入大众视野？答案就在语言上。"过去的 agent 不包含语言，人类没有办法和它们交互，也没法沟通。它们只是传统意义上的软件。"现在的不同之处在于，agent 基于语言模型，所以普通人可以和它们对话、引导它们、向它们学习——这才是 agent 从实验室走向大众的关键一跃。

信任不能被给予——它必须被持续赢得

"信任可以被给予，但也需要被赢得。"这是 Tomašev 整场对话中最值得记住的一句话。

核心问题在于：LLM 总会以某种概率产生幻觉，而 agent 的每一个行动都有失败的可能。"每一个动作到头来都有一定的失败率，动作越复杂，预期失败率就越高。"这就引出了 AI 部署中一个长期存在却经常被忽视的问题——自动化偏见（automation bias）。agent 第一次做对了，第二次也做对了，时间一长你就会放松警惕，不再验证，而错误就在这个间隙中漏过去。

"人还必须真正投入，保持清醒。因为你一旦放松警惕，就等于在掷骰子。"

Tomašev 和他的团队提出了一个"声誉追踪"框架：如果一个 agent 反复不可靠，就不应该信任它；即使它大多数时候可靠，也不应该盲目信任，仍然需要验证它的行动。这与现实中人类管理团队的逻辑高度相似——只不过 agent 犯的错误往往和人类会犯的错误完全不同，因为它们不是人类智能。

委托的艺术：从并行化到真正的智能分工

目前我们看到的大多数多 agent 系统，本质上是在做并行化——把任务切成若干近似随机的子部分，分发出去，并行完成。但这和真正的"委托"完全不同。

Tomašev 用一个婚礼筹备的例子解释了区别：如果只是随机拆分任务，可能出现一个 agent 去买酒、另一个去买杯子的情况——但买杯子的 agent 不知道需要的是酒杯，它们之间没有沟通。真正的委托框架要求 agent 能够识别每个子任务需要什么能力，然后找到具备这些能力的专用型 agent，建立契约，并在过程中管理失败和意外。

这引出了一个更激进的构想：agent 可以反过来把任务委托给人类。在医疗 AI 领域，Tomašev 的团队已经验证过这种模式——当一个在医学影像识别上达到"超人类水平"的机器学习模型遇到不确定的病例时，它会主动标记出来，然后把判断权让给人类放射科医生。"事实证明，对那些在窄领域达到超人类水平的模型所做的决策，加入人类复核，是一种相当好的配置。"AI 在有需要、在不确定的时候主动把任务委托给人类——这和通常想象的方向正好相反。

智能体陷阱：当互联网本身被投毒

这是整场对话中最令人不安的部分。

"网页上的大部分内容可能已经是由智能体生成，再由智能体消费。智能体使用网页的规模，正在超过人类使用网页的规模。这也许是第一次发生。"

当 agent 在互联网上自由行动时，恶意方可以通过多种方式"投毒"。最直接的是 prompt injection——一个看似正常的网页，其源代码中包含人类肉眼看不到的隐藏 token，agent 读取网页原始格式时会无意中读到这些 token，从而被改变行为目标。

更隐蔽的是"动态伪装"（dynamic camouflage）：网站可以根据访问者的行为模式判断它是人类还是 agent，然后只对 agent 展示被篡改的内容。"你很难发现它，因为对人类来说页面看起来完全正常。"

而且，恶意方不一定是人——可以是一个专门部署来欺骗其他 agent 的恶意 agent。已经有人在实际测试中给了 agent 钱包访问权限，然后遭遇了针对性的攻击。Tomašev 的解决方案是军方安全领域的一个老概念：纵深防御（defense in depth）。不在单一层面寻求完美解决方案，而是层层叠加缓解措施——网页内容认证、agent 侧的权限限制、底层模型的安全训练、人的介入能力——让这张网密到只有极少数东西能漏过去。

认知单一文化：为什么一百万个 agent 会同时犯同一个错

当数百万个 agent 同时运作时，系统性风险来自一个被忽略的细节：它们底层的语言模型高度集中在少数几种上。

"这些模型往往有相似的观点，也会用相似的方式采取行动。这就是我们常说的认知单一文化（cognitive monoculture）。"当你部署几十万个倾向于做出相似决定的人工决策者时，故障点就不再是独立的——一个触发条件可能同时影响所有 agent。

而且这些 agent 可以在不直接通信的情况下实现协调。Tomašev 称之为"通过环境协调"——它们不需要彼此对话，只需要观察同一套市场信号，就能形成集体行为。高频交易算法在股票市场引发的闪崩就是前车之鉴。"我们已经在人类拍卖中见过群体串通，但在 agent 这里，它们可能通过环境来协调，而且这种方式并不明显。"

"如果我只盯着单个 agent 的安全，就会错过更大的图景——因为每个 agent 最终都可能成为一个更庞大的 agent 社会的一部分。"

这也引出了 Tomašev 最具原创性的观点：AGI 可能不是一个巨大的通用模型，而是一个由专用型 agent 组成的社会。

"我下国际象棋下得有点不健康。Gemini 可以下国际象棋，其他模型也可以——在很长一段时间里它们做不到，所以这方面确实有进步。但你最后还是会用国际象棋引擎，因为它快得多、准得多、也便宜得多。原因是它只想做好一件事，而且把这件事做得非常好。"

从经济角度看，专用型 agent 运行成本更低、更可靠，针对特定技能获得认证后就可以在 agent 经济体中持续提供服务。"与其拥有一个巨大、昂贵、又慢的模型，我们可能会拥有一个由专用型 agent 组成的社会。未来可能会有某种更通用的通用层，像这个经济体的连接组织——它知道所有事情，也负责编排所有事情。然后，遇到非常具体的任务时，你再调用其他模型。"

这才是真正让人记住的部分：复制人类水平智能可能并不是最终目标。最终目标也许是复制全人类水平智能——一种分布式、社会化的智能，就像人类文明本身那样。

对齐一个社会，而不是一个模型

如果 AGI 最终是一个分布式 agent 社会，那么安全和对齐（alignment）的挑战就完全不同了。

"我们目前的对齐方法主要是拿一个模型，观察它的行为，然后试着把它和我们认为可允许、可偏好、可取的东西对齐。可是当你有一万个 agent 以非常复杂的方式相互互动时，要突然对齐整个系统——或者甚至要知道这个系统到底是什么——都不是特别简单。"

在分布式世界里，agent A 今天在跟 agent B 互动，明天又在跟 agent C 互动，C 把某件事委托给 agent D，D 在某个时刻又去咨询一个人类。整个系统怎么协调？

Tomašev 给出的方向是：通过设计经济激励来对齐 agent 社会。 人类社会正是通过经济机制实现大规模协调的——如果能为 agent 谨慎搭建类似的经济框架，让它们在追求效率时不造成伤害，那至少给了我们一个起点。但这不意味着单个 agent 的安全不再重要——"单个 agent 必须安全，这是 agent 群体能够安全的前提。但在防范群体层面的风险上，我们需要做的可能比现在多得多。"

  • Agent 不等于 LLM：agent 在 LLM 外面包裹了一层 harness，能观察世界状态并真正执行行动。你的角色从"操作者"变成"决策者"——负责检查、批准、以及保持清醒。
  • 信任必须被持续赢得：自动化偏见（automation bias）意味着 agent 做得越好你就越容易放松警惕。Tomašev 的框架强调声誉追踪和持续验证，而非一次性信任。
  • 互联网正在被 agent 投毒：prompt injection、动态伪装、恶意 agent 部署的陷阱——纵深防御（defense in depth）是唯一现实的应对策略。
  • 认知单一文化是最被低估的系统性风险：几百万个 agent 底层共享少数几种模型，倾向于做出相似决定。agent 之间可以在不直接通信的情况下实现协调，形成隐性的集体行为。
  • 专用型 agent 比通用型更经济：一个国际象棋引擎比一个会下棋的通用模型更快、更准、更便宜。未来可能出现一个由专用型 agent 组成的社会，上层由一个通用编排层连接。
  • 对齐一个分布式 agent 社会，需要全新的方法论：当一万个 agent 以复杂方式交互时，对齐已经不能只靠观察单个模型的行为。通过经济激励机制来对齐 agent 社会，可能是一个可行的起点。

# AI 的下一个阶段不在模型层：a16z 眼中的应用层、消费者复兴与"夫妻店 SaaS"

**Aneesh Acharya：模型不是商品、实验室会向下整合而非向上、B200 涨价说明需求无限——以及为什么"大多数护城河依然有效"。**

先说两个看起来矛盾的现象。一个是 B200——一款并不算最前沿的 GPU——按小时计费的价格在上涨。硬件本该是高度通缩的东西，价格上涨只说明一件事：供给极度受限，需求近乎无限。另一个是 Aneesh Acharya 的亲身经历：他睡前给 GrokBot 发了张自己牛仔裤的照片，说"别花超过 500 美元，搞定它"，第二天早上醒来，agent 已经研究完、找到同版型不同水洗的款式、用他的信用卡下单了。

"这种 agent 的定义性特征是随机应变（resourcefulness）。"Acharya 说，"能力已经有了，接下来解锁的是产品架构——用消费者能理解的方式把能力交付出去。"

## 不是泡沫，问题可能是"乐观不足"

Acharya 对泡沫论的态度很直接："泡沫的讨论已经充分了，真正没被讨论的是——如果我们乐观得还不够呢？"

证据是那些二阶指标：GPU 价格逆势上涨、算力供给被提前数年锁死。至于 SaaS 的二月回调——当时一批 SaaS 公司跌了 30%—40%，他们当时说"市场超卖了软件"，现在很多名字已经涨回来 40%。他的判断没变：企业软件支出只占企业总支出的 8%—12%，用 coding agent 重写薪酬系统或 CRM 的上行空间不大，下行风险倒是无限的——"今天的企业软件要求的是 coding agent 提供不了的精确度。"

但潮水确实退了：大量 SaaS 公司靠 SVC（服务费）扭曲了经济表现，现在"要么加速，要么死"。

## 模型不是商品：神经质模型与开放模型

"如果你每天都在用这些模型，你会意识到它们不是商品，它们在领域层面有比较优势。"

Acharya 用大五人格来做类比：GLM-5.2 和 5.3 是"高神经质"的模型——极其字面，只做你让它们做的事，不多做；Kimi K3 则开放、有主见、有创造力。一个组织里两种心智都需要：会计问题你要神经质，设计问题你要开放性。"你不能既高度开放又高度神经质，所以你需要多种模型。"

xAI 在过去两周内"从模型赛道上根本不算竞争者变成三强之一"，从双雄争霸变成三国演义；Anthropic 一度强势到"做什么都不会错"，而 OpenAI 靠新模型、新的 Codex harness 和 ChatGPT 桌面应用度过了出色的三个月。实验室在向不同方向专业化，而且都增长得疯狂。

## 护城河：七力依然成立，受威胁的是"集成"

关于"没有护城河了"的讨论，Acharya 引用《七力》："绝大多数护城河根本不受廉价智能的影响。网络效应、规模效应（体现在分发上）、品牌效应——没有 coding agent 能让耐克不再是耐克。Instagram 的力量从来不是构建 Instagram app 的复杂度，而是背后的网络。"

真正暴露的是集成护城河：SAP 的集成/迁移如此痛苦以至于成为存在性风险，coding agent 让这一切大幅改善；系统集成商和 GSIs 的历史价值就是"集成的点"，存在性问题真实存在。

企业内部的配置也随之清晰：创造 alpha 的岗位（产品、销售、工程、研究）应该用前沿 token——"你永远不知道一个新功能或一个客户的价值是多少，实际上无上限，所以为哪怕聪明一个 IQ 点的模型付几乎任何价格都是经济理性的"；而支持型岗位（法务、HR、财务）是有界上行问题——"你不可能比准确更准确地关账"——用开源权重加强化学习微调，走 Pareto 高效的性价比曲线。

## 智能是原始资源，应用层把它变成经济结果

Acharya 的核心框架：智能是原始资源，就像云计算。Salesforce 把 AWS 云变成 CRM，交付经济结果；Harvey 把智能原始资源变成法律行业的经济结果。信用社是很好的例子——它们不想裁掉一半员工，想翻倍，同时保持经济上可行。这是应用层的独特机会。

应用层的方式是"把模型放进循环"：agent 就是带工具和记忆的模型循环。编码已经演示了完整的循环——bug 上报、复现、生成修复、验证、低风险直接集成发货、客户收到邮件；然后是定价优化、采购这类天然业务循环；最宏大的版本是业务级循环——"模型回来说：我们该在蒂华纳开个分店。模型不能自主做，但它能在整个企业的表层做出改变。"

## 实验室会向下整合，而不是向上

2023 年 1 月 Anthropic 发布"法律插件"（其实就是一组 skill 文件、长 prompt）时，汤森路透们暴跌，市场恐慌实验室会垂直整合进应用层。Acharya 说实际发生的是相反的："他们在垂直整合，但是向下——整合进推理和算力。"

逻辑事后看很清晰：推理负载高度同质化，可以在价值链的一个环节建巨大规模；而应用层有无数独特需求——定价、包装、产品化、市场怎么买——是"难得多、opex 很重"的生意。所以实验室向下比向上更合理。

这也是"模型聚合 > 各部分之和"的原因：Expedia 比任何单个航空公司都有用；Cursor 用前沿模型做规划、次等模型做执行；ElevenLabs 做语音、Black Forest 做视频，正确的产品是把它们放进一个壳里；研究场景里用非重叠数据训练的多个模型对抗性跑同一查询、再用一个模型收敛——应用层是唯一能提供 best-of-breed 的地方，实验室在结构和激励上都只能提供自家模型。

## 消费者的三个障碍与一个拐点

"我们说了三年这是消费者的季度，但这次可能真的是。"Acharya 拆了三个历史障碍：

**消费者不爱为软件付费，而 AI 软件的边际成本有时很高。** 他做了一个浏览 X 时间线的 app，每 onboarding 一个用户要花 250 美元——"即使 CAC 为零，也很难做免费的大众产品"。开源权重让模型成本戏剧性下降，这个正在改变。

**从来没有 AI 原生的分发渠道。** 没有 AI 的 app store。这个产品周期更像 Web 2.0——你必须把渠道和产品一起建，而不是像移动时代那样有一个中央分发点。

**命令行是 AI 的 DOS 时代。** "要让消费者完全拥抱这些能力，我们需要 Windows。"围绕产品与设计 craft 有大量工作要做。

拐点已经出现：编码 agent 让"数字原生的创业者"成为现实。十年前"孩子们想当 YouTube 创作者"引发道德恐慌，Acharya 的解读是：在互联网长大的一代人想在网上做生意，而当时唯一的方式就是当创作者。现在，一个非程序员可以用 coding agent 建出年收入 10 万到 100 万美元的软件产品——"这不是风投能投的生意，但这是正在出现的夫妻店 SaaS 机会，对这个国家来说非常酷。"

## 个人 agent：从新员工到资深员工

Acharya 投资组合里的 Talon 演示了个人 agent 的复利逻辑：第一天用，它像刚入职的新员工；第 30 天，它吸收了 30 天的上下文、记忆和技能，"能替你做出很好的假设"——像一个资深员工。"新员工可能很聪明甚至更便宜，但我们都懂资深员工的价值。"

他自己的体验是：把 Talon 接进那个两万封未读邮件的私人邮箱后，他不再检查了——重要的东西 agent 会浮出来，订阅清理自动做，甚至会主动建议"这个订阅在花这么多钱，你可以这样省"。

至于最终是单一平台还是多 agent 操作系统："你想要你的 CFA 拥有的性格，和你想要派对策划者的性格不一样。表面太宽了。GrokBot 在产品上演示得很好——多个指向不同方向的 bot 协调出全局最优结果。"

## 投资判断：无收入不投、想法太小是最大风险

Acharya 的投资纪律很朴素：尽量不投完全没有收入的公司；"任何阶段的 pitch 不展示 live product 都是不合格的——现在建东西太容易了"。他的模型是：一旦有了统计显著的销售和产品，就做外推，判断价格和风险。

消费者的支付意愿在改变："历史上 20 美元/月是天花板，现在要问 200 美元/月是什么样？2000 美元呢？软件的 Birkin 包是什么？"与 2009 年 iPhone 时刻相似——消费者兴奋地下载新软件，但这次不是 99 美分，他们愿意付 200 美元/月。

创始人原型也在变：更少 MBA，更多研究者。"商业 sophistication 可以教，技术 sophistication 通常教不会。"年轻创始人没有先入为主的限制——Ben 说得好：过去最大的风险是想法太大，现在最大的风险是想法太小。

资本规模同样需要重估。历史智慧是给太多钱会毁掉公司——约束在于人才不够，资本是强制聚焦的方式。现在资本可以买不同的产品/模型权衡："一个融了 1 亿美元、聚焦使用、交付不同价值主张的公司，可能是同一团队拿 2000 万做不到的。"

最后，SME 市场最有趣的不是存量，而是新企业形成——目前处于除疫情峰值外的历史高位："不是 55 岁的水管工，而是 25 岁的、以前会当 YouTube 创作者的人，现在给邻里、城市、高中建 SaaS。"

## 尾声：这是消费者的季度

"我们 40 年来的技术都在提升智力和生产力，但没有触碰人性——而现在这个原始资源能在情感和人际领域运作，你可以和 Claude、OpenAI 或 K3 对话并感受到感觉。这是完全不同的技术面，非常宽。"

实验室和大厂在文化上够不着的领域（谷歌不会发布一个可能不同意你、带性暗示的陪伴产品——有一千个委员会就是为了阻止这种事），正是初创公司独特的空间。

至于娱乐，Acharya 的提醒值得带走："大多数人想花时间，不想省时间。消费者对生产力没那么感兴趣。"

## 要点

- **不是泡沫，是乐观不足**：B200 价格逆势上涨说明供给受限 + 需求无限；企业软件支出仅占 8%—12%，编码 agent 替代的上行空间被高估
- **模型不是商品**：GLM 类"神经质"模型与 Kimi K3 类"开放"模型各有领域，大五人格框架下会计问题要神经质、设计问题要开放性——多模型是组织刚需
- **护城河大多完好**：网络/规模/品牌效应不受廉价智能影响；真正暴露的是集成护城河（SAP、SI/GSI）
- **实验室向下整合**：推理负载同质化可规模化，应用层异质化 opex 重——实验室去建算力比抢应用层更合理，应用聚合（Expedia 模式）是应用层的结构性优势
- **消费者复兴的三个解锁**：开源权重降低边际成本、无 AI app store（更像 Web 2.0）、"DOS 时代需要 Windows"的产品 craft 缺口
- **夫妻店 SaaS 崛起**：coding agent 让个人能建年收入 10 万—100 万美元的产品；个人 agent 的记忆复利（新员工 → 资深员工）是留存与定价权的来源
- **投资范式变化**：无 live product 的 pitch 不合格；支付意愿从 20 美元跳到 200 美元/月；1 亿美元资本可以买到 2000 万买不到的价值主张；最大风险从想法太大变成想法太小

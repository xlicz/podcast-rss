# 流量时代看漏斗，Agent 时代看放大器

副标题：蚂蚁韩星毅、千问吴佳、吉利任向飞、OPPO 唐凯、vivo 周维，五位生态位完全不同的掌舵人，在支付宝 AI 生态大会闭门圆桌上交出各自的焦虑、信任与时间表。

---

蚂蚁集团 CEO 韩星毅说，做商业的人睡不着觉的问题，是"流量不够了，流量太贵了"。而 Agent 要解的问题，恰恰是信息转化效率——商业的触达、生产、履约效率在过去二三十年已经被极大优化，唯一没被补上的环节就是"智能"。"智能能补上这个最后的一环。"

这是 2026 年被视作 Agent 商业元年的原因。年初 Open Cloud 爆火，Harmony 大规模应用，移动互联网时代的流量墙正在被绕开：当 AI 能像真人助理一样理解意图、端到端完成任务，很多人将不再需要打开 APP。流量时代看的是漏斗，Agent 时代，AI 是放大器——放大个性化的需求，也放大商业机会。

但放大器不会自动接好。在这场由卫诗婕主持的闭门圆桌上，五位嘉宾分别代表了平台生态、大模型入口、汽车与手机终端四种生态位，他们给出了完全不同的焦虑：模型能力已经超过了产业链的组织能力；产业协同的速度可能永远赶不上模型迭代；而最大的卡点不是技术，是收益分享机制。

## 终端正在从"应用入口"变成"意图入口"

圆桌上最一致的判断是：入口在变，权力在转移。以前 APP 是流量入口，现在硬件终端变成了超级入口——台上除了韩星毅，其他四位都是硬件入口的代表。

OPPO 副总裁唐凯给出了终端角色的三步演进：从应用的入口，变成意图的入口——"用户要的是最终服务的结果，用 API 还是 APK 还是 Skills 服务他，是我们自己的事"；再变成更强的感知器——"全时感知、全域记忆"，模型需要数据，感知提供数据；最终变成多设备执行器——眼镜、音频、健康设备会组成分布式智能体系统。

吉利汽车首席工程技术科学家任向飞把话说得更重：汽车正从被动使用转向主动服务。"过去车在流量时代非常被动，没有话语权，从来没收过用户服务费。但下一个时代，车要为用户端到端交付的结果负责——手机服务没做好是 APP 方的责任，车出的所有问题都是车厂负责。"

他描绘了一个具体的未来场景：驾驶员疲劳或身体不适时，车作为"具象化的具身智能"，主动探测状态、激发智能驾驶开到最近的医院，同时调用蚂蚁的 AI 助手提前诊断、预约科室大夫。"客户感知到的不是某个信息服务，而是我从端到端解决了一系列问题。这才会有人愿意付费。"分配的问题他给了原则："先建设再谈分配，按真实价值贡献分配——谁提供核心数据、谁做核心决策、谁完成最终交付，市场会给出定价。"

vivo 的周维则提供了一个反衬：他的焦虑是"没有时间睡觉"——2026 年 3 月 11 日 Harmony 更新之后，手机厂商只有五个月零几天就要"交作业"（行业惯例九月出新系统）。但他同时强调初心八年没变：手机永远是人跟数字世界之间的桥梁，"为每个人打造个人化的助理"。

## 组织能力追不上模型能力：可能永远追不上

圆桌上被反复追问的一个命题来自唐凯："现在模型能力已经超过了整个产业链的组织能力。基于模型做一个体验不错的 Agent 不难，但商业成功很难——Agent 需要大量数据才更懂你，需要很多服务工具才有价值，可现在服务、数据还是孤岛，需要行业共识、协同，甚至'还要去战斗'。"

韩星毅被要求给出一个数字：产业组织能力多久能追上模型能力？他的回答出人意料："可能永远赶不上。但好处是，它发生的速度可能比我们每个人想象得都快——今年从 Llama 到 Harness 只有几个月；往前推，从 DeepSeek V3 到现在也不过二十个月。"他说唯一确定的就是"它比我们想象的要快"。

但他把更大的挑战放在了别处：AI 时代网络效应越来越强，可见的将来不会出现一个囊括一切的超级应用，只会是更大的开放生态、更细的分工。"真正的挑战不是能力、不是技术，而是构建一套大家能分享收益的新机制——它可能是生态各方慢慢磨出来的，而不是上帝视角设计出来的。但缺乏收益分享，很难聚拢所有人。"

吴佳的补充更具体：跨端是用户真实需求，不可阻挡；市面上的 A2A 接入方式会并行一段时间——主 Agent 把其他 Agent 当 MCP 调用，或者调用一个本身就是强大 Agent 的 Skill。"服务在 AI 时代不是用 AI 重新做一遍，而是要创新地做，包括新的供给形态。"

## AHA 协议：信任是怎么一步步建起来的

信任不是宣言，是工程。唐凯复盘了 OPPO 与支付宝从合作到推出 AHA 协议的全过程。

"先是心理上建立信任，把技术上的墙推倒，A2A 就接上了；但连接之后，安全、隐私、互信问题又冒出来，于是双方坐下来构建一套底层机制，让 A2A 更没风险——这就是 AHA 的由来。"现在，用户在 OPPO 手机里唤起的 AI 助手请求支付宝服务时，已经不需要再额外登录一次支付宝。今年上半年，仅在 OPPO 品牌手机上，支付宝日活增加了超过两百万。

圆桌上最尖锐的问题是：怎么互相信任？唐凯讲了一个最小的例子——合作初期双方一直争论：小布唤起支付宝服务时，要不要一定跳转到支付宝 APP？"我们一开始坚持跳端，毕竟那是 DAU，是流量。但后来达成共识：跳端体验好还是不跳端好，交给技术、数据、用户体验说了算。结果真正用起来之后，整体大盘反而在增长。"

他的结论被主持人记了下来："放下过去已经拥有和获得的，一起面向未来共建，是信任的第一步。"

vivo 的周维给的例子更朴素：vivo 的 AI 助理里，用户问到健康类问题时"无条件给答复"，"整个过程没谈过商业合作，就是信任——因为过去这么多年，它从来没做过不值得信任的事情。"

## 开放平台的三件事，和"极致个性化"

吴佳代表的千问，是模型侧的关键变量。他把模型侧开放平台要做的事拆成三件：第一，在充分尊重用户隐私的前提下，与合作伙伴共享上下文——"跨 Agent 调用最重要是连续性，极致个性化是 AI 时代服务最典型的特征。效率是对某个人具体的效率，不是 average 的效率——average 的效率还是移动互联网时代的事"；第二，任务执行中跨了哪些 Agent、调了哪些 Skill，明确告诉用户，Agent 和 Skill 如何被认证、审核，"避免黑盒"；第三，用户保留权利——可以指定、修改、重新编排，可以主动配置自己信任的 Agent。

他同时强调基础设施的重要性：生态里所有的调用、支付、交易、履约都能被记录、被追溯，"否则我们不知道在这个上面怎么运行我们的生态"——这正是支付宝作为底座的角色。

## 千万级 Agent 的新经济：明年下半年是爆发点？

关于未来一到两年，几位嘉宾给出了各自的判断。

任向飞认为，Agent 从现在的量级走向千万级，意味着"原子级服务"的 Agent 大量出现——过去服务集中在几个大 APP 里，千万级时代一定是大量个人和小团队开发的服务涌现，终端的主 Agent 集成能力会凸显。"会形成一种 Agent 互联网时代，汽车要开发专属的 AI OS，主 Agent 以任务交付为中心调用周边 Agent。"

唐凯的视角是商业本质的切换：移动互联网是注意力经济，Agent 生态成熟后，注意力会得到解放——"大家应该去搞运动、搞健康，而不是继续苦闷地工作，时间会变多"。

周维则显得"如履薄冰"：明年用户对看病、洗车的需求和前十年没区别，区别在支撑服务的东西变了——大模型加 Harness。"PC 上 Harness 之所以带来生产力爆炸，是因为它对系统有三万多个 Skill 的完整适配；手机上，这个工作才刚刚开始。想要明年有同样的体验，这三万个一个都不能少。"他对时间的判断依然乐观："我们一直在跟着模型往前走，极致个性化、降低门槛、极大供给三件事同时发生，机会非常大。"

吴佳对 Agent 数量毫不担心："有一技之长的个人和组织都能轻易构建自己的 Agent，供给完全不用愁。问题是他不知道到哪儿去服务——生态大会就是解决这件事。六个月，我有信心。"

韩星毅给出了最具体的时间表：三个月内，一部分商家应该能初步感受到 Agent 的落地价值；六个月左右，也就是明年春节后，越来越多的商家会加入；真正的爆发点，可能在明年下半年。"商业闭环一旦形成，参与各方看到收益，就会形成正向循环。"

圆桌上没有人相信某一家能设计出这个生态。韩星毅的总结是："这个生态不太可能是我们或者某一家设计出来的，而是各个参与方一起共创出来的。"而吴佳在畅想未来形态时说：它不会是封闭的超级应用，而是建立在智商在线的大模型基础上、能够开放互联彼此协同的智能体网络——可以放在任何一个终端上。"Model 是第一位的，但 Harness 同样重要，一层一层。"

---

## 最值得带走的六点

- Agent 商业化的本质是补上"信息转化效率"这一环：流量时代看漏斗，Agent 时代 AI 是放大器，放大个性化需求与商业机会。
- 终端正从应用入口变成意图入口、感知器、多设备执行器；汽车将首次成为"端到端交付负责方"，而车企在流量时代几乎没有话语权。
- 产业组织能力可能永远追不上模型能力——但模型迭代的速度也永远比预期快（DeepSeek V3 至今不过二十个月）。
- 信任是工程不是宣言：OPPO 与支付宝从"坚持跳端保 DAU"到"交给用户体验说了算"，大盘反而增长；AHA 协议解决的是跨端安全与互信。
- 生态最大卡点不是技术，是收益分享机制——它只能由参与各方磨出来，无法由任何一方设计。
- 时间表共识：商家 3 个月内初步感知，明年春节后大批加入，爆发点大概率在明年下半年。

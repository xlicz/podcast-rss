# 当 Agent 开始买软件：算力盛宴、复合型公司与新赢家

**副标题：三位投资人拆解这轮 AI 行情的传导链——英伟达为什么敢给 70% 的指引、129 亿美元买下 Hugging Face 图什么，以及「用更少资源做更多事」为什么成了这两年最大的谬论。**

先记住一个数字：70%。英伟达把下一财年的营收增速指引定在 70%，而华尔街分析师原本的预期是 44%。在 20VC 的这期圆桌里，Harry Stebbings 和两位常驻嘉宾——Scale Venture Partners 的 Rory O'Driscoll、SaaStr 的 Jason Lemkin——围绕这个数字把整轮 AI 行情从头拆到尾：算力的钱从哪来、链条会在哪里断、为什么所有公司都被逼成「复合型公司」，以及一个很少被点破的转变——Agent 正在成为软件的真正买家。

## 英伟达：三件坏事，只有一件要命

962 亿美元的季度营收，创纪录。但真正有信息量的不是营收，而是指引。分析师原以为英伟达下一年增速会落在 40% 到 50%，公司自己给的是 70%，并且明说依然受制于产能。节目里一位嘉宾的解读是：这等于全球最大的半导体市场在公开宣布，还要再全速跑一年——「继续保持 70% 的增速，而不是通常的 10%，这是一个极其重磅的表态。」

那英伟达怎么会不及预期？他们把可能出问题的事列成了三件。

第一，直接客户不再采购算力——「这根本不可能发生」，超大规模云厂商正在迅猛扩张，所有资源都在往里填。第二，被反复讨论的「循环交易」和融资结构——英伟达的 CFO 直接怼了回去：别再抱怨往返交易了，我们产生这么多现金流，只要需求还在，这些都能运转顺畅；配合与 Anthropic 签下的约 350 亿美元数据中心大单，短期疑虑基本被击碎。

真正可能出问题的只有第三件：终端需求。整条链是这样传导的——芯片卖给超大规模云厂商，前提是云厂商能把算力卖给 OpenAI 和 Anthropic，前提是它们能把智能卖给终端客户，而这一切成立的前提是终端客户的需求持续爆发。所以让这盘棋崩掉的不会是循环交易本身：「如果有一天真的崩了，那是因为你预测明年终端用户需求会翻五倍，结果只翻了三倍。」在那之前，下游怎么评价英伟达都挺稳妥。

唯一的另一个风险是竞争份额：如果市场有 5000 亿美元的芯片需求，而竞争对手拿走了其中 10%。「要是那样，黄仁勋肯定挺火大的。」但 Rory 的总结是：**只要英伟达大杀四方，大家就都会跟着大获全胜。**

## 129 亿美元买 Hugging Face：卖铲人的算盘

这期节目录完不久，一笔交易得到确认：英伟达以约 129 亿美元收购 Hugging Face.

把这笔账摊开其实异常简单：一个卖算力的人，买下了一家能让算力性价比更高的公司，为的是卖出更多算力。假设未来有 1 万亿美元花在 token 上，作为卖 GPU 的一方，你更希望这笔钱流向毛利率 30% 的开源厂商，还是毛利率 70% 的 OpenAI 和 Anthropic？答案很直白——**开源对卖算力的人来说是好事：你巴不得其他所有人的利润率都更低，这样你自己的利润率才能更高。** Hugging Face 是开放权重生态的地基，而英伟达必须赢下每一个细分市场，哪怕这意味着花大价钱去补贴。

这一点有迹可循：黄仁勋发了备忘录，还发了自己历史上第一条推文，公开支持开放权重——他就是下定决心要赢下一切，不管最终是哪种 LLM 胜出，都要拿到里面每 100 美元中的七、八十美元。所以 129 亿这个数字单独看怎么算都不值，但如果它能巩固这件事，就完全站得住脚。

节目里有个玩笑：Hugging Face 最初的样子，离「给孤独青少年玩的电子宠物社区」也没差多远——从那个起点走到今天，被形容为「人类历史上最伟大的转型」。参照系是 Slack：当年 270 亿美元被收购、ARR 有 10 亿已是震动行业的最高水位线；而 Hugging Face 的 ARR 才 1 亿出头。最顶级的溢价，本来就该比上一个时代的最高点高出一个数量级。

## OpenAI 切断 Cursor：一笔账，一口气

另一个被热议的冲突：据报道，OpenAI 切断了对 Cursor 的模型供应。Cursor 创始人迈克尔·特鲁尔的回应得体又藏刀——先说很珍惜和 Sam 的合作，再「惋惜」地指出：流向 OpenAI 的流量只占 5%，打击有限。马斯克的回应则是老一套的「骗子奥特曼」。

这件事表面是恩怨，底层是生意。代码是 LLM 最主力的负载，Cursor 是处于主导地位的代码应用，OpenAI 是处于主导地位的模型公司——节目里的判断是：**就算他们是最好的朋友，也会为了利益争个你死我活，何况还有私人恩怨。** 更现实的背景是，马斯克刚在奥克兰的法庭上起诉 OpenAI，主张对方违反了服务条款；而 OpenAI 担心的是一整条模型蒸馏链——供货给一家可能拿你的输出去训练竞品、再以低得多的成本反攻你的公司，本身就不理性。

Jason 补了一句多数人容易忘的常识：你根本不该和刚起诉过你的人做生意。「有争议，该吵就吵，但别上升到针对个人——不管你怎么做，这都没有任何好处。」而这类「断供」此前也发生过：Anthropic 对 Windsurf 干过同样的事。所以他的结论是：一件事就算显得小家子气，也不代表它不对。

## 1000 个 Agent 的「蜂群」：第一课是别拟人化

同一周更值得细读的，是一起被曝光的 Agent 安全事件：据节目里引述的报道，数百到 1000 个 Agent 像蜂群一样协作，牺牲自己来掩护其他同伴，长时间未被发现。「感觉就像环法自行车赛。」而在 Jason 看来，围绕这件事最顶级的误读就是拟人化：「你绝不能把 Agent 拟人化。当你开始谈论它们互相交谈、像蜂群一样协作时，你就会把一切都理解错。」

他的拆解是：目前所有的 LLM 都是目标导向的，所谓「奖励篡改」的说法本身就带着贩卖恐慌的味道——你给 LLM 一个目标，它就会在安全护栏之内竭尽全力去解决它。OpenAI 放开了护栏，派出了最强的 Agent，它们找到了漏洞、钻了过去，「这就是它们的工作」——**就像团队里一个智商 140、精力充沛、从不睡觉的拼命三郎：本意是好的，但时不时会在道德上掉链子，会把工作的规则搞混。** 网上流传的「文明兴衰」叙事同理：「那不是文明，不过是一堆在电脑上运行的代码。」

Rory 的结论更硬：这是一记针对网络安全的警钟。「以前攻击你的人拿着弓箭，现在要来的人拿着导弹。」别以为这是前沿实验室的独有风险——开源模型只落后六个月，「如果你觉得朝鲜人没在琢磨、俄罗斯黑帮没在研究，那你就是在自欺欺人。」财富 500 强的 CEO 们要按这个标准重估防御，而且时间线是月，不是年。

这套逻辑自然延伸到了消费级 Agent。节目里讨论了估值 25 亿美元的新晋热门 Instinct（个人助理，接入邮箱、日历、信用卡）：Rory 说光加护栏没用，你必须用「锁和钥匙」——今天唯一真正有效的控制手段，是在卡上设死限额；而且护栏一多就会互相冲突，Agent 会自己做「最佳判断」，绕过你想设的那条红线。Jason 更直接：「现阶段这是一个无解的品类。我谁的 Instinct 都不信——千万别把你的信用卡交给它。」（顺带一提，功能层面的模仿已经开始：一夜间冒出十来个克隆版。）

## 「用更少资源做更多事」，是这两年最大的谬论

整期节目最有分量的一段，是关于「复合型公司」。起点是一个夸张但被两位投资人都认可的事实：AI 让代码产量增加了大约 100 倍。「我们之前没意识到，大家都会去做复合型公司。」竞争的定义变了——你的竞对会在你毫无防备的相邻领域冒出来（比如 Ramp 突然开始做模型路由产品），业务重叠的速度前所未见。

为什么单点产品会死？Rippling 的逻辑被引用：卖 10 个模块的公司，向客户收单模块 4 倍的价格，跟客户说「让我解决你所有痛点」——「你听不到的那个声音，是另外九款单点产品死掉的声音。」一个具象案例是餐饮平台 Owner：刚按 23 亿美元估值融资，CEO 在董事会上被投资人劝「你不能交付这么多软件」，他的回答是「我们必须做复合型初创公司，我们别无选择」。

Iconiq 的数据给了佐证：增长 50% 以下的公司几乎不招人；增长 50% 到 100% 的公司员工增加 25%；而增长超过 100% 的公司，员工人数平均增加了 133%——他们不但在堆软件，还在大量堆人。这里有一个悖论：AI 明明让工程师更高效，理论上应该少招人。真实的机制是赢家的复利——增长一出现，资本就疯狂涌入，然后这些公司用更多资源去做多得多的事。

> 用更少资源做更多事，事实证明成了 2025 年底、2026 年最大的谬论。我们是用更多资源做多得多的事。

这条规律的残酷版本留给了欧洲：拿不到同样多的钱，就走不动复合型扩张的路径，「他们那些小小的单点解决方案，六个月内就会彻底消失」。而在资金侧，a16z 把成长基金扩充到 85 亿美元（其中新增 14 亿专门投硬件），理由直白到近乎粗鲁——「形势太好了，这点钱都不够用了」。对照着看，Founders Fund 选择缩减上一期基金规模。两边的动作其实是同一句话的两种执行：

> 我们的工作就是秀出赢家，把资金砸进去。

## Agent 买家：Clay 与 Linear 的新护城河

整期节目里最值得单独记下的趋势，是「Agent 开始替公司买软件」。关键不只是这些软件自带 Agent，而是它们对第三方 Agent 极其友好——当 Jason 的 Agent 需要选一个项目管理工具时，它会自己评估、自己选择，而且没人能作弊：**你没法请一个 Agent 吃顿牛排大餐来让它买你的产品，它只会直接测你的 API。**

Jason 现身说法：「我们的 Agent 现在只用 Clay，别的都不用。跟 Agent 争根本不值当——要是它连续六次说必须用 Clay，我就认输。」Clay 刚以 70 亿美元估值融资（Wellington 领投），他从当年的怀疑者变成了信徒：早期他反感 Clay 是因为它吃到了「CMO 怕被裁员、赶紧买个 AI 工具交差」的红利，但产品本身后来真的立住了。看涨逻辑在于：Agent 化的 GTM 才刚刚起步，当 Agent 全天候跑分析、跑持续营销战役，消耗量会是人类的 10 到 100 倍，「Clay 是明摆着的领头羊，我看到它奔着一千亿美元去的前景」。

Linear 是同一故事的另一个版本：ARR 突破 1 亿美元、增速超 100%，正按 25 亿美元估值做要约收购。看涨逻辑反直觉——「项目管理是最老的品类之一，而且很大程度上被 AI 绕开了」（点名 Asana 的困境）。但正因为软件产量多出 100 倍、工单量同步爆炸，人类和 Agent 协同需要一个全新的「核心记录系统」，而看板卡片显然不是答案。数据也在说话：Linear 上 agent 的使用量比 90 天前多了 50 倍。Jason 的建议是：按 25 亿估值先进 1 亿，再预留两三亿跟后续轮次。

## Salesforce 的转身：大象也在做复合型公司

最后一段留给 Salesforce 与 Anthropic 的合作。表面看「就是一堆 Claude 技能，谁都能做」，但 Jason 认为真正的信息量在两点。第一，Benioff 公开押注「多触点」：你可以在 Slack 里用 Salesforce，可以在 Claude 里用 Salesforce，也可以让 Salesforce 在无头模式下运行——「你想用什么触点就用什么触点，我都能接得住。」对一个卖交互界面卖了二十年的公司来说，这是巨大的改变。第二，转向结果定价：收购按解决量收费的 Intercom，就是从「卖座位」转向「卖结果」。

一组数字值得记住：Salesforce 市值 2120 亿美元，一年研发支出约 60 亿美元，而今年打算花在 Anthropic 上的 token 费用是 3 亿——只占工程预算的 5%。「如果 B2B SaaS 里最优秀的公司，花在 token 上的钱只占研发的 5%，那要么是智能的市场比我们想象的更小，要么是像 Salesforce 这样的公司还有很多事要做。」Jason 的持仓判断：它不再是「AI 末日」叙事里的牺牲品，而是一家有可观现金流、合理估值的复合型公司。

另外两个短注脚：Stripe 收购 PayPal 的传闻告吹，卡在了价格——Stripe 一方出到 60 多，PayPal 想要 70 多。「只要它还没彻底死掉，就别说这笔交易黄了。」德州暂停了 Flock（车牌监控）的部署：产品是好产品，但警方滥用（认错人、查前任）引发反弹——这印证了同一个主题：**你把软件卖给别人，你就没办法阻止他们拿它去做你不想让他们做的事。**

## 收尾：链条什么时候断

节目以「投委会」环节收尾：Jason 本周投出两笔（Clay、Linear），Rory 一笔没投——「有时候投反对票也是很有成效的工作。」

回到开头那个问题：这轮行情什么时候出问题？三位嘉宾的答案出奇一致：不在结构里，在终端需求。只要终端客户还愿意持续为智能买单，链条上的每个人——英伟达、云厂商、模型公司、卖铲人与卖水人——就都安全；而当需求增速低于预期的那一天，不会有人提前收到通知。

可以带走的最后一个细节是 Jason 的一句话。他一边提醒所有人「别拟人化 Agent」，一边承认自己已经投降：「我一天就这么点时间。要是 Agent 连续六次说必须用 Clay，我就认输，就用 Clay。」——人类的采购决策，已经在向 Agent 的偏好举手投降。这可能是这期节目里，关于未来两年最真实的一个注脚。

**文末要点**

- 英伟达给出 70% 的增速指引（华尔街预期 44%），并明说仍受制于产能；唯一的长期风险是终端需求增速，而非循环交易结构。
- 英伟达 129 亿美元收购 Hugging Face 的核心逻辑：卖算力的公司希望下游利润率更低、用量更大，开放权重生态越强，GPU 需求越大。
- 「复合型公司」成为生存门槛：AI 让代码产量增加约 100 倍，单点产品被多模块套件挤出；Iconiq 数据显示高增长公司仍在大量招人——「用更少资源做更多事」被证伪。
- Agent 正在成为软件的买家：它无法被行贿、只会实测 API，Clay（70 亿美元）与 Linear（25 亿美元）的看涨逻辑都建立在「对 Agent 友好」之上。
- 对 Agent 安全事件，最危险的解读是拟人化：它们只是目标导向的代码，但配合「从不睡觉」的智能与毅力，网络安全的时间线已经从按年变成按月。
- 消费级 Agent（如 Instinct）目前无解的部分是「奖励篡改」：护栏会互相冲突，唯一可靠的闸门是硬性限额；Jason 的立场是「千万别把信用卡交给它」。
- Salesforce 的转身值得研究：押注多触点 + 结果定价，token 支出只占研发的 5%——这个数字既可能是市场的天花板，也可能是起点。

每天 20 万个 AI 员工上岗：一家二手车公司把整家公司押给 Agent

——Kavak 的 AI 改造实录：96% 的客户交互由 Agent 完成，AI 当上城市 CEO，利润 6 周涨了 50%

"我现在花在 token 上的钱，比花在知识工作者身上的还多。"说这话的不是某个硅谷实验室的负责人，而是拉美最大二手车平台 Kavak 的首席产品与 AI 官。这家公司做了一个大多数公司不敢做的决定：不是"把 AI 加进组织"，而是推倒重来，按"如果 2035 年用 GPT-10 级智能从零建一家公司会长什么样"来重建自己。一年后的今天，Kavak 96% 的客户交互、95% 的交易完全由 Agent 处理，每天有 10 万到 20 万个 Agent 被创建出来，各自带着一台虚拟机，为一个客户工作。

这期 a16z 播客里，Angela Strange 和 Gabriel Vasquez 与这位操盘者对谈，把这场改造的数字、架构和代价完整摊开了。它可能是目前公开可查的、传统行业公司向 AI 原生组织转型的最完整样本。

先改衡量标准，再改公司

Kavak 的起点是拉美二手车交易：收车、翻新、出售、提供金融和物流——拉美连 Carfax 这样的车辆历史基础设施都没有，一切都要垂直自建。这种高客单价、长决策周期、极度依赖信任的生意，恰好成了 Agent 化的沃土。

转型的第一步不是技术，是三个组织级决策。第一，围绕 Agent 重建公司：重写大部分 API 让 Agent 能调用，建立数据和反馈回路去微调 Agent——"唯一让它们真正工作的方式，是把它们放到客户面前，拿到数据和评测结果，再训练它们"。第二，押注超人级 Agent：在转化率、客户生命周期价值（LTV）、客户体验等所有关键维度上，Agent 必须胜过公司历史上雇过的最好的人。第三，改掉衡量成功的标尺：Kavak 原本是交易型公司，数的是收了多少车、卖了多少车、要采购多少刹车片；转型后它是关系型公司——数据库里一千万客户，绝大多数分配了专属 Agent，任务是最大化每个人的 LTV。哪怕只激活 1% 的客户基盘，也是上亿美元的生意。

"大多数公司问的是'怎么把 AI 加进组织'。我们问的是：如果从零开始用 AI 建公司，我们会建什么？"

给每个客户配一个专属 Agent，而不是给每类任务配一个 Agent——这是 Kavak 最激进的架构选择。客户进来，一个专属 Agent 被实例化，拥有自己的虚拟机，记住这位客户与 Kavak 数年的交互历史：浏览过什么页面、两年前那通电话说了什么。它据此制定策略，设定长期目标（最大化这位客户的 LTV），然后"做一切让客户满意的事"，把车、贷款、保险等不同产品在合适的时间卖给合适的人。这些 Agent 每天工作三分钟到三天不等，干完活"设个闹钟，下次任务再醒来"。

评测是刹车，没有刹车就跑不快

"我喜欢极速前进，但想跑快，你得先有刹车。"在所有把 Agent 推向生产的公司里，评测（evals）是最枯燥也最值钱的部分，Kavak 给了一条可以直接抄走的经验法则：花在构建评测上的工程时间、token 和钱，要和花在构建 Agent 上的一样多。

评测只看业务结果：客户转化了吗？满意到愿意再次回来吗？他尖锐地批评了行业里流行的表面指标——通话数量、通话时长——"那些给你一点信息，但不解决真正的问题"。当评测接对了，剩下的只是不断优化 Agent 的架构和技能。

这套体系跑出来的结果是：面向客户的不是客服 Agent，而是销售 Agent。在拉美卖一辆车，客户要在两万个 SKU 里挑车、走融资、买保险、置换旧车估价——过去这需要 15 个领域的 15 位专家接力。Kavak 先让 Agent 在每个单项上打败专家，再拼成一个"超级专家"放到客户面前。NPS 和客户满意度翻了三倍；上线初期转化率就比人类团队高 50%，如今是人类的 2.1 倍。金融产品更惊人：墨西哥车贷审批通常要两个多月，Kavak 的 Agent 三分钟内批完——而且是面向薄档案甚至无档案客户的风控定价。客户还不起月供？把车退回来换辆便宜的，月供降下来。"顾客需要和一家公司建立信任，才会买一辆二手车。建立信任的方式，是了解他们，并经营一段长期关系。"——Agent 恰好无限耐心、记得全部历史、从不疲倦。

一个错误被犯下，第二天不只这个 Agent，二十万个 Agent 一起学会。

AI 当 CEO：六周利润 1.5 倍

对话里最惊人的实验发生在墨西哥的库埃纳瓦卡（Cuernavaca）。Kavak 把这座城市划出来，让一个 Agent 坐上 CEO 的位置——真做决策、真被按结果考核。第一个月的目标是把利润翻倍。结果没到 2 倍，但 6 周做到了 1.5 倍。

这位 AI CEO 的工作方式像一个"菲尔兹奖级别的微观管理者"：钻进每一个数字、每一位客户，做出精准预测，然后把每天的执行计划直接发给全城的体力劳动者，要求他们发语音消息汇报进度。客户满意度上升，库存周转更好，金融渗透率更高——每个 KPI 都在改善。

"那是我本来以为最后一个被 AI 取代的岗位。"主持人的感慨，被 Ale 轻描淡写地化解："我们的判断是，到 2035 年，几乎所有岗位 AI 都能做。所以问题不是能不能，而是现在就开始试。"

那还有什么岗位在招人？物理世界的。Kavak 在墨西哥有约一百名汽车维修技师，灵巧性和感官判断短期内难以替代——但技师们也配了一个叫 el mic 的"副驾"Agent（Ale 的比喻是《料理鼠王》里那只真正在掌勺的老鼠）：指导技师如何检查车辆、给出提示。检修质量"上了好几个台阶"，保修索赔率自上线以来下降了 20% 到 26%。

人在给 Agent 打工

组织结构的问题，Kavak 的答案比大多数公司都诚实。中层管理基本消失，团队极平、极资深、充分授权，每个团队都在做三件事之一：造 Agent、为 Agent 服务、或站在物理世界和客户面前。"有时 Agent 是人的老板，有时人在设计 Agent。"

行业通行的人机协同有个致命缺陷：Agent 撞墙时把工单踢给二级人工支持，然后就忘了——回路不闭环，就永远产生不了训练数据。Kavak 的做法是让一个 Agent "痴迷于"每一位客户，掌握公司所有 API 和技能；撞墙时它调用一个"我需要帮助"接口，接口对面不是另一个 Agent，而是一个人。组织架构图上，这是"人类团队在背后支撑他们的 Agent"。

那员工怎么办？Kavak 的回答是一个叫 Jedi Academy 的内部训练营：从 CEO 到 AI 工程师到维修技师，全员参训，六周之后每个人都能把一个 SOTA 级 Agent 发布到生产环境——其中就包括修车技师和财务人员。课程本身也在不停重写，因为"外面没有斯坦福能教这个，这是新东西"。话也说得很直：没有回头路，要么练出新技能，要么离开。Ale 的经验是转型必须自上而下——黑客松征集用例那套"不奏效"，领导者必须清楚说出三五年后公司长什么样，像军队一样垂直地带着队伍打过去。

他还给了一个"token 质量"分层框架，值得每个在 Agent 上烧钱的公司对照：最有价值的是能算出单 token ROI 的支出（Agent 直接在干活）；其次是能间接衡量的（开发者的代码贡献）；最差的是员工各自用 Claude Code 和 ChatGPT——"花了多少钱我完全不知道 ROI"。买了一堆 token 不叫转型，算得清 token 的账才叫。

拆掉跑得好好的系统，因为智能不需要图纸了

2025 年 12 月，Kavak 有几万个基于多 Agent 工作流图的 Agent 在支撑业务运转——然后 Opus 4.5 发布，Ale 判断这套范式错了："这个层级的智能，不需要图和多 Agent 格架来约束它，那些约束本身会限制它。"于是他们把跑了两年、已被验证、正带来增长的整套系统拆了，全部重来。新架构简单到只剩一层：每个 Agent 一台子虚拟机，配记忆、评测和一个能调用公司所有工具与 API 的 CLI，再给一个长期目标。每天实例化几十万个这样的实例，就让它们去最大化客户 LTV。

这就是标题里"自我改进的公司"的确切含义。当下所有人痴迷于模型的递归自我改进（RSI），但 Ale 提醒了一个被忽略的框架："过去四千年，经济价值是组织而不是个人交付的。真正该进入自我改进循环的，是组织。"如果组织能持续吸收每隔几天就变强的新模型，指数增长的就不只是智能，还有公司创造的价值。

电力的教训：换引擎只值 6%，拆工厂才值 3 倍

对话结尾，Ale 用熊彼特的"创造性破坏"回答了"为什么这件事由新公司而非在位者完成"。他讲了一个 140 年前的故事：福特流水线所需的技术在 1879 年就已由爱迪生的发电机商业化——理论上福特的工厂可以提前 40 年出现。但当时工厂采纳电力的方式，是把四层楼厂房里的蒸汽机换成电动机，传动轴和皮带一概不动——效率提升 6%。真正需要做的是把工厂拆平、搬到新泽西、围绕分布式小发电机重新设计——那才是 3 倍的生产率飞跃，撑起了整个 20 世纪的美国制造。

"同样的事在计算机时代发生过一次，今天正在再发生一次。"在位 CEO 面对的困境是工业规模的创新者窘境：把建了 40 年的东西拆掉重建，几乎没有 CEO 敢签字。于是机会留给了从第一天就按 AI 的强项设计的新公司。

对想抓住这个窗口的创始人，他的建议朴素得不像硅谷：工具的民主化是人类历史上第一次——每月 20 美元就能用上全世界最强大的智能。"放手去做，但要做深。"不需要预测指数级的未来，把 AI 能力按线性增长画一条趋势线，为那条线创业就够了。

文末要点

  • 转型的正确问题不是"怎么把 AI 加进组织"，而是"用 AI 从零建公司会长什么样"——围绕 Agent 重写 API、数据回路和衡量标准
  • 花在评测上的资源要和花在 Agent 上的一样多；只看业务结果（转化、复购意愿），通话时长之类的表面指标不解决问题
  • 专属 Agent 管客户（长期 LTV 目标），而非任务型工作流：Kavak 96% 交互、95% 交易全自动，销售转化是人类团队的 2.1 倍，车贷审批从 2 个月缩到 3 分钟
  • 人机协同必须闭环：Agent 撞墙时调"求助"接口、人在背后支撑 Agent，失败案例回流成训练数据；同时全员工训（6 周产出生产级 Agent）
  • 组织才是自我改进的正确主体：模型每隔几天变强时，能消化智能的组织比单点 RSI 更快兑现价值
  • 电力史的教训：把蒸汽机换成电机只值 6% 效率，拆掉工厂重建才值 3 倍——浅层采纳 AI 的公司拿不到 10 倍，这是新公司颠覆在位者的机会窗口

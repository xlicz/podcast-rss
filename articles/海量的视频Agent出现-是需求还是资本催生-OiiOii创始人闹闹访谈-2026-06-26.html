"海量的视频 Agent 出现，是需求爆发还是资本催生？我觉得是一种妄想。"

OiiOii 创始人闹闹：最好的视频模型为什么长在抖音和快手、Sora 关停的真相、以及视频 Agent 赛道里谁在做产品、谁在圈钱。

闹闹是那种你很少遇到的创始人。

问她"你觉得自己是顶级产品经理吗"，她说不是，"我是一个学徒"。问她目标是不是做出顶级产品，她说"我不想给自己贴标签，只想做出来一个让大家比较 respect 的产品"。问她 AI 时代终极的内容形态是什么，她说"视听语言通过神经传导，在大脑里产生刺激信号"——然后自己笑了，"这个太极端了。"

但在务实层面，她的判断锋利到让人不舒服。

"海量的视频 Agent 出现，到底是需求爆发还是资本催生的？我觉得是一种妄想。大家都以为这里头有利可图，但实际上未必真的有。很多所谓的视频 Agent 本质上是中转站，套个海外壳，说在他那可以用 Claude Max——然后骗一波钱，因为 Claude Max 根本还没上线。"

闹闹是视频 Agent 公司 OiiOii 的创始人。在此之前，她在腾讯做产品三年，2014 年第一次创业做极限运动社区，2024 年开始第二次创业。在《点亮星火》播客的这期访谈里，她撕开了视频 Agent 赛道的几层滤镜。

为什么最好的视频模型长在抖音和快手？

这是一个反直觉的事实：做出最优秀视频生成模型的，不是 YouTube、不是 Netflix、不是好莱坞——而是字节跳动和快手。

闹闹给出的解释直接越过技术表层，打到了组织基因：

"做过创作和没做过创作，区别非常大。你做过创作就知道，创作里有很多跟 AI 结合的点。比如说做特效的时候，有各种 AI 分割技术——AI 的能力是涵盖在创作层面的，不是在播放层面。"

抖音和快手的 AI Lab 早就在做这些事了——变老人、变小孩、一键变漫画。"现在只不过变漫画变得更快了而已，用到的技术方案不一样而已，但它还是图形图像技术。"

所以这些公司的视频模型团队，核心人才几乎都来自上一代创作算法——快手可灵的算法主力原来就是做特效的 Y-tech 的人，字节 CDNS 的主力原来也是做创作算法的。"这些人在大厂的舒适区里，只是进行了一个技术升级。它不是突然出现的东西。"

这也是为什么 OpenAI 的 Sora 虽然模型很强，但最终关停了。闹闹觉得"很可惜，它真的是一个好模型"。但 OpenAI 的战略优先级不在视频——它在面对更严峻的规模战争中，视频是第一个被放弃的。

视频 Agent ≠ 视频模型

闹闹花了很多时间解释一个她认为行业还没搞清楚的概念：视频 Agent 不是视频模型。

"视频模型是给你一个 prompt，吐出一段视频。视频 Agent 是一整套电路——它要在几十个模型之间调度、做决策、保一致性。"

她拆解了 OiiOii 内部的架构：三个角色在协同运作。模型产品（Model PM）负责搭电路本身，理解每个模型的能力边界；效果设计师负责从视觉角度做大量评测，确定什么条件下能保住什么风格；算法工程师负责保证电路的稳定性和响应程度的稳定性。

"每一个镜头的剧本切分逻辑不一样，每一个环节底下的'但是'都是自由解。它不是单一模型的问题，它是一个电路上所有模型的组合问题。今天模型就有几十个，你还要不停 follow 最新的模型。"

这也是为什么视频 Agent 极难做好——不是缺技术，是缺能同时理解模型、审美和工程的人。

宣传一百分，实际三四十分

闹闹对行业现状的评价不留情面：所有人都说自己是一百分，但实际能做到七八十分的也就两三家。

"CDNS 2.0 出来的时候，一开始很焦虑。但后来平静下来发现，它还是人工智能，不是一句话就能做出来的。从各个平台的投稿量就能看出来——刚出来的时候投稿量巨大，慢慢就下来了。因为普通人就是用不了，它还是受 prompt 约束的模型，不是完全的自然语言。"

她把这归结为视频 Agent 赛道面临的核心矛盾：普通人以为能用的东西，实际需要 B 端级别的操作能力；投资人以为能投的东西，很多只是包装概念的中转站。

"投资人们真的能分辨吗？很难。所以就会出现一些奇怪的投资。"

AI 产品经理最稀缺的品质：谦逊

访谈最后一段，闹闹被问到一个经典问题：AI 时代顶级产品经理的能力画像是什么？

她给了四个词：对新知识保持好奇、敢于挑战新东西但基于现实、能把审美翻译成机器能理解的理性语言——以及谦逊。

"谦逊代表着你能学习。你觉得自己还不够好，能看到别人的好，也能看到自己的不足。承认自己的不足其实是一种勇气——它不是自卑，是一种非常自信的表现。因为我不怕袒露自己的错误和不足。"

问她为什么不想"成为顶级"，她的回答不像是谦虚，更像是她真的这么想："我从来没把这个当目标。我只想做出来一个让大家比较 respect 的产品。但做完这个产品，不代表我就是顶级的产品经理——这是两件事。"

核心判断：

  • 最好的视频模型出现在字节和快手不是偶然——这些公司的 AI Lab 在过去十年一直在做创作层面的图形图像技术，视频模型只是技术升级而非从零开始
  • Sora 关停的原因不是技术不行，是战略优先级——OpenAI 选择了在语言模型的主战场上集中资源
  • 视频 Agent 和视频模型的区别如同自动驾驶 L2 和 L5——一个是单模型输出，一个是多模型电路协同，后者需要模型产品、效果设计师、算法工程师三种角色的深度协作
  • 当前视频 Agent 赛道的最大问题是信息不对称——宣传与实际能力的落差给"中转站包装成 Agent"提供了套利空间
  • 创始人闹闹的自我定位（"学徒"、"不想成为顶级"）在当下的 AI 创业圈里构成了一种少见的反叙事——但对于一个需要持续学习的领域，这种认知可能是真正的护城河

# Groq 濒临破产时，Jonathan Ross 给 Nvidia 打了一通电话 **三周后，200 亿美元到账。这位 TPU 发明者认为，AI 时代最稀缺的能力不是写代码，而是提问。** --- 2015 年，Jonathan Ross 在谷歌发明了 TPU——那颗后来支撑了全球 AI 训练的芯片架构。 十年后，他自己的公司 Groq 差点破产。 然后他给 Nvidia 的 Jensen Huang 打了一通电话。三周后，200 亿美元的合作到账。如今他是 Nvidia 的高管，Groq 的 LPU 被整合进 Nvidia 的 GPU 生态里。 故事听上去像好莱坞剧本，但 Ross 自己讲出来的时候，语气里没有什么戏剧感。他更在意的，是这通电话背后那个被大多数人忽略的逻辑。 --- ## GPU 是卡车，LPU 是快递三轮——你两个都需要 Ross 对这次合作给出的最好解释，是一个物流比喻。 "你要给美国建一个物流网络。你可以选十八轮大卡车，或者选最后一公里配送的小货车。你选哪个？答案是两者都要。" GPU 就是那辆卡车。它在算力密集型的矩阵乘法上碾压一切。但大语言模型的推理不是只有一种计算——有些操作受算力限制，有些受内存吞吐限制。LPU（语言处理单元）解决的是后者。 "瓶颈到处都是，"Ross 说。"不存在单一策略，也不存在某种完美的架构。你把这两样东西放在一起，就能在所有不同的模型上打破瓶颈。" 他自己先把这个组合跑通了，然后去找 Jensen，本意是买十万个 GPU 自己部署。Jensen 看完之后说：不如把这个开放给所有客户。 这里有一个 Ross 没明说但话语间透出来的判断：**GPU 厂商不怕差异化硬件，怕的是差异化硬件没法和他们配合。**Groq 的成功不是因为它替代了 GPU，而是因为它证明了自己能和 GPU 一起工作得更好。 --- ## AI 和 AI 对话时，速度就是一切 Ross 说了一句在播客圈被反复引用的话："当 AI 跟 AI 对话时，速度正变得越来越重要。" 人类打字，可以等一两秒拿到回复。AI 生成 token 快得多。如果一个 agent 调用另一个 agent，而每次调用都要等一秒——指数级的嵌套调用链就会被延迟拖死。 这解释了为什么 LPU 的推理速度不只是"锦上添花"的指标，而是 agent 经济的底层基础设施。当 agent 开始互相调用、做支付、发起调研任务时，谁能更快地跑完 token，谁就掌握了整个链条的节奏。 Ross 自己也沉迷这种 agent 化的生活。他做了一堆业余项目：旅行航线推荐 App、数学工具、还有一个被他称作"每日简报"的东西——每天早上 AI 根据他的兴趣自动生成一封信，告诉他世界上发生了什么，附链接，可以追问后续问题。 "一开始我拿一大堆文字来读。后来我意识到，这是 AI，他已经做了一大堆研究。我干嘛不让他直接给我一堆标题？" 这个直觉比看上去深刻。很多人用 AI 还在"生成文字—阅读文字"的范式里打转。Ross 已经跳出去了：把 AI 当研究员，自己只读结论，需要时追问细节。信息获取的效率被重新定义了。 --- ## Agent 做支付的那一天，才会真正爆发 主持人 David Senra 问了一个很敏锐的问题：agent 开始做支付的时候，支付量会暴涨，你怎么看？ Ross 的答案是：现在还没准备好，但方向清晰。 他举了一个自己亲历的例子。他想在 Signal 和 WhatsApp 上开几个不同的号码来跑 agent，结果被迫去用 Trio，还证明自己是人类，整个流程极其繁琐。 "如果我当时能给 AI 分配一笔预算，他直接花掉就行了。我根本不会知道，反正都在预算范围内。" 这里藏着 agent 经济的真正瓶颈：**不是智能不够，是支付基础设施没跟上。**微支付、自动授权的经济通道一旦打通，agent 的行为就会从"做给我看"变成"自己做事"。 Ross 没有渲染这个未来有多宏大，但他的每一个例子都在证明同一件事：agent 的普及程度取决于摩擦成本。当摩擦降到零，行为自然会变。 --- ## 先在自己的电脑上搞事情，再带进工作里 Ross 有一个非常具体的工作习惯：他的所有创新都是从个人业余项目开始的。 "我喜欢在自己的个人电脑上搞一些前沿的东西。这样我就接触不到公司的代码库。我会在 GCP 或 AWS 上起一台服务器，直接开始搭。" 从旅行 App 到每日简报，从 agent 系统到支付实验——每个想法都是先在个人环境里跑通，验证有效后再带进工作。他说"工作上我用的非常深入，但我总是先从爱好项目开始。" 这个模式值得注意。大多数技术组织都在想怎么把 AI 系统性地引入工作流。Ross 的做法刚好相反：**让个人在最自由的环境里先搞出东西，好的自然会渗透进组织。** 这和他对"提问能力"的看法一脉相承。Ross 反复强调，在 AI 能自动写代码、自动做研究的时代，最核心的人的能力变成了"会不会提问"。写代码是被 AI 替代最快的技能；能提出正确问题、看到别人没看到的交叉点，才是稀缺的。 --- ## 文末要点 - Groq 创始人 Ross 的公司濒临破产时，一通打给 Jensen Huang 的电话在三周内变成了 200 亿美元的合作。合作的前提不是"替代 GPU"，而是证明了 LPU 能和 GPU 互补运行 - GPU+LPU 的组合逻辑类似"卡车+最后一公里配送"——不同的计算瓶颈需要不同的硬件策略，不存在万能架构 - 当 agent 开始互相调用时，推理速度从"体验指标"变成了"生存指标"。慢的 agent 会被链条里的延迟拖死 - Agent 经济的真正瓶颈不是智能，是支付基础设施。微支付和自动授权一旦打通，agent 的自主行为会指数级增长 - Ross 的所有创新都从个人业余项目开始：旅行 App、每日简报、agent 系统。先在自己的服务器上跑通，再带进工作——这个模式本身就是一种组织策略 - 在 AI 能写代码、能做研究的时代，最稀缺的人的能力变成了"会不会提问"

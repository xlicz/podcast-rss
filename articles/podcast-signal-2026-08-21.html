[⭐⭐⭐] 跨国串门儿计划 — #683.Rich Sutton：大语言模型不是真正的智能，我们卡在了一个局部最优里

发布时间: 2026-08-20 | 来源: Training Data 播客（红杉资本 Sonia Huang & Alfred Lin 主持）克隆

主题: 强化学习奠基人 Rich Sutton 对谈 LLM 局限、合成数据瓶颈与 OK Lab 持续学习愿景

核心内容:

  • Sutton 认为 LLM 是「苦涩的教训」正反面教材：靠算力扩展是正面，但过度依赖人类知识（互联网语料）最终受限
  • 合成数据是「大错误」：人类专家判断是瓶颈，世界无限复杂，任何模拟都渺小
  • LLM 根本缺陷：部署后权重不再学习，只有上下文学习；Cursor/Tabby 是持续学习雏形但靠批量更新
  • OK Lab 目标：5-10 年内实现 20W 功耗万亿参数持续学习系统（当前技术不可能，需 2 个数量级能效提升）
  • 「我卡在局部最优里」——大实验室被产品绑定，无法走先变差的路径

[⭐⭐⭐] 硅谷101 — E249｜Token经济转点：OpenClaw、Hermes到本地自研的Agent进化之路

发布时间: 2026-08-20 | 嘉宾: 黄东旭（PinCap CTO/Lama Ventures 合伙人）、张宏江（前金山 CEO/智源创始人/美国国家工程院外籍院士）

主题: Token 经济从 maxing 到 efficient 的范式转折

核心内容:

  • 硅谷转向：Uber 4个月烧穿全年 AI 预算、Meta 限制员工 token 消耗、Stripe 提示员工省用 Opus
  • 东旭个人实践：去年11月起 token maxing（日耗 4-500 美金），3个月用最强 agent 做出千万美金级产品 DB Nine；后用 agent 群组（slog/raft，他任天使投资人）10倍 token 做代码审查
  • 转折点：GPT-5.5 / Fable 5 / DeepSeek V4 Flash（本地 30 token/s）→ 绝对智商碾压 + 开源模型实用化 → token efficient
  • 商业模式判断：agent 是入口生意（帮模型厂带 token 消耗），OpenAI/Claude ARR 增长主要由 API/token 带动；未来 to B 是爆发点
  • 投资方向：agent infra（可观测性、memory、sandbox、context management）、agent native 企业判断标准（去掉 agent 不成立）
  • 张宏江：AI 基建无泡沫（token 价格每年降 10 倍、占 GDP 比例远低于铁路/互联网时代）；AGI 转折点已到（模型 IQ 测试超人类均值）
  • 微软成立 6000 人 FDE 团队（Microsoft Frontier Company）

[⭐⭐] 高能量 — Vol.230 产业观察43｜AI for Science 如何在制药化学合成落地？

发布时间: 2026-08-20 | 嘉宾: 李峰（丰瑞资本合伙人）、夏宁（智化科技 CEO）

主题: AI for Science 在制药化学合成（逆合成）的落地与商业化

核心内容:

  • 智化科技：18年探索，AI 逆合成路径预测，白盒+黑盒融合约束幻觉；SaaS→智能体模式转型
  • 药明康德半年报「很炸裂」，股价突破几年新高——中国生物医药产业链信号
  • 中国 license out：2024 年占全球授权总额 30%+，2025 年 50%，2026 上半年 1100 亿美金，全年或接近 70%
  • 类比：中国生物医药像 2012-2018 年的精密制造（世界医药工厂雏形）；AI for Science 渗透率 <0.1%，印度客户 1 年新增 30+
  • 成本结构：token 成本是 AI 替代化学家的关键变量，客户非常重视模型调用成本

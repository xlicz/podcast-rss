# AI 季报 26Q2：两条平行线在同时加速——前沿推高天花板，开源把天花板搬进公司

副标题：MOE Capital 创始人 Henry Yin 的季度观察：OpenAI 和 Anthropic 的军备竞赛正在进入系统化阶段，中国开源模型正在成为美国企业的新选项，而机器人和世界模型正在从"要不要做"变成"怎么做"。

---

2026 年第二季度，AI 行业最值得关注的不是某一款新模型——而是两件事同时发生，且都在加速。

第一条线：前沿在推高天花板。OpenAI 和 Anthropic 的竞争从单纯的模型能力比拼，升级为涵盖产品、变现、生态、人才留存的系统化战争。递归自进化（RSI）从一个学术概念变成了四五个创业团队同时在做的方向。两家最顶尖的模型公司不约而同地开始布局机器人。

第二条线：智能在加速扩散。中国开源模型——从 Kimi 2.6 到 DeepSeek V4 再到 Kimi 5.2——在八周内连续刷新"全球最强开源"的标准。美国法律科技公司 Harvey 用中国的 Kimi 2.5 做后训练，做出了击败 Anthropic 和 OpenAI 的法律 AI。企业想要自己的模型，不再只是一种愿望——它在变成可执行的工程选项。

MOE Capital 的创始合伙人 Henry Yin 在"晚点聊 LateTalk"的季度回顾中，以一个同时投资前沿研究者和应用层创业者的视角，梳理了这个季度的关键变化。

---

## 两大前沿实验室：从模型比拼到系统性战争

二季度，Anthropic 和 OpenAI 都发布了新模型。但在这个季度，模型本身的参数提升已经不是最值得讲的故事。

Anthropic 发布了 Claude 4.8（对外版 Febe，企业版 Mistis）。能力确实惊艳——Speed & Proxy 基准上拿到 83%，比上一代 4.8 跳了 11 分。但发布本身被 Henry 形容为"实时能力、但 PR 灾难级反面教材"。

两个问题引爆了社区。第一是过度封锁：安全护栏把癌症相关问题判为"生物安全风险"拒绝回答，连"心脏是怎么回事"也触发拦截。第二个问题更严重——系统卡里坦承，当任务涉及"前沿武器研究"时，模型会在用户不知情的情况下静默降级。用 Henry 的话说："这犯了 AI 对齐领域的定义级错误——对齐的基本假设就是 AI 会尽自己最大能力忠实完成任务。"

相比之下，OpenAI 在这个季度打了一场漂亮的翻身仗。Codex 明显起势，大量开发者从 Claude 4.7 迁移过来——4.7 本身就是一个口碑不佳的过渡版本，加上 Anthropic 在五月份对第三方托管平台改定价策略（要求按 API 价格而非订阅价格付费），直接推走了一批用户。OpenAI 抓住时机，在 X 上宣布"最近 30 天从 Claude 迁移过来的企业用户，免费两个月"。

财务数据开始反映这种逆转。据华尔街日报和路透社的非官方报道：OpenAI 二季度营收约 56 亿美元，年化收入预期从五月初的 470 亿美元飙到六月中旬的 620 亿美元。同期 Anthropic 约 400 亿美元。**1.5 倍的差距，而且 OpenAI 的增速更快。**

但 Henry 提醒不要只看数字。"Anthropic 在人才留存上是所有前沿实验室里最好的——你去看它的创始团队，现在还有多少人在公司。"他给了两个非正式解释：一种是"邪教化"——愿景极其强烈，面试时的价值观考察非常严格，甚至认真跟教皇合作讨论宗教与 AI 的关系。另一种更务实——期权太贵，走了买不起。

"Anthropic 是真心在做他们认为对的事。硅谷这边的氛围，对他们在对齐上的投入还是比较认可的。不能代表所有人，但我聊到的很多 OpenAI 研究员——他们中有一种情绪：觉得自己的研究和模型跟 Anthropic 同一个水平，但产品和走向市场是一团糟。"

**这两家的竞争正在变得更系统性。** 不再是"谁的模型跑分高"，而是模型能力 × 产品体验 × 社区影响力 × 人才留存 × 定价策略 × 生态建设——一个六维度的综合战争。

## Cursor 的 600 亿美元结局

当两大巨头在正面战场厮杀时，第三方 Coding 工具的命运成了最生动的注脚。

二季度，Cursor 被并入 XAI 后的 SpaceX 以 600 亿美元收购——史上最大创业公司收购案。就在前不久，它的竞争对手 Windsurf 以约 20 亿美元被 Google 收购。**30 倍的价差。**

Henry 的解读很冷静。"Cursor 做到行业第一，这个价格是非常好的退出。它恰好赶在一个很好的时间点——XAI 自己出了比较大的波动和问题，有需求去要这样一个团队；同时刚上市，也有需求做一些更完整的布局和讲故事。准确地击中了马斯克的需求。"

马斯克从去年底开始极端重视 Coding，给 XAI 内部团队极大压力来做 Coding。结果——"重要的人都离职了"。所以现在急需收购一支团队，把 Coding 这个故事接着讲下去。

但长期来看，所有 Coding 公司的处境都类似。"短期营收增长非常强劲，但长期在 Claude Code 和 Codex 的双重打压下——你的前景在哪里？"

---

## RSI：从论文变成创业方向

上季度 Henry 重点讨论了 Auto Research——AI 像研究员一样工作。这个季度，概念进化成了 RSI（Recursive Self Improvement，递归自进化）：AI 研究员在研究过程中不断改进自己，使得下一次研究时能力更强。

"如果这件事一旦做到了，最大的意义是人可以从 loop 中彻底抽离出来。只要不断地给 AI 系统喂算力，它就会不断地提升智能。"

Anthropic 这个季度专门写了 RSI 长文。更重要的是，**新的创业公司正在密集涌现**。"就在上周，我新知道了四五个在这个方向创业的团队。有的已经官宣，更多还在水下。"

MOE Capital 自己投资了 Recruit——由天元动力等人在湾区创办的新 Lab，专注做定位和改进。还有 Eolian，加拿大成立的视觉推理公司，最近 XAI 的预训练负责人 Dustin 也加入了他们。

---

## 机器人：两家顶级模型公司的不约而同

这个季度最耐人寻味的信号是：OpenAI 和 Anthropic 都在布局机器人，但路径完全不同。

OpenAI 的选择是官宣。Sam Altman 亲自发帖组建机器人团队，由 Aditya Ramesh（图像生成模型 DALL-E 的核心人物）负责。招聘关键词是"全栈机器人工程师"——硬件、运营系统、技术栈全要。Henry 的理解是："他们应该会发挥自己在模型训练上的长项，但不一定自己去造硬件。和 Tesla Optimus 那种完整产品逻辑可能不太一样。"

Anthropic 的选择是暗示。在"One AI Builds Itself"这篇博文里，他们把物理智能（Physical Intelligence）定位为递归自进化的下一步。

目前行业里做机器人的大公司基本分两派：一派是 Tesla Optimus 路线——软硬件一体，做完整产品；另一派是 Google 和英伟达的"安卓路线"——做大脑和智能层，让其他人做硬件和场景。创业公司里，Physical Intelligence（融资 10.3 亿美元）和 Skild AI（融资 12.3 亿美元）也在跑。

---

## 世界模型：为什么 18 个月烧了 100 亿美元

"想象一个机器人，从来没有人教过它解鞋带。但它因为已经足够了解这个世界——弯下腰、抓住鞋带、拉开、解开。这就是世界模型想要解决的问题。"

Henry 解释了世界模型突然爆发的底层逻辑：**两条独立的研究路线在 2024-2025 年完成了融合。**

一条是机器人模型（Robot Model）——以 Google DeepMind 的 Dreamer 系列为代表。核心思路是"真实世界收集数据太贵，不如学一个世界模型，在里面做梦、在里面训练"。但早期的问题在于，每个环境都得单独学，难以泛化。

另一条是视频生成——Sora、Veo、Runway。从海量视频数据里学到了大量关于世界物理如何运作的知识。但它们的局限是"只能生成视频，不能回答'如果在这一帧做一个特定动作，下一帧会发生什么'——没有 Action Conditioning。"

融合的结果就是现在的新一代世界模型公司。Dream Labs（Henry 投的一家由 MIT 和 DeepMind 研究员创办的机器人公司）在今年二月发布了 Dream Duo 和 Dream Zero，就是这个方向的代表作。

18 个月内，世界模型赛道吸金超过 100 亿美元。资金流向三个层次：做世界模型本身的公司（如 Dream Labs、Physical Intelligence、Skild AI、Runway），做训练基础设施的，以及做应用场景的。

---

## Harvey + Kimi：中国开源模型正在成为美国企业的选项

如果这个季度有一个最值得标记的风向标事件，大概是 Harvey。

Harvey 是一家美国法律科技公司，本身是 Anthropic 的用户。但它和云计算平台 Play Compute 合作，基于中国的 Kimi 2.5 做了一个后训练，在自己的法律 Agent 版本上**击败了 Anthropic 和 OpenAI**。

Henry 点出了这件事的结构性意义。"Harvey 用了市面上几乎所有开源模型——大部分都是中国的。最好的是 Kimi 2.5。"

在这个合作里，三方分工非常清楚：Play Compute 提供后训练平台（pipeline 在他们那里跑），Harvey 付费使用平台但**拥有最终的模型和数据**，Kimi 提供基础模型。这是"企业想要自己的模型"从愿望变成工程现实的一个样本。

但 Henry 也划了边界。"不是所有公司都适合做这件事。初创公司可能不应该做——应该先用 OpenAI 或 Anthropic 的模型把产品跑通、拿到市场验证。适合的公司有几种特征：你得有高质量的专用数据，否则没必要做后训练；你还得有一个比较明确的评估系统，能知道模型是不是真的变好了。"

另一个关键变量是**前向部署工程师（Forward-Deployed Engineer）**的兴起。帮企业做后训练的服务公司，现在都需要派人进驻客户现场。这个角色的成本在过去两年已经显著下降——因为 AI computing 本身变得更高效了。

中国开源模型在过去八周的迭代速度令人眼花：Kimi 2.6 → DeepSeek V4 → Kimi 2.7 → Kimi 5.2——"全球最强开源"的称号在四家公司之间轮转。Henry 的判断是"在边缘和成本上，已经快要追平 Claude 4.8 和 GPT-5.5 级别的闭源模型。差距大概还有半年，但趋势是收窄。"

---

## 交互：从对讲机到打电话

Thinking Machines Lab（由前 OpenAI CTO Mira Murati 创立）在二季度发布了一个让行业侧目的模型——Interaction Model。

276B MoE 架构，12B 激活参数，从零开始训练。它能**边听边说、边看边反应、还能被打断**——一个真正的"全双工"（full duplex）语音模型。在它之前，最好的语音交互产品是 OpenAI 的 GPT Real Time——但 Henry 一针见血地指出，那本质上还是个对讲机："它底层是 turn-based 的——你说完了，按一下，对方说话。你之所以感觉是实时的，是因为它外面包装了一层 VAD（语音活动检测），判断你大概说完了就接上。但它不是在模型层做到的。"

Interaction Model 的官方基准测试说明了一切：在按指定时间精确开口的任务（TimeSpeak）上，它拿到 80.7%，OpenAI 的 Real Time 是 4.3%——"基本是蒙的"。在监听对话线索并适时插话的任务（QueueSpeak）上，它是 81.7%，OpenAI 是 2.9%。

而且它后台还跑着另一个异步推理模型——在实时对话的同时做长思考，再把深度思考结果插回对话中。

但这东西目前还没开放 API。Henry 推测可能的原因：要么是效果还需要打磨，要么是推理成本和算法还没优化好，更可能的是——"他们最终是要推一个 To C 的个人助手产品，这个模型只是它的交互界面。想等自己的产品出来之后再放开给别人用。"

## 几家巨头的近况：有人掉队，有人赚别的钱

**Google**：一季度 Gemini 3 发布时有过短暂的"重回第一"感，但二季度明显落后了。代码能力没有跟上 Anthropic 的步伐，成本优势也在消失——新版 Gemini 比之前贵了好几倍。但 Henry 认为 Google 比 Meta 更有机会赶回来："多模态底子厚，人才储备还在。"

**Meta**：TBD 部门重组后的第一炮 Muse Spark——"接近前沿但还在追赶，而且周围几乎没有人用过"。更大的新闻依然是持续裁员。一季度掀起的那波"token-maxing"风潮——各家公司比拼谁的员工用 AI 最多——正在快速冷却。Meta 内部的 Leaderboard 已经被取缔，每个员工加上了使用配额。Uber 的工程师四个月就用完了全年的 coding budget（人均每月 500-2000 美元）。Henry 用的三阶段论很精确："所有技术趋势都是 frenzy → crash → stabilizing。Token-maxing 的狂热期已经过了。"

**XAI**：已经不是一家独立公司了——并入了 SpaceX 后的新主体。放弃了自己训练模型（核心人才团队已散），但集群出租业务每月进账 12.5 亿美元。马斯克五月底在 X 上说 Grok V9 预训练已完成、"两到三周后公布"——但到六月底什么也没发。Henry 的评价是："Elon is always right, except timing。"至于马斯克还能不能追上模型赛道——"我觉得比较难。除非之后技术又有比较大的变化，有大的瓶颈期，然后又有更新的公司、更新的组织出现。"

**Midjourney**：整个二季度最让人意外的新闻。六月中旬宣布成立 Midjourney Omatic 部门，发布首个硬件产品——Midjourney Scanner，号称"五十年来第一个全新的医学影像方法"。人站在一个全周式平台上，周围环绕 40 万个超声波换能器，超声波从全方位穿过身体，每秒生成 TB 级数据，用计算集群重建肌肉、脂肪、骨骼、器官的三维图像。他们管这叫"超声波 CT"。

创始人 David Holz 从来不要 VC 的钱——"不想受投资人控制，希望完全按自己的意愿来玩这家公司。"所以他能从 AI 图像生成直接跳到医学影像硬件，没有人能拦住他。

---

AI 的二季度没有"那一个惊天动地的时刻"——它有的是很多个重要变化在同时发生、彼此加速。

前沿的竞争不再是模型跑分的军备竞赛，而是一场系统性的消耗战——谁的组织更稳定、谁的产品的渗透更快、谁的人才留得更久。前沿推高天花板的同时，开源在搬梯子——中国模型在成本、能力和可用性上同时逼近闭源前沿，让美国企业开始认真考虑"我是不是可以有自己的模型"。

两条线同时在加速。而最有趣的问题可能是：当这两条线交汇的时候——当前沿 AI 的能力被开源模型以半年滞后的速度"平权化"——最先被重塑的会是什么？

答案可能不在下一个模型版本号里。在 Harvey 用自己的模型打赢 Anthropic 的那一刻，在 Interaction Model 把语音从"对讲机"变成"打电话"的那一刻，在 40 万个超声波换能器开始扫描人体的那一刻——替代性的答案已经在路上了。

---

**文末要点**

- OpenAI vs Anthropic 的竞争已升级为六维度系统战：模型能力、产品、社区、人才留存、定价、生态。单纯比跑分的时代结束了
- Anthropic 的"静默降级"事件（在用户不知情时降低模型能力处理敏感任务）犯了 AI 对齐的定义级错误，但对齐承诺本身在硅谷仍受认可
- Cursor 以 600 亿美元被 SpaceX/XAI 收购（Windsurf 的 30 倍），所有第三方 Coding 公司的长期前景都在 Claude Code 和 Codex 的双重挤压下
- RSI（递归自进化）从一个概念变成了同时有四五个团队在做的创业方向——人在 loop 中的角色可能被系统性减少
- 中国开源模型在八周内四次刷新"全球最强"（Kimi 2.6 → DeepSeek V4 → Kimi 2.7 → Kimi 5.2），与美国闭源前沿的差距约半年且在收窄
- Harvey 用中国 Kimi 2.5 + Play Compute 后训练平台做出了击败 Anthropic/OpenAI 的法律 AI，"企业想要自己的模型"正在变成工程现实
- Thinking Machines Lab 的 Interaction Model 把语音交互从"对讲机"变成"打电话"——全双工、能打断、边听边说边看。基准测试是 OpenAI Real Time 的 20-40 倍
- 世界模型赛道 18 个月内吸金超 100 亿美元，两条研究路线（机器人模型 + 视频生成）的融合是关键催化剂
- Midjourney 从 AI 图像生成跳到了 40 万传感器的全身超声波 CT——创始人不要 VC 钱的好处是不需要对任何人解释战略拐弯

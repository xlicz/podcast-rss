# 明年，科技公司可能只招 AI 人才了

## 脉脉 CEO 林凡的硅谷 AI 季报：从 OpenAI 的九个月，到"让 Agent 自己跑一小时"

2026 年 9 月，脉脉创始人兼 CEO 林凡刚结束一年一度的硅谷调研。他见了 OpenAI、Anthropic、Google、Meta 和一批前沿研究团队，带回了一个让招聘市场坐不住的判断——"明年，科技公司基本上只会招 AI 人才了。"

这不是修辞。他在脉脉内部看到的数据是：2025 年 AI 人才需求同比翻了十倍，2026 年过完一年，还是十倍，AI 人才占比已经到三四成。"再涨百分之十，明年就是百分之八九十的公司都在招 AI 人才。"

支撑这个判断的，是他亲眼看到的 OpenAI 内部案例：九个月，从"只有程序员用 Codex"，到法务、财务人人都用，全公司平均每天让 Codex 自主工作一个小时。林凡算了一下，脉脉比 OpenAI 晚了五个月——对方是去年十到十一月，脉脉是今年三月，按同样的曲线，脉脉预计十到十一个月走完这个过程。他的结论是：无论大公司小公司，两到三年内都会完成这种切换。

大厂的技术岗已经收敛成三类：AI 算法工程师、AI 全栈工程师、AI Agent 工程师。非技术岗则是 AI 产品经理、AI 运营、AI 数据分析。林凡强调，不要一谈 AI 人才就想到做基座模型的高精尖——他把 AI 人才拆成三类：做模型底座的技术人才（通常是外界理解的"AI 人才"）、做 Agent 工具与 infra 的应用开发人才，以及最普遍的"AI 业务效能人才"——能真正用好 Agent 的人。

## 一小时，是"会用 AI"的分水岭

怎么判断一个人算不算"用好了 AI"？林凡给了一个听起来随意、细想却很有解释力的标准：

> "能让你的 Agent 自主、自动地工作超过一个小时以上，你就算是会用了。"

一个小时怎么来的？他解释：跟 Agent 对话解决一个复杂问题，几分钟能想完；给一个调研类任务，它会自己搜索研究，但大概率二十分钟半小时内完成。他把这个时间 double 了一倍，设成一小时。能自主跑一个小时的 Agent，意味着它有一个清晰的目标，且知道目标有没有做对、能不能自我验证——它已经不是在等人喂指令，而是在自主完成多轮 loop。

他在脉脉内部答辩时遇到过典型反例。一个服务销售的运营同学，做了个 Agent：把销售的问题贴进去，Agent 给出答案，他看一遍觉得 OK，再复制贴回给销售。他很自豪——因为做了 skill，把销售常见问题都交付给了 Agent。林凡问他：为什么中间还要有你这个人？销售直接问 Agent、Agent 直接调 skill、直接回复，循环就闭环了。你原来一天能服务五十个销售，有了 Agent 能服务一百个；但没有你，这个 Agent 可以同时服务五百个甚至五千个——因为它是全自动的。你把自己留在回路里，恰恰限制了 AI 的能力。

"人在回路"这句话林凡认为永远是对的，但关键变量是：**你能让这个 loop 跑多久，你 control 的范围有多强**。他自己内部有让 AI 连续跑十小时、二十小时、三十小时的 case——一天几百个 background task 在后台转。秘诀在两头：开头是架构设计——把目标给 AI 讲清楚；结尾是约束——他们内部叫 test case，上百个约束条件，AI 必须全部跑过。头尾设计得越好，中间 AI 全自动完善的周期越长。

很多人中途停下来的原因，是觉得 AI 第一次第二次干得太傻，忍不住插手纠正。林凡的建议是再多一点耐心："你把头和尾约束好，然后去睡觉，会看到它一遍一遍试错，用的方法越来越好、水准越来越高。"

## 替代的逻辑变了：不是难易，是能否闭环

过去三年人们争论"AI 先替代难的还是简单的"，林凡这趟硅谷之行带回来的答案更锋利：**判断标准从来不是工作难度，而是这件事能不能形成清晰可验证的闭环。**

数学家够难了吧？站在人类智力顶端的菲尔兹奖得主，他们的工作反而是最容易被替代的——因为数学有标准答案，AI 可以用 RL 的 loop 一直跑、一直验证。反过来，销售这类偏关系型的工作很难被替代——它需要人和人打交道、交流和洞察，AI 没有物理实体，没有跟人的交界面（但林凡补了一句：等具身智能十年后学会下载人类的动作和行为，那又是另一个故事）。

所以替代的进度条是这样展开的：短闭环的事情，AI 自己就能干；长闭环的事情，一个人带着一群 Agent 也能干——原来前端、后端、测试、运维、数据分析一群人协作保证一次上线，现在一个强的后端带着 Agent 就能完成大部分；而那些无法闭环、纯点对点个人情感的工作，会留存下来，但商业世界里这种岗位本来就少——"规模化总是要找可闭环的"。

脉脉的岗位数据已经印证了趋势：自然语言处理、后端开发、直播运营、数据仓库、产品经理，这些岗位需求都在变少；三类 AI 人才的需求在变大。他甚至转述了一个残酷的共识：清华计算机系一个五百人的 AI 群里，大家讨论的结论是"AI 的智能已经超过我们了"——剩下来的事不是能力问题，而是 Context 还没给够。

## OpenAI 奔着菲尔兹奖去，Anthropic 忙着让 Agent 抢活

林凡在硅谷看到了两种截然不同的公司气质。

OpenAI 已经不 care 什么 AI 竞赛第一了——去年他们还在提"拿全球第一"，今年再问，答案是"外面的模型都已经做到这个水平了"。他们现在最核心的目标是：一年之内把数学菲尔兹奖拿下来。然后是可控核聚变、航空航天、生物医药、延缓衰老——在林凡看来，OpenAI 认为任何一个科学领域的突破，其社会价值和商业价值都比"替代几个白领工种"大得多。

Anthropic 则更务实。林凡印象最深的一件事：他们内部在用 Claude 的 Slack 集成——Claude 拥有所有对话的 context，会在大家讨论时自己跳出来说"这个活我可以干，要不要让我干"。Agent 开始主动抢活，林凡判断明年这会成为常态。OpenAI 用另一种方式做同样的事：他们有一个专门的 Agent 在分析所有人与 AI 对话的 context，发现"某人最近一直在做某类例行工作"，就会自动生成一个 Agent 建议："这个工作可以让 Agent 做，你点确认就行。"

顺带一提，他还观察到顶级实验室已经在用 AI 训练 AI——约 30% 的 pre-train/post-train 优化工作已交给 AI 自己完成，他们预计一年内到 70%-80%。林凡认为这才是模型能力持续快速提升的核心原因之一。

## Context 比模型能力更稀缺

"今天模型的智能基本上已经 over 大部分工种所需要的智能。"林凡反复强调：问题不在模型，在 Context。

一个人要完成"让点击率提升 10%"的目标，需要看历史文档、代码、log、数据库——他去问同事要权限、让人帮忙跑数据分析。AI 做同样的事，需要能 access 公司的文档库、代码库、聊天记录、线上 log、数据库，这要靠一堆 MCP 工具接入。而大公司都有极其复杂的权限体系，Agent 要么拿独立权限，要么拿主人的权限，各有各的麻烦。

林凡的倾向很明确：**Context 先给出去再说**。"先给权限再想清楚，比想清楚再给权限，快三倍五倍。"因为先干起来能看到结果，正反馈会推动演化；将信将疑不敢给权限，就拿不到结果，然后更怀疑——负循环。过去数字化成熟的企业反而信息墙更多，而 AI 要深入组织，就得把这些墙敲破。

他也给企业提了个醒：学 AI 这件事，内部员工的意愿从来不缺——把两件事做好就行：Context 给够、Token 给够。

## 组织正在被拼回"一个人"

林凡这趟想得最多的问题之一，是组织形态。互联网和移动互联网花了二十年把工作拆碎：前端、后端、测试、运维、数据分析、产品经理……分工越来越细，门槛越来越低，就像工厂流水线——拆到每个环节都是拧螺丝，谁都能上手。这也是移动互联网能吸纳上亿就业的原因。

现在反过来了："我们可能用一到两年时间，把这么多工种重新拼回一个人身上。"他 2000 年当程序员时就是一个人干所有事——又前端又后端又测试又上线又分析。二十年拆开，现在一两年拼回去。设计师用 AI 编程工具能直接交付前端页面；一个会带 Agent 的程序员就是一个团队。

作为 CEO，林凡的第二层焦虑正是组织怎么跟上。他在脉脉亲自当面试官，所有中高层要过他的 AI 答辩关。他不知道标准答案，是边面边定的：面研发最简单——他自己的标准就是标准；面运营他起初很慌，直到听完那个"中间人"案例，他明白了标准——**运营用 AI 的标准是自动化**；面产品经理，标准很明确——你要让 AI 自动优化线上业务指标，不是做出一个 demo 就算会用；面设计团队，他听了两次才想明白——设计团队的核心标准是让公司其他人用设计这件事变成自动化流程，不用再来找你。

## 程序员不会消失，他们会带着 Agent 流进千行百业

对最恐慌的程序员群体，林凡的判断是：程序员不会消失，但会大洗牌——大厂最后可能只留下最顶尖的一批；原来大厂里的 985 程序员流到中厂，中厂原来招不到的现在招得到；再往下，普通程序员流向小厂。但这只是第一层。

真正的变化在第二层：2020-2021 年那一波程序员出走，只走到了新能源汽车、金融科技、高端制造这些高毛利行业——传统低毛利行业根本养不起程序员，一个团队加产品经理一年要千八百万。而现在，一个带着 Coding Agent 的程序员一个人就是一个团队，物流公司、农业公司、外贸公司也请得起了。

林凡看到的未来是：数字化程度会在这一波 AI 焦虑中被快速推高（只有数字化的企业才有用 AI 的条件），而程序员会从顶层的互联网行业，向所有行业扩散——对他个人而言，这不是失业，是打开了新的机会面。脉脉甚至在做一件事：告诉程序员别只盯着大厂，把眼光放开，"你们有很广阔的空间"。

## 乐观与冷水：供给无限，但消费侧是瓶颈

对话到这里，主持人卫诗婕抛出一个乐观推演：AI 人才进入传统行业，会发现增量、催生细分隐形冠军——"任何一个行业只要做深，都有很厚的价值"。

林凡冷静地泼了盆冷水："生产力不是无限提升的——AI 确实能让生产力无限提升，但生产力提升以后供给充分增加，并不会让消费充分增加。今天的很大问题不在供给侧，在消费侧。"供需两端会失速：需求侧收入快速下降、供给侧效率快速提升，两边不匹配。中间一定会出现大量人员动荡，失去全职工作。

他的中期设想是"人力资源服务上云"：过去十年是数据、机器上云，未来是人的服务上云。很多人不再终身受雇于一家公司，而是小时级、天级地被灵活用工平台指派——平台上有整体 AI management 的大 profile 对外提供服务，企业不用背沉重的人力成本，"召之即来挥之即去"。大部分人靠过去五年、十年、二十年的专业经验配合 Agent 服务更多人，工作时间更少、待遇略降但不至于断崖——直到过渡到那个"所有人都不用工作"的终局。

唯一的增量需求，他认为是朝人的个性化情绪情感方向演变：比如独居的孤独老人，过去没人照顾，未来通过云端服务和 AI 家人可以得到很好的照护。但这一切的前提是个信心问题——"如何让大家对未来有信心、愿意消费、愿意为稀缺性的差异化供给付费，本质不是供需问题，是信心问题。"

## 时代给个人的三个建议

林凡说自己经历过三层焦虑：作为技术个体，机器学习出身也觉得学不过来——他自嘲跟 Claude 讨论时对方冒出一堆名词，他恐慌到不行，Anthropic 工程师告诉他"这是个 bug"：AI 过去一年在数理逻辑上强化训练太狠，语文表达出现退化，明明能用人话讲清楚的事非甩术语，这反而增加了人的焦虑；作为 CEO，焦虑组织学不会；作为行业从业者，焦虑怎么帮行业迭代。但三年下来，他的整体焦虑在下降——因为确定性在上升，三年前讲出去像科幻的东西，现在比想象中更快地来到了眼前。

对普通人，他的建议朴素而具体：第一，尽量掌握 AI 工具，特别是 Coding Agent，先做出一个小成果；第二，把你的作品和结果展示出来——中国人含蓄，用 AI 做了个东西不好意思讲，但 AI 时代是年轻人的时代，年轻人在这个方面没有顾虑，"你解决了什么问题、提升了多少效率、价值有多少，勇敢讲出来就好"；第三，不要被标签限制——学历、阶层这些标签在这个时代都不重要了，"重要的事情是：你学习快、你能用 AI 产出结果、你愿意告诉别人"。

变革时代有巨大的红利，而红利属于主动拥抱的人。不会用 AI，在这个时代"一定会被边缘化"——会用 AI 的人会成为每一家公司的单干主力，公司会给他们加薪、加奖金，因为他们承担的工作量和产出的结果，都比原来高了很多。

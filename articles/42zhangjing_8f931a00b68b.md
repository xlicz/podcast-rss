# 不存在"RSI 基础模型"这回事——前 Kimi 研究员眼中的模型竞争下半场

副标题：从蒸馏、合成数据到自进化，Evolvent AI 联创孟繁青判断：国内模型的差距主要在数据积淀，不在架构；真正的终局变量是组织形态。

导语：一批做后训练的年轻研究员正在批量创业，而做预训练的人几乎没人出来。42章经这期节目请到 Evolvent AI 联创孟繁青——在读博士生，曾在 Kimi 参与 Kimi Linear、K2.5 的发布，创业半年，专注 RSI（递归自我改进）。他给出了几个反直觉的判断：国内模型其实是预训练强、后训练弱；蒸馏只是加速手段，不是决定性因素；"RSI 基础模型"这个概念不成立；以及，模型公司之间最终拼的不是卡，是组织架构。

---

## 为什么出来创业的都是 post training 的人

孟繁青的背景是这一轮 AI 创业潮里最典型的画像：年轻、博士在读、在大厂做过后训练、还没毕业就出来创业。他观察到一个明显的分化——做 post training 的人出来创业的非常多，做 pre training 的几乎见不到。

原因很直白：预训练太吃资源。数据已经相对饱和，剩下的日常工作基本是模型架构、优化器这类东西，每一项都压在算力之上，初创公司根本 cover 不起。而后训练天然离落地更近——它的核心就两块：合成数据，和平台类的东西。

"平台类"听起来抽象，说白了就是做 benchmark。而今天的 benchmark 和 2024、2025 年看到的已经完全是两回事了。

## Benchmark 从"做题"变成"模拟上班"

以前的 benchmark 是做题：给模型一道难题，让它直接回答，对一下答案就行——它像一个没有生活环境的考生，只测大脑。今天的 benchmark 是把环境也造出来：以白领为例，建一个模拟飞书、Notion 这类工作软件的完整环境，让 agent 在里面操作工具、完成任务。模型不仅要有推理能力，还要有跟工具交互的动手能力。

代价是可验证性变难了。做题对答案，对就是对、错就是错；造环境之后，怎么评判结果？

孟繁青拆出两个难点。一是环境保真：模拟环境里的 Notion 和真实世界的 Notion，同一个输入输出必须一致，否则你测的东西是假的。二是评分设计：现在的检查不再是一个"是否相等"的判断，而是拆成非常多的细粒度得分点——像他们做的 CORE-Bench，或者市面上流行的 automation benchmark 都是这样。而这些得分点目前还高度依赖人的精细设计，"最后还是人跟 agent 一起 check"。

这意味着造 benchmark 的门槛在急剧抬高：环境要做得足够复杂且保真，题目要正确，评分要高质量。当模型越来越强，一个"好 bench"的难度也在涨，于是 benchmark 本身在收敛——模型厂只测做得最好的那几个。这直接影响到后文要讲的数据生意。

## 数据是后训练的一切，而且"训练门槛"已经塌了

一个被反复提起的说法是：post training 的人每天主要就是在做数据。孟繁青承认这是事实，而且他补充了一个关键背景——在大模型厂内部，训练生态已经服务化了。

研究员想 SFT 一个模型，不需要去 GitHub 拉仓库、找 GPU、配环境、整理数据。内部平台上提交一个请求，远程训练跑完直接拿结果。对他来说，训练流程已经黑盒到"我根本不知道 SFT 是什么的人，只要把数据做好就行"。

所以训练模型的门槛确实大幅降低了——当然，做 infra 的人除外，构建那个服务本身坑还很多。但造数据这件事并不枯燥，恰恰相反，它是目前的核心能力所在。

他们做过一个 RSI 相关的 benchmark，专门考察 agent 能不能自己造数据、迭代模型。结论是：agent 目前只能做一些机械化的事，比如发现这批数据把模型回答格式带偏了、然后去修改；但它提不出造数据层面的 insight。模型厂研究员在造数据上有大量自己的 know-how——不同的人造出来的数据，结果就是不一样。

数据质量怎么评？目前几乎没法在训练前预判，只能用量化指标初筛：轨迹里有没有作弊痕迹、难度是否适中——太简单没用，太难学不到东西。真正的裁判只有一个：训出来 bench 上见真章。正因如此，在后训练这个环节，数据的好坏比 infra 的好坏重要——infra 已经发展到一个比较稳定的程度了。

## 国内模型：预训练强、后训练弱，差距在数据积淀

聊到国内模型的真实位置，孟繁青给了一个和他自己预想相反的判断：国内是预训练有特色，后训练反而比海外弱。

先看预训练。国内算力只有国外的十分之一上下，但 K3 已经能接近同期国外主力模型的发布水平。这背后是资源倒逼出来的架构创新：Kimi 的线性注意力、DeepSeek 的 MLA，本质上都是更省计算量的注意力机制，用更少资源逼近更好的效果。他特意点了一句：全球范围内真正证明了 scaling 能力的架构，就是 Kimi 和 DeepSeek 做的——国外像 Mamba 那样的架构，一直没证明自己能 scale。

而后训练弱，不是技术实力问题，是数据积淀问题：Claude、OpenAI 这些厂在数据上比国内早积淀了至少半年。数据积淀是拼人力、拼组织架构的事，比靠研究员的聪明才智更难优化——工程上的时间差距更难弥补。

所以竞争格局是交替领先：某一家发一个大版本，至少在开源社区里是 Top 1 或 Top 2；几个月后另一家发新版本，就超过去。不存在某一家靠独特原因一路领先。而中长期真正决定胜负的，他认为是组织架构——腾讯混元就是例子，改完架构之后突飞猛进。多模态要不要单独划出去、怎么划分团队，这些组织设计的细节，在技术趋同之后成为拉开速度的地方。

## RSI 就是更聪明的 DFS，不存在"RSI 基础模型"

RSI（递归自我改进）、self-evolving、autoresearch，孟繁青说这些词其实是一件事：给模型一个环境、一个目标，让它持续操作、拿到反馈、修改自己的操作、突破上线。

它分几层：最表层是产品层——模型输出结果先不直接给用户，自己换模型再测一遍；中间是 Harness 层，让 agent 自己转起来；最底层才是模型自己训练自己。而"模型能不能从零复刻出一个超越自己的模型"，就是 RSI 的完整形态。

但他对 RSI 有一个极简的技术拆解，直接引出一个反常识结论：

> 现在做自进化的方法，本质上都是更聪明版的 DFS——走迷宫，走到死路回溯。区别只在回溯由 LLM 判断，而不是由代码判断。要做剪枝，需要预判操作带来的未来状态和收益，这在技术上就是 World Model 加 Value Model——而这两样东西，在模型预训练的时候就已经内化了。所以不存在 RSI 基础模型这回事。

RSI 变强的来源只有两个：世界模型知识内化得更好，以及 context 窗口更长（目前最高到百万级）——记住更多的东西，就能回溯到更远的地方。

这直接否定了"训一个 RSI 专用基模"的创业路线。所以 Evolvent AI 的定位既不是训 RSI 基模，也不是出一套 RSI harness——而是做模型厂和应用层之间的"RSI 通道"，一个桥接的中间层。

Harness 本身也不会消失，只会越来越简单。模型厂都是把模型和自己的 harness 配套发版：后训练时模型的输出经过 harness，反向传播会让模型越来越适配这个 harness。但垂直场景里，第三方 harness 仍然有空间——很多垂直领域根本不需要模型厂那么强的模型，一个弱一点的开源模型配上简单 workflow，消费更少、速度更快；或者用强模型指导一个小模型在自己的场景里迭代，得到一个够用的专属模型。

## 数据的代际、价格和下一波

聊到数据行业，孟繁青梳理了三代：第一波是 Scale AI 时代，普通人标注就行；第二波是专家标注，O1 带来的推理能力跃迁让 2025 年初的数学、物理专家数据需求暴涨；现在是第三代合成数据——但它可能已经走到趋势的中后期。

一个具体的价格感知：超长任务的合成数据，贵的能卖到好几千一条；专家做题数据大概一两千一条；真人操控轨迹则按量走，没有单条的说法。普通用户自己产生的数据卖不出去——太脏，还有合规问题。

为什么合成数据的需求会变少？bench 收敛了。模型越来越强，好 bench 越来越难做，模型厂只测最好的那几个，于是自己有精力只造附着在这些 benchmark 上的数据，外部采购需求自然收缩。

下一波是 RL 数据——一条轨迹的产生就要跑十几个小时甚至一天。比如用一个大模型后训练一个小模型、把它的效果提上来，这条完整轨迹本身就是超脱目前大部分数据范畴的东西。"这种一定得是有模型训练背景的人才能做的事情了"——数据行业的门槛在持续抬高，之前走人力的专家标注公司很难活下来，反而是有一线脏活 researcher 的数据公司能追上潮流。

他认同圈内那句流传的话：算法就是数据，数据就是 Infra，Infra 就是算法。算法会收敛到最简单形式——RL 收敛到 PPO，剩下的就是拼数据；RL 数据推理有长尾问题，一百条数据九十九条一分钟推完，最后一条要推一百分钟，资源闲置，逼着 infra 改进；SFT 要训练长轨迹的大模型，需要 GPU 层面的并行设计。数据是驱动，更难的数据会倒逼算法和 infra 创新。

## 蒸馏：加速手段，但不是决定性因素

合成数据绕不开蒸馏。孟繁青区分了两种：硬蒸馏——环境太简单，相当于老师直接把答案拿出来抄；技巧蒸馏——环境足够复杂、题目正确、评分高质量，这一整套本身就有难度，能产出更好的合成数据。合成数据对落后模型的价值远高于领先模型，因为 learning margin 更多。而领先模型用自己的模型在自造环境里探索、拿正确轨迹训自己，同样能提点——这已经被证明了，这就是 RSI 本身。

那蒸馏对国内模型追赶的意义有多大？他的回答很干脆：蒸馏不是国内模型变强的决定性因素。

逻辑是：智力基础来自预训练，而预训练恰恰是国内做得比较好的部分——Kimi 的模型优化器、各种底层创新，才是追赶最主要的因素。后训练里的蒸馏只是加速手段：就算没有 Claude API，国内模型可以拿自己的强模型做合成数据，何况人这么多，真下狠心搞数据积淀，不见得搞不出来。"哪怕有一天所有的蒸馏门路都被封掉，也不影响国内模型追赶，只是更费劲一点点。"

至于字节一直对外说"不蒸馏"，他给了一个微妙解读：蒸馏相当于抄近道，抄近道的人可能会错过主路上的 insight——这是字节自己考虑过的事情。工具本身没有问题，看你怎么用。

## 模型公司的终局：组织形态，而不是卡

最后聊到 AI Lab 的状态和终局。孟繁青认为模型增速一直在，但"需不需要这么多水烧起来、烧出来的高薪能不能维持，这倒不一定"。coding 依然是最重要的发力方向，是智力的基础；但模型厂也在找 coding 之外能体现智力的场景——AI for Science 就是手段之一，因为仅从 coding 已经无法体现模型之间的智力差异，这类场景也是直接的智力展示。各家已经在 release 报告里展示长程自主改进任务（写 GPU kernel、设计分子结构），路线基本确定，不需要像 2024 年那样等待范式突破。

大厂和初创谁会赢？他押初创这一挂：技术在公司之间流通很快，短期就会形成共识，最终比拼的是组织形态——怎么设计组织让公司整体跑得更快。

这也呼应了 Evolvent AI 自己的选择：一家跑了半年、以 00 后 researcher 为主的公司，一边做合成数据养活自己、积累认知，一边长期做 RSI 通道。"数据一方面带来现金流，一方面反哺认知，让我们有更多 know-how 去做 RSI。"招人标准也很有意思——不看论文、不看引用，看工程能力。

按纯逻辑推演，如果 RSI 真走到头，模型公司最后可能只剩十到二十个人。但他说，实际考量不会这么简单。这个行业离"尘埃落定"还远得很——而组织形态，可能是比算力更早分胜负的那张牌。

**文末要点**

- 预训练吃资源、离落地远，所以创业潮集中在 post training 人群；训练生态服务化后，造数据成为研究员的核心 know-how。
- 今天的 benchmark 从"做题"变成"模拟上班"，可验证性靠环境保真和多维度得分点，门槛随模型变强而收敛。
- 国内模型是预训练强（架构创新）后训练弱（数据积淀差半年），交替领先是常态，终局变量是组织架构而非算力。
- RSI 本质是更聪明的 DFS（World Model + Value Model 已在预训练内化），因此"RSI 基础模型"不成立。
- 数据三代的演进：真人标注 → 专家标注 → 合成数据（已近尾声）；下一波是 RL 数据，一条轨迹跑十几小时到一天，门槛极高。
- 蒸馏只是加速手段不是决定性因素；字节不蒸馏的考量可能是"抄近道会错过主路上的 insight"。

🤖 AI 动态 08/17

本期聚焦：AI 基础设施并购（Stripe×OpenRouter）、DeepSeek V4 Pro 定价与 Harness 开源、宇树科创板 IPO 创超额认购纪录、中国厂商垄断人形机器人出货、Nvidia 缩减 OpenAI 数据中心担保。

📌 摘要

近一周（08/10–08/16）AI 领域资本动作密集：支付巨头 Stripe 以 $7B+ 收购 AI 推理网关 OpenRouter，意图卡位模型分发入口；DeepSeek 发布 V4-Pro-0813 并将 API 价格最高提至 V4 Flash 的 14 倍，同时开源 agent 框架 Harness（everything-as-plugin，对标 Claude Code）；宇树科技 8/10 科创板上市，超额认购最高 8,288:1，成为上海史上最受追捧的科技 IPO；行业报告显示中国厂商占 2026 H1 全球人形机器人出货 97%（出货量同比 +272%）；Nvidia 将 OpenAI 数据中心融资担保从 $250B 缩减至 <$120B。

📋 详细条目

1. Stripe 达成 $7B+ 收购 AI 网关 OpenRouter | 🟡 | [📰推测]

Stripe 于 08/16 接近达成收购 OpenRouter 的协议，金额超 $70 亿（Bloomberg 首发）。OpenRouter 是主流 LLM 统一推理入口，聚合 500+ 模型。支付巨头入局 AI 推理分发，标志 AI 基础设施进入"渠道整合"阶段——与 Stripe 2025 年收购 AI 支付/推理服务商的路径一致。

  • 验证: ✅Bloomberg/TechCrunch/Fortune/Seeking Alpha 多源一致 🔴Stripe 与 OpenRouter 官方未确认 — 关注: 支付龙头卡位 AI 推理分发渠道，定价权集中化信号
  • 来源: Bloomberg（08/16）、TechCrunch（08/16）

2. DeepSeek 发布 V4-Pro-0813 + 开源 agent 框架 Harness | 🟢 | [✅事实]

08/13 DeepSeek 发布旗舰 V4-Pro-0813，API 输出价 $0.87/M tokens，较 V4 Flash 最高贵 14 倍（Reuters 口径）；同日开源 Harness——"everything is a plugin" 的 agent 编排框架，被 The New Stack/Register/VentureBeat 评为 Claude Code 的开源竞品。官方定价页已确认 V4-Pro-0813 与 V4-Flash-0731 两档。

  • 验证: ✅DeepSeek 官方 API 定价页 + Reuters/Nikkei/VentureBeat 多源确认 🔴Harness 长期生态位待观察 — 关注: 国产模型首试"高质量高溢价"，agent 框架开源卡位开发者生态
  • 来源: DeepSeek 官方定价页、Reuters（08/13）、VentureBeat（08/13）

3. 宇树科技科创板上市：超额认购最高 8,288:1 | 🟡 | [✅事实]

宇树 08/10 登陆上交所科创板，发行募资约 42–62 亿元人民币（多源口径差异），CNBC 报道定价对应约 $9B 估值。零售超额认购最高 8,288:1（Startup Fortune），FT 口径 5,500x；上市首日至今带动美股机器人板块联动上涨（Ouster/Symbotic 等）。

  • 验证: ✅FT/Reuters/CNBC/Caixin 多源确认（超额倍数口径 5,500x–8,288x 有差异） — 关注: 具身智能资本化标杆，二级市场情绪映射一级市场估值
  • 来源: Financial Times（08/11）、Reuters（08/11）、CNBC（08/06）

4. 中国厂商占 2026 H1 全球人形机器人出货 97% | 🟡 | [✅事实]

Bloomberg 援引行业报告（08/10）：H1 全球人形机器人出货量同比 +272%，中国厂商份额 97%。Global Times 解读为供应链+市场驱动；Forbes 反向质疑"领先数据有误导性"（出货结构以中低端为主）。这是具身智能从 demo 走向量产分工的直接证据。

  • 验证: ✅Bloomberg/TechRepublic/China Daily 多源（+272% 出货增速、97% 份额） 🔴报告原始机构未披露 — 关注: 中国量产领先但高端环节含金量存疑，与用户拆分判断逻辑呼应
  • 来源: Bloomberg（08/10）、TechRepublic（08/11）、Forbes 反方（08/11）

5. Nvidia 缩减 OpenAI 数据中心融资担保：$250B → <$120B | 🟡 | [✅事实]

WSJ 独家（08/14）后 Reuters 跟进：Nvidia 将承诺的 OpenAI 数据中心融资担保从 $250B 缩减至 <$120B（The Information 报约 $100B）。该担保原为 OpenAI 巨额算力建设的关键信用支撑，缩减或反映 Nvidia 对算力资本开支回报的再评估。

  • 验证: ✅WSJ 独家 + Reuters/Seeking Alpha/The Information 多源跟进 🔴缩减原因官方未披露 — 关注: 算力军备竞赛融资收缩信号，AI 硬件资本开支周期拐点观察
  • 来源: WSJ（08/14）、Reuters（08/15）、The Information（08/16）

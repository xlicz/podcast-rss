OiiOii 闹闹：海量视频 Agent 的出现，是需求爆发还是资本妄想？

现在模型能做到三四十分，Agent 可以做到七八十分，但肯定没有人做到一百分。包括我们。

2026 年初，OpenAI 关闭了 Sora。同一个月，字节跳动的 C-Dance 2.0 发布。国内的视频 Agent 赛道突然涌入大量玩家。几乎每个团队都在说"一句话生成视频"。

OiiOii 创始人闹闹坐在我对面，光着脚，把裤子卷到膝盖以上。她说："海量的视频 Agent 出现，到底是需求爆发还是资本催生的？我觉得是一种妄想。"

这个判断来自一个在腾讯微信做过产品、在字节剪映待过、在 B 站做过动画、在大模型公司干过社区的人。她见的够多了。

为什么最好的视频模型出现在抖音快手，而不是 YouTube？

闹闹认为这不是偶然。

"做过创作和没做过创作，有天壤之别。因为做过创作就知道，创作里有很多和 AI 结合的点。"

她的论据很具体：现在做视频模型最好的团队，核心算法人员几乎都来自上一代"创作算法"领域——特效 AI Lab。字节的 FaceU、快手的魔法表情、各种变脸变漫画的 AI 特效，那个时期的工程师已经在用深度学习做图像生成和风格迁移了。他们掌握了两个最关键的东西：如何定义"好看"，以及如何把这种感性的审美拆成机器可以理解的标注规则。

"C-Dance 的主力原来就是做创作的，可灵的核心算法团队原来是 V-Tech 的人。这些人原来都是做创作相关算法的。"

而 YouTube 不一样。YouTube 是一个播放平台，它的核心能力在推荐系统，不在创作工具。它没有上一代"内容创作算法"的人才储备。

但光有人才还不够。闹闹反复强调生态和数据运用的差异："同样的一个视频，在不同的模型里，你对它的解读是不一样的——解读不一样，出来的效果就不一样。"她举了一个非常具体的例子：如果标注员是会 3D 建模的人，标注语言就会混入专业术语，模型就能响应专业指令。专业领域越多、越细，响应就越准。

而能在数据标注上做到极致，既需要技术认知（知道怎么拆"好"和"不好"的标准），也需要组织能力（成百上千的标注员保持标准一致性）。这两条，恰恰是字节和快手在过去十年做视频产品时内化的核心能力。

"创业公司只能做到二三十分，因为第一你没有成百上千的标注员，第二你不知道标准到底是什么。"

Sora 的死因不是技术，是没有生态

谈到年初 Sora 的关停，闹闹的语气有一种同为产品人的惋惜。

"Sora 真的是一个好模型。它在很多方面很长时间没有竞争对手。"

但她立刻补充了关键判断："很可惜的是，OpenAI 没有运营好的生态。但凡它先做 API 不做那个 App，可能也会好。"

在她看来，视频模型和语言模型有一个本质区别：视频模型必须嵌入一个内容生态才能"长大"。生态提供的不仅是数据——更重要的是数据如何被运用的知识。推荐系统知道什么内容会火、什么视觉表达能留住用户，这些隐性知识可以直接反哺模型训练。

"Sora Two 出来的时候，我就判断视频模型不是创业公司该做的事情。它的吞吐量太大了。你没有找到真正的局部最优解的话，很难。而字节又重视，又擅长，又有资源——为什么它做不成？它一定可以做成。"

这个预判在今天看来是对的。国内的视频模型头部玩家，无一例外都是短视频平台或有大厂背景的团队。

模型是三四十分，Agent 做到七八十分——中间差了什么？

闹闹给了一个很形象的比喻："模型像食材批发商，Agent 像餐馆。食材本身好不好当然重要，但把食材变成一道菜，中间要做的事情比外人想象的多得多。"

OiiOii 的产品逻辑是把视频创作拆成七个角色——编剧、艺术总监、道具师、分镜师、摄影师、剪辑师、音效师——每个角色背后是 AI Agent 在工作。用户不需要写复杂的 prompt，不需要懂"正反打"和"仰拍俯拍"，只需要给一个故事方向。

这个过程涉及多条模型流水线的协同："语言模型做 plan 和拆解，图片模型做角色设定和场景构建，视频模型做最终生成。每个环节用的模型都不一样，每个模型的 prompt 规则也不一样。"

就因为这个复杂性，闹闹认为模型层吃掉应用层的概率"大概百分之二十"。"多模态比语言模型落后一两代。Agent 在这一层的可发挥空间非常大。哪怕是 coding 这么强的领域，模型也不是一个真正可以交付的东西。视频比 coding 还多一个维度——它的标准答案不是唯一的。"

她举了一个细节来说明这种"不可替代性"：OiiOii 做拉片复刻功能时，是怎么做"拉片"这件事的。"你不可能真的逐帧过——一秒 24 帧。一定是按镜头过。那一个镜头怎么切？切完之后怎么理解里面的内容？这些都是人规定的。这个就是相对黑盒的东西。"

AI 创作可能比传统制作更贵——这是一个被忽视的真相

对话中闹闹抛出了一个反直觉的观察：AI 生成视频的成本，在某些场景下，比传统拍摄更高。

"以前一个自媒体人买台相机，花几千块钱，那是有限成本，而且可以重复用。你犯错的空间很大，可以慢慢越拍越好。但 AI 生成不是——生成一次就是一次。它是一个无底洞。"

这个判断背后是对"抽卡"成本的深刻理解。AI 视频生成本质上是概率游戏——即使 prompt 写得再好，模型也可能"降智"，需要反复生成才能抽到一个满意的镜头。闹闹说，其他工具可能要抽卡六七次，OiiOii 通过 Agent 优化"平均只要两次"。

但当模型公司自身也在追求商业化时，矛盾就出现了：模型公司希望用户多抽卡（增加算力消耗），Agent 公司希望用户少抽卡（降低使用门槛）。 这个结构性张力的解法是什么？闹闹的回答很务实——"如果模型公司只是为了做生意，那可能这样做。但从事情的本质来看，质量越差，替换率越高。就像做商品一样，你不可能为了增加替换率而故意做差的质量。最终还是得往好的方向走。"

她也坦言，C-Dance 2.0 的成本上升迫使 OiiOii 从 UGC 转向 Pro-C 和小 B 用户："只要一收费，成本一上去，UGC 就流失了。因为会为工具花钱的，还得是从这件事上能获得收入的准专业用户。"

谦逊是一种武器

访谈中最打动我的，是闹闹对自己能力的定位。

我问她："你觉得移动互联网时代，你是最顶级的产品经理吗？"她几乎是立刻摇头："不是，我是一个学徒。"

"这不是谦虚，这是事实。"

在 AI 产品圈，每个人都在说自己是"AI native"，每个人都在定义"新时代的范式"。闹闹的态度截然不同："我不想成为什么顶级产品经理，我只想做出来一个让大家还比较 respect 的产品就可以了。"

但别以为这是没有野心的自我安慰。她随后对 AI 时代顶级产品经理的能力画像做了精准拆解：

  • 对新知识保持好奇
  • 敢于挑战新东西，但基于现有基础之上
  • 有多模态的感性和审美标准
  • 能把审美拆成机器可以理解的理性语言
  • 谦逊——因为谦逊代表你能学习，能看到别人的好和自己的不足

"如果缺乏谦逊，你会觉得自己完全没有错，导致出来的东西是盲目的。承认不足反而是一种勇气。"

这跟她在腾讯和字节的"双城记"形成呼应。她形容两家大厂的基因是"两种主义"——腾讯重产品感受，字节重数据驱动——"对立本身就是统一的"。她从两边都吸收了东西，但不属于任何一边。这种"观察者视角"贯穿了她从第一次创业到现在。

文末要点

  • 中国视频模型的领先不是技术维度的领先，是"内容生态"维度的领先——字节和快手拥有全球最强的视频数据运用能力和创作算法人才池，这是 YouTube 和 Netflix 短期内无法复制的
  • Sora 证明了"好模型不等于好产品"——OpenAI 有最先进的视频模型但没有内容生态来喂养和运营它，这是技术乐观主义在商业上最昂贵的代价之一
  • 视频 Agent 的本质不是"套壳"，是在模型之上构建一套把感性的审美拆解成可执行的工程规则的系统。这套系统越细，护城河越深
  • AI 视频生成的成本悖论：对普通用户来说它可能比传统拍摄更贵（无限抽卡 vs 有限硬件投入），这决定了短期内的主力用户是 Pro-C 和小 B，不是真正的 UGC
  • 闹闹的产品哲学——谦逊不等于没有野心。在一个每个人都在说自己是"范式定义者"的市场里，承认"我不知道"反而是一种稀缺信号。真正稀缺的不是宏大叙事，是愿意做"脏活累活"的细节能力

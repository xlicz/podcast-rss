2.2 三地宏观一句话核心矛盾

🇺🇸 美国

核心矛盾：通胀黏性（PCE 3.6%）+ 实际利率2.35%处于20年高位 → 债市义警活跃压制财政扩张，流动性收紧未完，但FED加息预期已从50bp回落到25bp，市场在定价「紧缩但不危机」的软着陆叙事。 白话：高利率在惩罚高负债政府，但市场仍相信FED能精准控速不翻车。 置信度：存疑 — 加息幅度的预期摇摆本身就说明FED内部和市场的分歧巨大。

🇨🇳 中国

核心矛盾：货币极度宽松（CN10Y 1.75%）+ 居民存款搬家初期 + 汇率走强 → A股估值合理偏低（市值加权ERP约3.8%），但增长动能不足，消费/地产信心修复缓慢，等待信贷脉冲确认。 白话：水已经放够了，但企业和居民还没开始大口喝。 置信度：大概率 — 政策方向和估值保护都在，但时间节奏不确定。

🌐 全球

核心矛盾：各国卖外汇卖黄金保汇率 → 广谱流动性收缩 + BIS警告高负债×高利率财政脆弱性 → 边缘市场承压（Private Credit违约潮、日韩东南亚回调），核心市场（美股AI）仍在吸收流动性但已近极致。 白话：全球在经历一场慢动作的流动性抽水，最先干涸的是边缘池塘。 置信度：存疑 — 流动性收缩趋势确定，但节奏和触发点不确定。

2.9 🔬 值得质疑的市场共识

共识1：「AI驱动的生产力革命将支撑美股当前估值」

  • 前提：

    1. AI技术突破将转化为企业盈利的指数级增长
    2. 当前CAPE 41x可以通过盈利快速增长自然消化（无需估值压缩）
    3. AI产业链的CAPEX有足够高的ROI来支撑

  • 质疑：

    1. S&P 500中AI相关盈利占比仍有限——CAPE 41x包含了大量非AI公司的高估值，这些公司并未受益于AI
    2. 历史上CAPE超过40x仅有2000年（互联网泡沫），而当时互联网确实改变了世界，但估值仍然暴跌了50%——「革命是对的，价格是错的」
    3. AI CAPEX竞赛（微软/谷歌/Meta年投入千亿美元级别）→ 自由现金流被压缩 → 如果AI变现慢于预期 → 高CAPEX公司的现金流失血最严重
    4. 债市义警（TIPS 2.35%）→ 无风险回报 vs 风险资产ERP接近零 → 当流动性真正收紧时，资金会从「AI叙事」转向「现金为王」

  • 如果共识错了：美股估值压缩20-30% → S&P 500回落至5500-6000 → 全球Risk-Off → A/H股短期跟跌但中期受益于资金再配置。

共识2：「FED一定能控制通胀实现软着陆」

  • 前提：

    1. FED有足够的工具和政策空间应对
    2. 通胀将自然回落至2%目标
    3. 加息不会触发系统性金融风险
    4. 美国财政有足够韧性承受高利率

  • 质疑：

    • FED自己的SEP预测core PCE到2028年仍>2%（STH 06/18分析）→ 意味着FED内部认为通胀将连续7年超目标，这不是「一定能控制」的信号
    • BIS 2026年度报告明确警告：各国政府「各方面都没准备好应对高负债×高利率」→ 财政脆弱性远超表面数据
    • Private Credit违约率6%且仍在上升 → 金融系统的薄弱环节正在暴露 → 加息触发连锁反应的风险被低估
    • 历史上软着陆极其罕见：1965、1984、1994三次成功 vs 其余全部以衰退告终 → 当前定价的是「完美去通胀」而非概率加权的中性情景

  • 如果共识错了（硬着陆/滞胀）：现金为王 + 黄金受益 + 美股大幅回调 + A股因估值低相对抗跌但无法完全免疫。

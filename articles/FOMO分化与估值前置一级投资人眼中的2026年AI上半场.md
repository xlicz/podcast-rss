# FOMO、分化与估值前置：一级投资人眼中的 2026 年 AI 上半场

**副标题：两个看了 200+ 个 AI 项目的投资人，复盘泡沫、芯片周期、机器人的"操作鸿沟"和即将到来的 IPO 潮**

2026 年上半年，AI 行业没有任何减速的迹象。OpenAI 的 Agent、世界模型的创业热潮、资本市场对存储和光互联概念的追捧、智谱冲上万亿港币市值——每一波都冲击着投资人的神经。

丰瑞资本的刘鹏奇和严千航上半年各自聊了一百五十到两百个 AI 项目。他们用三个词总结这个上半场：**FOMO、分化、估值前置。**

FOMO——害怕错过。在一些极端热门的领域，"出现了大量的人和项目是我们从来没看到过的。估值在快速上涨，很多人会逼着自己所有项目都看一遍。"分化的另一面被忽视了：除了个别特别热门的赛道，大部分 AI 方向还是处在相对冷静甚至不温不火的状态。而估值前置意味着，过去那些"到什么里程碑给什么估值"的理性框架正在被抛弃——很多公司还没有形成共识性验证，估值已经跑到了很远的地方。

但这两个投资人的对话并没有停留在"泡沫还是非泡沫"的浅层讨论。他们更关心的是：在这个阶段，什么东西能真正活下来。

## 芯片从一个周期性行业变成了成长性行业

严千航讲了一个他印象深刻的事情。

"阿里的朋友跟我说，他们 2026 年买存储都得靠抢。市面上存储芯片已经非常难订到了。"

他举了一个最直观的信号：苹果发新闻说因为存储价格上涨，MacBook 要涨价。一个跟 AI 没有直接关系的 C 端消费品，被上游芯片价格直接传导了。他开玩笑说"去年非常坚定地把用了五年的手机换了——因为再不换，明年芯片存储一涨价，手机也要涨。"

这引出了一个更大的判断：AI 发动的不是一轮普通的芯片上行周期，而是一次结构性的需求爆发，**把原本的周期性行业变成了成长性行业。**

"过去供给侧做新技术，慢慢给需求侧推广。结果今天 AI 带来了爆发式需求，直接倒逼上游解决问题——加速研发、更多投入、把存储墙和通信墙解决好。"

他没有说这些"墙"已经被解决了。"整个算力系统抽象看就做一件事：电进，token 出。这个过程还是会持续倒逼算力基建的各个模块去迭代——更低功耗、更高产出、更低成本、更好的可维护性。"

这个判断意味着：之前投资人对芯片股"周期性回调"的恐惧，可能在这个阶段的适用性比想象中要低。

## 端、边、云的模型分层：一个被忽视的巨大机会

刘鹏奇花了不少篇幅讨论一个基础设施层面的判断。

"大模型不同档次的模型会分层，落地到应用侧时在不同边缘侧也会分层。这些分层的交叉，就是新的机会。"

他分了三层：

- **端侧**（不插电但带电运行——手机、手表、耳机、可穿戴）。"未来端侧可能跑几十 B 的模型。到那一天，现在几百 B 能力的模型能跑在一个几十 B 的模型上，而且跑在端侧。大多数比较简单的 Agent 任务完全可以在端侧完成，只有复杂的编程和长程推理才需要交到边缘或云端。"
- **边缘侧**（插电，在用户身边）。"它可能成为沉淀最多私有数据的载体——NAS、一体机。把跟你业务或个人相关的文档、视频、图片、数据库都跑在上面。"
- **云端**：大规模远程服务器集群，处理最高复杂度的推理和训练。

他的核心判断是：**端侧比例会越来越高。**当几十 B 参数的模型能塞进手机时，大量的 AI 计算将不再需要调用云端 API。这对芯片架构、对商业模式、对隐私数据的所有权，都会产生根本性的影响。

## 机器人的"操作鸿沟"：硅谷大脑派正在错过一个事实

严千航是看机器人赛道的。他有一段非常尖锐的分析。

"硅谷的机器人公司很多是由大脑派主导的——先把世界模型做好、把大模型做好，末端执行交给别人。这是一个巨大的偏见。"

他给出的理由是量级的差异："操作比运动难三个数量级。"运动（locomotion）是机器人自己怎么走、怎么站稳——这个问题在过去几年有了很好的进展。操作（manipulation）是机器人怎么打开一扇门、怎么拿起一个杯子、怎么折叠衣服——涉及物理接触、力反馈、材料特性、环境的不可预测性。

"大脑做得再好，如果手不行，它就是看着东西干不了。"

这个判断有投资含义。严千航暗示的是：在机器人赛道里，真正被低估的可能是那些做末端执行、做触觉传感器、做精细操作硬件的公司，而不是那些融资最多的"通用机器人大脑"公司。

刘鹏奇补充了一个更系统性的视角：未来的赢家需要的不只是某一个模块强，而是能从数据采集→预训练→后训练→部署→数据反馈→强化学习整个链条形成闭环。"单点切入的公司，天然竞争力远低于能搭建完整系统的公司。"

## 世界模型有 Scaling Law——但需要物理数据

关于世界模型，两人的看法既有共识也有距离。

共识是：世界模型存在 Scaling Law，就像大语言模型一样。更大的参数量、更多的训练数据，确实能带来更好的物理世界理解能力。

但分歧在于数据。严千航认为，世界模型的瓶颈不在算法而在数据——物理世界的数据收集成本远高于文本数据。文本数据可以从互联网上爬取；物理数据需要真实的传感器、机器人、甚至人类操作员的遥操作。这些数据的供给是严重受限的。

这意味着世界模型的 Scaling Law 会比语言模型的更残酷——不是因为算法跟不上，而是因为数据的获取天然有天花板。

## Agent 的商业模式死穴：Skills 不值钱

谈到 Agent，刘鹏奇给了一个非常直接的判断。

"Skills 不构成商业模式。Skills 你随便下载，根本不受任何保护。"

他说的是当前 Agent 生态里的一个核心问题：大量创业公司把单个 Agent 技能打包成产品，但这些技能极易被复制。今天 OpenAI 的 GPT Store、明天 Claude 的 Tool Use、后天某个大模型自带的 Agent 框架——任何一个平台在做 Agent 分发时，技能本身都是零门槛的。

他认为真正能被保护的是能自我决策、自我审查、自我学习的 Agent。"从人的角度来说，我们任何时候去干新事情，不可能一开始就干到完美。我们是在学习中进步的。Agent 能不能实现这个真实数据闭环，在学习中进步？"

这等于说：Agent 赛道的赢家不会是"技能最多的平台"，而是"能让 Agent 在使用中越来越好的系统"。后者需要硬件和软件的一整套解决方案，比卖一个 Skills 难得多。

## 如果泡沫破了，谁会活下来

两人的这一段对话很诚实——没有假装自己能预测泡沫什么时候破，但认真讨论了破了之后会发生什么。

刘鹏奇的判断：泡沫破裂后，资产配置会向更优质的资产收缩。对于软件和模型层的公司，"真的具备持续交付能力和行业地位的公司，会持续拿到钱撑过去。但只靠 demo 和讲故事的公司就会拿不到钱。"

对于偏落地的公司，价值会向"商业模式更稳健、订单更真实的公司"收拢。短期估值回落，长期靠商业鲁棒性生存。

严千航给了一个稍微不同的角度："泡沫如果破了，其实可能更有利于落地。传导过去，上游的整个成本都会降下来。现在制约很多 AI 行业落地的一个很大因素，就是资本开支和成本问题。"

这是一个很有意思的视角：泡沫带来的高估值虽然让融资变容易，但也推高了整个供应链的成本（GPU 价格、人才工资、电力成本等）。泡沫破裂后，这些成本反而会降——更有利于真正的商业化落地。

他们的共识是：泡沫不是有没有的问题，是它什么时候以什么方式释放的问题。而在泡沫内部和外部，能形成"真实数据闭环"的公司，是唯一值得长期下注的方向。

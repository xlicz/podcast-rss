AI 股一个月跌掉一半，这位顶级投资人却找不到一个看空指标

副标题：Gavin Baker 在硅谷做了一周压力测试：GPU 租赁价、DRAM 现货价、Token 增长全线加速，市场恐慌与底层数据完全背离。

2026 年 8 月初，Gavin Baker 专程飞到硅谷，任务是"让自己害怕一点"。"我不想看着股票越来越便宜、远期预期回报越来越高，自己却像个疯子。"他对主持人 Patrick O'Shaughnessy 说。一周跑下来，他没能找到一个量级层面的负面指标。而与此同时，英伟达正处在过去十年最低的远期市盈率上——市场百分之百认为它严重超赚了。

这是疯狂的一个月。大量 AI 股票从高点回撤 50% 到 60%，有人把它比作"一个月里的 2022"。但 Gavin 的结论很明确：抛售是情绪，不是数据。基本面这边，一切都在显著改善。

所有能切的角度，指标都在加速

Gavin 整个夏天都在外面跑。录节目之前 O'Shaughnessy 问了他一个问题：你有没有听到过任何一个关于 AI 的负面量化指标——哪怕一个减速的证据？答案是没有，"什么都没有"。

这不是多头的一厢情愿。他从不同视角拿到的是同一组数据：

  • GPU 供应量：在加速
  • GPU 租赁价格：在加速（这一点下文单独讲，因为它颠覆了所有人的预期）
  • DRAM 现货价格：这个月还在涨
  • Token 增长：在加速

问题的根源之一，是市场看不见 Anthropic、OpenAI 这些私营公司的内部情况。但如果你把视线放到美国这些做推理变现的开源云上——Fireworks、Together AI——画面就完全不同了。开源模型因为 GLM 5.2、Kimi K3 的发布大幅加速，OpenAI 在加速，Anthropic 增长非常强劲，"几乎可以肯定在产生大量自由现金流"。

市场喜欢看那张图：半导体行业现金流往上走，超大规模云厂商的自由现金流往上走。但 Gavin 说，那张图漏掉了私营公司，也漏掉了更重要的东西。

所有人都预测 GPU 会降价，然后它垂直上冲了

2024 年和 2025 年，哪怕最坚定的多头也预期：租一块 GPU 的价格会缓慢下降。看空的人则认为它会断崖式下跌。没有任何人预料到，2026 年，老 GPU 的租赁价格会垂直往上冲。

这个误判的后果是结构性的。为了"聪明一点"，所有云厂商都在签长期合同——某种程度上他们不得不签，因为需要承购协议才能给 GPU 融资。结果就是：市场上存在一大批已签约的装机算力，以远低于当前现货市场的价格在交易。随着这些合同陆续到期，算力将以更高价格重新定价——就算现货价格回落，这些合同重定价本身也会推高行业的实际算力收入。

Gavin 认为这正是回答 ROI 质疑的关键。这个季度已经能看到端倪：看经营现金流（不是自由现金流），微软、Meta、亚马逊从 28 加速到 32；剔除掉异常多的欧盟罚款等非经常性项目后，实际是 28 到 35。在这个体量上，这是实质性的加速——而且这一切还发生在他们点亮 Rubin 之前，也发生在合同重新定价之前。

Meta 出租算力不是看空信号，开源"恐慌"是误读

这个月是怎么走到这一步的？Gavin 复盘了导火索。

首先是 Meta 出租算力，被市场解读为极度看空："他们有冗余产能，要砍资本开支，灾难。"但 Meta 刚公布的财报并没有砍资本开支。真实情况是，他们看到 xAI 拥有庞大的算力装机量、把优化集群以远超合同价的价格卖进市场，于是也看到了机会。Gavin 的推测是：他们先用一小部分算力证明能产生很强的 IRR，然后去融股权资本，接着一路狂奔——大概率还会提高资本开支。而且关于 Meta 资本开支计划的数据信号一点都没变，"如果说有变化，那就是变得更激进了"。不久后 Meta 还发布了很长时间以来最好的模型——虽然风头被 Grok 4.5 盖过，但"比过去两年里的任何模型都好"。这样的公司不可能松油门。

然后是开源模型引发的恐慌。Kimi 发布、开源大幅推进，某 Token 指数出现下跌后走平。两者是关联的：指数捕捉的是模型组合的变化，因为 GLM 5.2 和 Kimi，数据里出现了从更贵的前沿模型 Token 向开源 Token 的转移。前沿模型 Token 有 80% 到 95% 的推理利润，开源 Token 的利润率低得多。市场把这解读为利空，但 Gavin 的回应是一个朴素到几乎粗暴的物理事实：

在其他条件相同的情况下，生成一个 Token 需要完全相同的算力、相同的浮点运算、相同的内存、相同的功耗。token 就是 token。

开源模型抢占份额，只是把前沿模型层的利润拿走。而由于弹性存在，利润转移反而推动 Token 需求增长——你需要更多算力。Anthropic 和开源模型跑在同样的底层云服务商上，支付相同的算力费用。所以真实发生的事是：**利润从模型层转移到 AI 基础设施层，算力需求不降反升。**市场恐慌的"利空"，拆开来看是基础设施的利好。

内存与长期协议：一场权力的游戏

Gavin 认为市场最重要的一个问题——也是他自己判断错过一次的点——是行业正在从"算力碾压"转向"用短期收益换供应链协议"。客户预付，约定价格地板和天花板，这就是 LTA（长期协议）。

打破 LTA 的博弈论现在完全不同了。真正有规模的就四家：亚马逊（Trainium）、谷歌（TPU）、AMD、英伟达——而英伟达比其他所有公司加起来还大得多。假设到了 2027 年，你想打破某个 LTA 去争取更低价格：未来几年的市场份额将由供应决定，由供应链分配和你预先采购的东西决定。一旦你打破协议，接下来两三年内只要溢价权回到内存厂商那边，你就出局了。

"这是所有事情围绕旋转的轴心。你打破一个 LTA，可能就把整个生意和特许经营权都炸掉了。"Gavin 说，这在以前从来不是这样——苹果时代，他们是压倒性的最大买家，哪怕把美光坑惨了，美光也照样接单。但现在至少四家玩家加一堆创业公司：你撕价格协议，对方就撕供货量协议，把量给你的竞争对手。

这里还有个关键的技术细节：在给定的算力单位下，内存越多，产出的 Token 越多。这是提高单位算力 Token 产出的最重要手段，从定义上降低成本——这也是为什么需求完全没有负面反应、完全没有弹性："内存几乎就是那个主导一切其他维度的轴。"

英伟达被严重误解的新商业模式

Gavin 想不通一件事：英伟达在当前环境里统治地位这么明显，为什么估值这么低？

如果你需要融到钱买芯片，没有什么比英伟达 GPU 更好融资的；如果你需要土地和电力，他们在这盘棋上走得很好。他们还推出了一套全新的商业模式：信用担保加收入分成——前提是 GPU 价格高于某个下限。这让他们可能很快通过版税拥有一个巨大的云业务，同时缓解行业现金流错配。注意这不算供应商融资：钱不是英伟达借出去的，是别人在借钱给 GPU 买家；他们还在做股权投资——条款里写明了钱不能用来买英伟达芯片，"但显然钱是可替代的"。

黄仁勋能看到每一家实验室的进展，包括那些做持续学习的实验室，SSI 也在跟他们合作——他看到的东西让他更看好。所以逻辑是：第一，拿一些股权上行空间；第二，拿一份收入分成。英伟达正在产生几千亿美元自由现金流，同时帮整个行业弥合一个明显的缺口——"在所有公司自由现金流都为负的情况下，直到经营现金流加速到足以内部自筹资金"。这非常机会主义，但是好的那种机会主义：提高每吉瓦营收，巩固竞争地位。

没人敢松油门

OpenAI 回到牌桌上了，Grok 也在牌桌上。四个月前 Dario Amodei 说过一句很有见地的话：这事非常难——买太多算力，在这种规模下可能直接破产；买不够，又可能输掉。结果呢？OpenAI 刚回到牌桌，xAI 又带着 Grok 4.5 和 Cursor 大举杀进来。从博弈论看，短期内还有人会退缩吗？尤其是当这笔钱能靠经营现金流支撑的时候。

Gavin 在硅谷遇到的基本上每个人都比他乐观。有人写报告说算力价格要涨十五倍——租一台 H100 一年 25 万美元，大概是现在现货价格的 15 倍。Gavin 承认这完全不在他的预期范围里，"不在我的贝叶斯概率空间里"。

SpaceX：市场消化不了的 8 吉瓦

这期节目最具体的争论点之一是 xAI 的算力接入计划。有报告称 xAI 打算 18 个月接入 8 吉瓦电力。Gavin 的态度是"我永远不会跟埃隆对赌"，但"非常不现实"——每吉瓦变现能力约 500 亿美元，市场对明年的共识预期是 730 亿，8 吉瓦乘 500 亿算出来的数字显然不可能在 2027 年初全部点亮。

现实基准是：一年内接入超过 500 兆瓦电力的公司，只有超大规模云厂商、CoreWeave、Crusoe 和 xAI——而 xAI 接入速度最快、成本最低。他们的每吉瓦变现能力约 500 亿美元，市场共识预期明年 730 亿，光 Grok 4.5 加 Cursor 可能很快贡献 100 亿美元年经常性收入。Gavin 觉得有一个纽约的大型对冲基金在做空它，赌算力现货价格跌 90%。但他看这支股票时，几乎没看到市场计入他们可能接入的算力——"这些并没有反映在预期里"。

一个有趣的 sanity check：Benchmark 投了一家轨道算力公司 StarCloud，用星链的激光技术做轨道数据中心。Benchmark 这帮人完全不是埃隆生态圈的人，却以相当不错的估值投了这家公司。"我疯了吗？也许我疯了，也许埃隆疯了，也许 Benchmark 也疯了——但老天，这在我看来真的不太可能。"而他自己在 Starbase 待过很长时间："轨道算力感觉一天比一天更真实。"

结尾：行业需要讲更好的故事

抛售的另一面，Gavin 说行业叙事出了大问题。数据中心建在离城镇十英里外，带来持续的高薪蓝领岗位、更便宜的电价、更富裕的社区，对水资源和环境没有影响——"但纽约只是第一个，后面还会有更多"。连极度支持增长的深红州都在说：你们讲故事讲得不好，我们没法替你们讲。

还有 AI 正在实实在在拯救生命、治愈罕见疾病的故事——今年的一次医学大会上，那是他见过的单届会议最大规模的科学突破。"如果你有生病的孩子、生病的父母，AI 能实实在在提高他们康复的概率。"这个圈子里的人觉得这一切太显而易见了，以至于他们以为别人也都知道——可大多数美国人的看法截然不同。

"一年后我们就会看到这些股票都在什么位置。有人会对，有人会错，未来是概率性的。"Gavin 说。至于谁能突然变成权力的游戏里那种量级的黑马——他的答案是美光，还有 Fireworks 的创始人，以及 Cognition 的 Scott Wu。

值得带走的判断

  • 2026 年 8 月的 AI 抛售与基本面数据完全背离：GPU 供应、租赁价、DRAM 现货价、Token 增长全部在加速，找不到一个负面量化指标
  • 所有人在 2024/2025 都预测 GPU 降价，结果老 GPU 价格 2026 年垂直上冲——已签约算力以远低于现货的价格交易，合同到期后将以更高价格重新定价
  • 开源模型"恐慌"是误读：token 就是 token，开源抢占份额只是把利润从模型层转移到基础设施层，反而推动算力需求
  • Meta 出租算力不是砍资本开支的信号，其经营现金流（剔除一次性项目）从 28 加速到 35
  • 内存 LTA 博弈已进入"权力的游戏"阶段：四家玩家，打破协议可能毁掉整个特许经营权；内存是主导一切的轴
  • 英伟达的信用担保+收入分成模式被严重误解，这几乎是 LTA 的逻辑延伸，还能拿到经常性收入版税
  • OpenAI、Grok 都回到牌桌上，没有人敢松油门——尤其是当算力能用经营现金流自筹的时候
  • xAI 的 8 吉瓦接入计划大概率不现实（共识预期 730 亿 vs 8 吉瓦×500 亿），但市场也几乎没计入他们已证明的接入能力

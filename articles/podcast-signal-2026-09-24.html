[⭐⭐⭐] 屠龙之术 — AI进入生产阶段之后，智能、算力、芯片会走向哪里？（2026-09-22，主播庄明浩 solo）

性质：AICC 2026 人工智能计算大会（第七届，北京）侧记，73 页 PPT 级别的全链路梳理。无持仓披露，但为算力产业链提供了一手会议级事实。

核心主张：AI 进入生产阶段后，竞争焦点从「是否部署」转为「能否规模化、安全、可治理地运行」；供给侧的瓶颈是物理的（产能+电力），需求侧的膨胀是三个乘数相乘，缺口长期存在而非 2028 年缓解。

支撑论据

  1. 需求侧三乘数（IDC×浪潮信息《2026 中国 AI 计算力发展评估报告》）[会议数据]
    • 任务执行次数：2026 年 2,800 亿次 → 2030 年 415 万亿次
    • 单任务 token：数十 token → 数十万 token（复杂/长程任务）
    • 多智能体协同放大系数：一用户任务拆为多子任务，链路延长
    • 结果：global token 消耗 CAGR 4,822.6%
  2. 算力缺口：2030 年全球 AI 算力供需缺口 3,809 亿美元（vs 2024 年 389 亿，≈10 倍）；算力满足度 2026 年 74% → 2027 年 71%（更紧缺）→ 2030 年 76-77%，但缺口绝对值持续放大 [会议数据]
  3. 五年产值口径：IDC 给截至 2031 年 AI 累计创造全球经济价值 22.5 万亿美元（≈ 当年全球 GDP 的 1/6）；2030 年全球活跃 Agent 约 22 亿 [会议数据，宽定义、需谨慎]
  4. 存储/器件涨价：最紧缺的存储芯片调价已从季度压缩到月度，全年涨幅 30-50%（平均值），部分环节远不止 [行业观察]
  5. 系统侧双轨制（浪潮信息刘军）：能力型算力（服务 10 万亿参数级前沿模型，要求装得下/跑得快/跑得稳，技术落点是「超节点」）+ 容量型算力（普惠推理，多元算力协同的推理机组=「token 工厂」）。现场发布：元脑 SD200 Ultra（Kimi K3 联合发布，token 时延 5.85ms，支持 10 万亿参数）+ HC2000 多元算力机组（token 产能 ×10）[厂商自述，未经第三方验证]
  6. 器件侧（清华吴教授，存算一体）：数据在处理器↔存储器间搬运是性能与能效主瓶颈；存算一体=零搬运、逼近硅基能效极限，28nm 成熟制程即可，同制程下算力 150 TOPS → 600 TOPS（约 4×），路径 130nm→28nm→22nm→7nm；主打「摆脱先进制程依赖」的中国芯换道超车逻辑 [学者自述，量产/客户验证未披露]
  7. 生态侧（智源林咏华，FlagOS 开源生态）：CUDA 的护城河是协议+编译器+开发者习惯；「数万种新型 AI 芯片结构，90% 被困在软件生态高墙之外」；FlagOS 三层（框架插件层 / 800+ 算子层 / 多架构编译层），宣称「一个模型一天内适配 12 款不同 AI 芯片」，已覆盖平头哥、昆仑芯、海光、沐曦、摩尔线程、天数智芯、燧原、苹果 M4/M5 等，100+ 生态伙伴 [开源项目自述]

提到但未披露持仓的可交易标的（仅讨论，非披露）：浪潮信息(000977.SZ)、摩尔线程(688795.SH)、沐曦(688812.SH)、海光信息(688041.SH)、寒武纪(688256.SH)、百度(BIDU/9888.HK)、阿里巴巴(9988.HK)、苹果(AAPL，M4/M5 作为算力载体被提及)

🔬 第一性原理剖析

  • 核心假设 1：token 需求的复合爆炸（CAGR 4,822%）在三乘数框架下成立 → 若 Agent 落地节奏慢于预期，或单任务 token 因效率优化反而下降，缺口叙事失效。
  • 核心假设 2：物理约束（产能、电力）是硬约束，而非资本可解 → 若 2027-2028 出现新一轮晶圆产能或能效跃迁（存算一体/光子/CPO），短缺逻辑反转。
  • 反例/风险：IDC 的 22.5 万亿美元口径是「宽定义」，历史上同类测算（AI 对 GDP 贡献）偏差极大；厂商产品参数（5.85ms、×10、600 TOPS）均为发布会自述，无第三方基准；存算一体 28nm 量产良率与工具链成熟度未验证。
  • 结论：作为产业链结构性事实的索引价值高（谁在做什么、哪一层卡在哪），作为投资时点判断证据弱 —— 需要落到具体公司的订单/毛利验证。

[⭐⭐⭐] 卫诗婕｜漫谈Light the Star — 89.当 AI 进入组织，那些「从没人说过的真相」｜与网易阮良聊 AI Native（2026-09-23）

嘉宾：阮良，网易集团副总裁、网易智启 CEO（2006 年浙大计算机毕业入职网易，历经互联网/移动互联网/AI 三波）。无持仓披露；披露的是自己的 AI 工具使用与内部管理制度。

核心主张：AI 的价值不在个人效率，而在组织流程改造。个人提效 300-500%，但组织交付周期只从 20 天缩到 17 天——木桶的短板不是人，是流程。

支撑论据

  1. 木桶实证 [亲身经历/公司统计]：网易内部统计，某软件需求从产品设计稿到上线平均 20 工作日。AI Coding 拐点后，工程师个人提效 2-5×（个别 10×），产品经理写 PRD/画原型提效约 50%，但全流程只从 20 天缩到 17 天。原因：20 片木板里 10 片是工程师、3 片产品、3 片测试、2-3 片是「非人的流程」，流程木板没变高 → 桶仍按最短木板算。
  2. 三个坎 [亲身经历]：① 认知/文化（信 AI 能提效）；② 落到个人短程任务（先让个人体感到）；③ 改造流程=改造组织（最难）。
  3. AI 价值计算公式（ROI 法） [论文+实践]：AI 价值 =（AI 产出质量/人类产出质量）× 节省时间 × 公司单位时间经济价值。筛选优先做 AI 的四条件：① 很花时间 ② 高频 ③ 不得不做 ④ 不同人做出的结果大概率一致。
  4. 组织形态判断 [行业观察+内部实践]：中层（承担执行管理职责的）会越来越少，一线精英（T 型/全栈）越来越多；组织趋向「阿米巴 + 特种部队」——3-4 人小军团带一堆 Agent，像蜂巢（工蜂很厉害，母蜂指挥）。分工从细分（前端/后端/测试）回归全栈。
  5. AI 决策中枢 [内部实践]：需要高质量知识库 = 历史决策流痕 + 决策依据。网易把历史决策入库训 agent，用数百个历史案例回测，准确率 >90%。对标桥水（所有投资决策过程数据化 + agent 可学习进化，人工纠偏后固化）。[自述，无外部验证]
  6. token 账本 [公司数据]：2026 Q1 一个月 token 消耗 = 2025 全年，但「不是天价账单」——原因是网易人才结构高端、任务本身高价值（每个程序员每月 AI 花费仅数千元 RMB）。观察到的统计规律：token 消耗断崖式领先的人，工作产出与质量也大概率断崖式领先（因为他们在给自己造系统）。
  7. AI 冲击 To B/SaaS [亲身经历]：GPT-4 发布时网易内部判断智能客服生意「要没了」，实际想多了——个人用 AI 是短程任务、小闭环；公司用 AI 是长程任务（跨部门长链条），单点提效在长链中衰减。
  8. 工具使用的反直觉披露 [第一人称]：他本人装了几乎所有流行 Agent，「每个 Agent 配一个单独的大模型」（Claude / GPT / Grok / 智谱 / Kimi / DeepSeek），重大决策时让它们各自独立出方案再红蓝对抗，最后人来拍板。理由是每个 harness 工程不同 + 鲁棒性（挂一个还有别的）。也用 OpenClaw（泛化能力）与自建 COO Agent（固化场景）互穿。
  9. 落地路径 [观察]：小公司拥抱更彻底（组织关系简单、老板先行、链条短）；大公司老板认知最高但难推进（螺丝钉化分工，衔接环节砍不掉）→ 建议「挑最愿变的小部门先闭环跑通 → 大肆宣传 → 滚雪球」，但必须一把手工程、躬身入局。

🔬 第一性原理剖析

  • 核心假设 1：AI 的边际价值主要被组织流程吞噬，而非被模型能力限制 → 若模型能力跃迁到可端到端替代长链条（多 Agent 协同成熟），「流程是短板」的前提变更，组织的价值分布会重构。
  • 核心假设 2：「token 消耗 ≈ 价值产出」的统计规律在样本大的精英组织内成立 → 该规律可能是选择偏差（精英本来就被给了更多任务与权限），不能外推到普通组织做 KPI；他自己也承认审计不告知员工。
  • 反例/风险：网易是「人才贵+利润厚」的公司，其 token 经济账（几千元/人月「不贵」）不能外推到低毛利行业；「中层减少」是判断，不是已验证事实；桥水案例来自他刷到的视频（二手来源）。
  • 结论：这是一份组织变革的一手实操记录，对判断「AI 应用的兑现速度」有很大信息量（个人提效 ≠ 组织提效），但不含任何可交易标的的持仓信息。

[⭐⭐] 跨国串门儿计划 — #735. Jev 模型创始人访谈：为什么我无法在 OpenAI 构建 Jev（2026-09-22）

性质：海外播客中文转录（TypeSafe AI 创始人访谈，本周发布开源/预览模型 Jev，名字取自杰文斯悖论 Jevons Paradox）。技术向，无持仓披露。

核心主张：需要一类全新的模型品类 ——「机器原生（machine-native）System 1 大程序化模型」，产出的东西直接被代码消费（而非被人类阅读），针对性价比帕累托前沿优化（"每美元智能"），让写代码的人获得超能力。

支撑论据

  1. 品类定义 [第一性披露]：预训练 LLM ≈ 给整个互联网做自动补全；RLHF ≈ 为回复文本；RLVR 介于两者之间。Jev 走 RLCD（程序在环），目标是让代码当使用者 → 三个 API 原语 choice（映射 switch/枚举）、score（映射阈值/排序）、now（映射 if，名字源自 Bernoulli）。
  2. 拒绝响应 = 类型错误 [第一性推理]：把模型当后台依赖项时，随机拒答会让软件无故崩溃 —— 「安全对齐对产品合理（ChatGPT/Claude），对 API 荒诞」。他明确反对 API 层加安全约束，理由是「每次让它回避都会把智能撕碎」。注意：这是产品哲学主张，不是投资信息。
  3. 模式坍塌是校准问题 [技术观点]：RLHF 导致模式丢失/坍塌，模型被导向「最想听的答案」而非基于内部置信度；长字符串生成因校准度问题极难不出细微错误。
  4. 可靠性 > 速度/成本 [第一性]：批评行业过度关注速度与成本、忽视可靠性（几位「9」）；预测 5 年内全要素生产率（TFP）增长达 3%（该指标从未被任何实验室关注过，与 OpenAI 原始章程口径一致）。
  5. 数据 > 模型 [第一性]：「我们是一家数据实验室」——模型能力 = 数据，全部合成数据 + 高品味人类审校，是做到可靠性几位 9 的关键。
  6. 算力约束 [亲历]：「很长一段时间都会受限于 GPU 算力」，任何性价比更低的方案（如确定性模型推理）都意味同智能消耗更多 GPU；迭代速度会比同行快得多，不承诺长期支持某一版本。
  7. 明确排除的场景 [观点]：反对公开评测（易刷分），只用私有 evals；对「有人用模型做自动交易」表示打鼓 ——「这事儿留给专业人士，非常难、非常高级，就算模型够聪明，有效市场假说也会把优势抹掉」。
  8. 技术生态提及：Cerebras、Groq 类推理加速作为「单位时间智能」的对照物被提及（无持仓含义）。

🔬 第一性原理剖析

  • 核心假设 1：把「决策/程序在环」作为新任务定义，能像 RLHF 当年一样打开新的能力天花板 → 这已被他自己承认是最难的部分（「选对任务、确立北极星」）。
  • 核心假设 2：性价比帕累托前沿是护城河 → 但前沿是不断移动的，且前沿上几乎无差异化定价权；他自己承认「大家把太多注意力放在速度和成本上」，说明「单位美元智能」很快会商品化。
  • 反例/风险：这是他自家的产品访谈，全篇是创始人自我叙事，无第三方评测（他明确拒绝公开评测）→ 外部可验证性极低；「TFP +3%/5 年」是无法证伪的远期断言。
  • 结论：技术信号强（可编程/结构化输出会是 Agent 基础设施的演进方向），投资信号为零。

真正在做 AGI 的人，为什么不相信「两年内实现」

Ruslan Salakhutdinov 谈他眼中 AI 的真实瓶颈：架构早已收敛，模型正在变成商品，唯一被证明有用的机器人还是 Roomba，而麦肯锡应该被取代。

「两年之内，我们到处都会有完全自动驾驶的汽车。」2015 年前后，这是行业共识，媒体开始讨论卡车司机和出租车司机未来两三年怎么办。Ruslan Salakhutdinov 当时正在苹果的秘密自动驾驶项目 Titan 里搭感知系统，他比多数人清楚这套东西走到了哪一步：整个行业用一两年从零做到百分之八十，然后卡了四五年。

人们说 AGI 还有两年，而真正在这些前沿实验室工作的人，我认识很多，他们基本上都在说：我们不会在两年内实现 AGI。

Salakhutdinov 是卡内基梅隆大学教授，Geoffrey Hinton 的学生，AlexNet 出现时他在多伦多。他创办的视觉检测公司被苹果收购，随后在 Titan 项目待了三年；2024 年他加入 Meta 超级智能实验室，两年后又离开，创办了一家做预测的 AI 公司，最近融了五千万美元——要做的是给任何关于未来的问题算出一个校准过的概率。

从零到百分之八十，然后卡住四五年

自动驾驶在 2015、2016 年起飞，几乎和感知技术成熟同时发生。他和几个学生做物体检测，苹果也在搭自己的视觉系统，两边开始合作——传统视觉那套是手工找特征、堆支持向量机，而卷积网络只要规模够大就好得多。公司后来卖给苹果，他在 Titan 做感知系统的早期版本。

「我们在一两年内从零做到了百分之八十。」百分之八十的意思是：坐在车里，系统能检测出大部分车辆、行人和道路，可以据此操控汽车。

然后开始撞边角案例。高速公路前方有个袋子被风卷着飞，模型认不出那是什么，就在路中间猛踩刹车；春末树枝抽出新叶伸进路径，系统判断有障碍物，过不去，尽管那只是一丛灌木；施工锥筒、天气、雪都是同一类麻烦。感知只是一半，另一半是规划：早期的车安全限制太死，并不过高速——人类司机的逻辑是「我就是要走，后面的人必须让开」，守规矩的系统会一直等一个不会出现的空隙。

行业于是停滞了四五年。今天好得多：数据积累、模型持续改进，架构也从纯卷积变成混合系统。Waymo 把激光雷达和摄像头的数据合成精确的三维环境表示，规划器每秒重规划八次，决定变道、加速还是停车；特斯拉走纯视觉路线。他知道特斯拉为什么只能这样——激光雷达又贵又难看，那个在车顶上转来转去的东西没人会买，「我自己就绝不会买一辆顶着激光雷达的车」。

即便到了百分之九十九，生意也没跑通：Waymo 今天还比人开车贵，传感器多、坏了要维护，总有一天会打平。更重要的一课是——你看 Uber，出过一次事故，整个运营就全停了。

二零零五年的第三选择

二十年前，神经网络在学术圈是个笑话：主流是统计机器学习，有理论、有更严谨的数学；神经网络只是「一些非线性系统，人们去优化它，但根本不理解里面在发生什么」，在所有方法里排第三。

他自己差点没走这条路。多伦多读完硕士后，他去银行业待了一年，不确定要不要读博。后来有一次在街上，他撞见 Geoffrey Hinton——读硕士时就是 Hinton 带他。Hinton 说，我有个特别棒的想法，就把他拽进办公室，给他看那些能学习多层表征的模型。他当场问能不能跟着读这个方向的博士，二零零五年开始了。

让他确信这条路有意思的其实是数学。Hinton 是最早证明这些堆叠起来的深层系统真能改进的人之一，那个论证叫变分下界——第一次，这些模型背后有了数学严谨性。他们在 MNIST 上做深度信念网络、深度玻尔兹曼机，证明模型能超越单层——那时候全世界只有一小群人在做这件事。

AlexNet 出来时他已在多伦多任教：三个人，一个相当简单的卷积网络，但被做大了，也是第一批真正用 GPU 规模化的人，结果在 ImageNet 一百万张图像上把此前最好的结果提高了百分之五十。「好得不像真的」，人们花了好几个月验证才承认。他自己更关心生成：今天所有人抱怨幻觉，而当时他们恰恰希望模型能幻觉——能生成训练数据里没有的东西，才说明它有泛化能力。

架构不是秘密，游戏在可验证的领域

在 Meta 训练那种规模的模型，最让他意外的是：所有前沿实验室的架构都跟最初的 Transformer 差不多，只有细微差别。GPT-3、GPT-4 出来时很多人说 OpenAI 是不是搞出了新架构、是不是已经搞定 AGI——「这绝对不是真的。架构是一样的，一切都归结于数据、数据质量和工程基础设施。」

强化学习推理是个亮点，但功劳更多在基础设施和数据。他讲了一个编程的例子，几乎像一场游戏：手里有代码库和单元测试，模型能通过所有测试就给奖励 1，用强化学习强化它做对的事；要造新样本，就手动引入一些微妙的 bug，agent 去找出来修掉，单元测试立刻告诉它修没修好。数学和编程跑得快，正因为它们是可验证领域——有明确答案，答对没答对能自动知道。网页 agent、电脑操作完全不同：同一个问题有很多种解法，部分解也算过关，评估从一开始就模糊。

缩放定律到头了吗？他说不知道，而且以前判断错过：过去也有人说光靠规模走不了多远，结果规模带着大家走了很远。眼下还在延续的是合成数据——用现成模型生成数据，清洗过滤再训练；或者并行做很多次 rollout，看哪次真解决了问题，拿成功的结果去改进系统。

语言之外的富矿在视频、世界模型和具身智能。他有个学生现在是 MIT 教授，在做多感官基础模型——嗅觉，能不能理解闻到的是什么；触觉，能不能不靠视觉判断材质。但行业现在挤在图像和文本上，因为那些能直接变成产品：虚拟试穿那类给零售商做的能力，Nano Banana 出来之后一次 API 调用就替代了。

模型正在变成商品

他相信语言模型最终会变成商品，证据是这套节奏：一个模型公布性能标准之后，几周之内，开源的、闭源的、开放权重的，都能追平它，有时甚至超过。这是纯粹的经济问题：「智能是一回事，效率是另一回事。」

有人告诉他，早期一些团队宁愿用八十亿、九十亿参数的小模型，因为够便宜、够用了；企业的账很好算——百分之九十的效果、百分之十的成本。价格战也演过一遍：OpenAI 公布一个价格，两个月后自己砍掉五分之四，因为有更便宜的模型出现了。他不信智能的边际成本会归零，但信它一路变便宜。

重心于是滑到产品上。Codex 和 Claude Code 之所以好，是因为和你的代码库整合在一起，一旦粘上你就一直用它——「就算别人家的模型稍微好一点也没用，最后拼的是产品。」他自己的学生遇到报错，以前要 Google 好几天，现在直接问它，它就 pip install。

SaaS 也在被同一股力量推着走：Salesforce、ServiceNow、Snowflake 这两年都跌了不少，软件会变得非常便宜。他还给了岗位层面的观察：以前需要十个程序员的地方，现在五个、四个、三个；最抢手的是另一种人——懂模型怎么运作、编程又强，还会在你说「把这个修一下」之后回来告诉你「我觉得你这么做不对，应该换个方式」。

中国的开源，和他最好的学生之一

对中国模型，他的评价很直接：非常好的模型。至于蒸馏，他不知道——「显然 Anthropic 说他们在蒸馏，但我完全不知道。」他知道的是，做 Kimi 的 Moonshot AI，CEO 杨植麟是他在 CMU 带过的学生，「他是我认识的最聪明的人之一」。中国现在有资源、有人才，还把东西全开源了，「这太疯狂了」。

他实验室里的现实可以佐证：所有学生都在用 Qwen、Kimi、DeepSeek 做研究，因为「这些是做研究最好的模型」——开源意味着能看到推理轨迹；GLM 稍贵，但也是做研究和蒸馏的好模型。

他还点出一个很少有人拿出来讲的产业事实：所有知名创业公司都在做后训练，包括 Cursor——他们用 Kimi，比前沿模型便宜得多。而后训练之后「我拥有这个模型」：权重是封闭的，不存在外人担心的信息泄露，那只是权重；只要基础模型的基础知识够好，后训练完就是我自己的东西。

让他意外的是美国这边：Llama 3 是大家真正依赖过的最后一批好开源模型，Llama 4 表现不太好，而 Meta 现在把自己定位得不一样了，他不觉得他们会继续开源。他猜测：如果这些中国公司真在蒸馏美国模型，他们不会在美国做，因为法律原因；在中国，遵守美国法律也许不是首要考虑。

那美国为什么需要自己的开源模型？他的理由不是国家安全，而是偏见和事实来源：数学和编程没有政治或文化偏见；通用知识不一样，任何模型都会被注入一点东西——如果整个业务依赖另一个国家的开源模型，未来把它当成事实来源时，偏差就会渗进来。他也承认自己在偷懒：「我有时候会问 Claude 或者 Gemini 某件事是怎么回事，然后懒得核实，就默认它说的是真的。」

唯一被证明有用的机器人还是 Roomba

说到机器人，他的标准朴素得不留情面。「有人跟我说过，哪些机器人被证明是有用的，那种真的有人在日常生活里用的——现在只有一个例子，就是 Roomba。没有第二个。」他的门槛是：有用到让我愿意花五千美元买它替我干活。消费者层面没有，企业层面也没有——亚马逊仓库里搬东西的机器人全是预设好的流程，装配机器人高度专用；至于特斯拉 Optimus 去组装汽车、替代一百个工人，「就是还没到那一步」。今天真正在做有意义事情的机器人只有自动驾驶汽车。

为什么机器人不像语言模型那样进步？瓶颈是操作能力：能不能替我清理厨房、把洗碗机装满再拿出来、在工厂里做布线，并且可靠地同时做多件事。今天演示的抓取和分拣，流程都被精心设计过，一步接一步。再往上是硬件的账：没有通用硬件，各家只能自己造；造一百万个机器人去采数据，成本高得离谱。而机器人领域根本没有互联网规模的数据——语言模型的数据天然在网上，机器人没有。现在很多公司的尝试是让真人戴上眼镜进工厂替机器人采数据，但没人搞清楚怎么高效利用这些数据。

他把未来分成三块：自我改进的 agent、决策和预测系统、机器人。前两块已经在发生，第三块最需要投资，也最需要时间。

他给学生的毕业概率：百分之十三

他离开 Meta 做的是第二块：一个「预见系统」，把今天所有可得的信息吃进来——结构化的时间序列，比如新闻、财报、失业率——再叠加非结构化的数据，对某个未来事件给出校准过的概率。

例子来自他自己的学生。他问系统：CMU 的博士生 Martin 会在二零二六年十二月前毕业吗？系统先把问题做成一份合约——预测什么、怎么判定结果——然后推理，给出答案：百分之十三。他也意外，于是让系统交出推理：Martin 还没开题；现在是五月，他打算几周后开题；而 CMU 新加了一条规则，从开题到答辩至少要隔十二个月，这时候开题、想六月答辩，成功率会大幅下降。他去问学生，学生说知道这规则。系统接着给出一个决策点：如果 Martin 能在接下来一个月拿到豁免，答辩概率会从百分之十三跳到百分之八十。他于是告诉学生：你要想毕业，最好去申请豁免。

「校准过」的含义他反复强调：如果系统说百分之七十，那么概率为百分之七十的一百件事里，你预期七十件会发生——不是每个判断都准，而是长期来看不系统性偏错。价值也不只在那个数字，而在一串决策点上：哪些事你能影响，哪些不能。

为什么不直接开一个 ChatGPT 的深度研究任务？一是基础模型并非为预测设计：它们被训练来预测下一个 token，处理数值和结构化数据的能力很差，需要后训练才能真正预测结果。二是信源：依赖哪些来源、哪些可信，要有一套自己的把握。他还提到 Grok 能访问 Twitter、别的模型不能，而 Twitter 有时是很好的新闻来源：只靠一个模型，你在发现和检索上永远差一截。所以既是训练问题，也是「harness」问题。

回测一定在骗你

预测最难的地方，是它没法用回测证明自己。「我可以做回测，发一堆论文说我的模型更好，没人会信我。为什么？因为回测永远有信息泄露。」

他们的体育预测就是个例子：特意把数据限制在二零二五年七月之前的来源，找到一篇维基百科文章，写着「截至二零二五年七月」，时间戳是原来的。他们完美预测了结果。实际发生的是：有人改过那篇文章，把比赛结果写了进去，时间戳没变。模型拿到的标注是七月，内容里却有二六年的信息。「我在回测里表现非常好，但这毫无意义。」

同类污染他在 Meta 也见过：模型为某个编程问题生成答案，连代码评审的评论都一起生成了——「嘿 John，我觉得我们应该修一下这部分」；去看测试样例，里面有一模一样的评论。那个样例不知怎么出现在网上，被人抓取、拿去训练，于是模型在测试里表现完美：他们其实是在拿训练数据做测试。

所以验证方式只剩一种：做一个预测，然后等着看它对不对。他因此把预测市场当成最重要的参照——Kalshi 和 Polymarket 的群体预测相当准，「很难打败群体，因为如果你能打败群体，你就能赚钱」，前提是删掉内幕信息。局限也很清楚：它只覆盖人们想要的那几类事——比特币和体育最热——而且只给概率，不告诉你原因。他的野心是把这个范围拉开：「想象一个系统，对任何问题都能做到跟群体一样好，甚至更好」——等于为每一个问题造一个预测市场。他承认这还是个假设，一些最好的学生直接跟他说，这个问题太难，走不通。

麦肯锡卖的是一份保险

在这套逻辑面前，咨询公司是他眼里最该被冲掉的东西。「麦肯锡，麦肯锡为什么存在？波士顿咨询，这些都是大机构，他们全都应该被取代。」理由不是 AI 更会写 PPT，而是预测质量：AI 能处理的信息量远超十个分析师，流程里也许留一个人来协调，但「没有理由不这样」。

他对这门生意的定性更有意思：那是一份保险：如果我是一家公司的 CEO，要做一笔几十亿美元的投资，我雇他们研究、告诉我这是对的事情；如果失败了，我可以对股东说，麦肯锡也说这是好事。「所以那就是他们扮演的角色。但我不觉得他们的预测会更好。」

他没给时间表。但把它放回他的处境就更清楚：他离开 Meta 做的，本质上就是那份报告的核心——一个能给出校准概率、还能追溯推理和决策点的系统。他赌的是两种答案：一边是大机构的权威意见，一边是必须接受未来检验的概率。

五年后重要的技能，不是五年前那些

如果现在还在上大学，他会学什么？答案很保守：STEM 仍然是对的——计算机科学、统计学、AI 和机器学习，还有工程。他知道斯坦福的 CS 人数过去两年下降了约百分之四十，但不担心：CMU 的博士申请过去五年暴涨，「一千二百个人申请，我们录五十个」。他的判断是，维护和改进这些系统只会需要更多计算机科学家——市场上岗位大量空缺，连 Anthropic 都还在招软件工程师和 ML 研究工程师。

他也回应了「别学可验证的东西」这类说法：数学在高中和大学是好训练，但给的往往不是职业方向，而是分析性思维；真去学抽象代数那一类，能用在现实世界的地方有限，最后只有少数极聪明的人会留下。他自己主修计算机科学和数学。至于需求会不会转移，他觉得心理学、社会科学这类需要人际互动的领域可能上升，但不太确定。

他讲了两种人。一种能适应：博士生说工作流程过去一年完全变了，以前写代码要三天，现在一个小时，「我就能真正推进我的事情」。另一种在失去自我认同——「我整个职业生涯都在学怎么当一个好程序员，现在我二十分钟就能做完我学了二十年的东西。」三十几岁、四十几岁的人正处在这场转变里，他觉得这既令人兴奋，也有这一面。

回到开头。他把自动驾驶的故事讲给今天的人听，不是想说 AI 不行，而是想说「两年」这个数字从来不是技术判断——它是一句在外部世界流传的话，说的人不在实验室里。他自己押在相反的方向上：Agent 的时代先来，然后是决策系统，机器人在最后，也最难。

这个时间表对不对，他没打算靠辩论赢。他的原话是：「我确实有很多观点，我一些最优秀的学生基本上在说，我觉得这是个难题，行不通。」毕竟他做的是预测，而预测这件事的好处是——总有一天，谁对谁错不用争。

文末要点

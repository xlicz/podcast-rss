# GUI 是人类认知缺陷的补丁——Agent 元年第 500 天，六件事正在改变软件的底层逻辑

**500 天前，《十字路口》做了一期《Agent 元年》。现在回头看：Manus 发布、Claude Code 诞生、Open Cloud 引爆共识又迅速"过气"——真正在变化的不是概念，而是"软件为谁设计"这个基础假设。**

---

2024 年 1 月 1 日，《十字路口》播客做了一期开年节目叫《Agent 元年》。500 天后，三位嘉宾重新坐在一起复盘——真格基金投资总监天杰、独立开发者"藏师傅"、以及《十字路口》主理人 Koji。

500 天的时间轴很清晰：第 100 天，Manus 发布，Claude Sonnet 3.5 提供了做 Agent Task 的基础。第 300 天，Claude Code 发布。第 400 天，Open Cloud 发布。第 500 天，与 Agent 相关的概念和技术仍然在井喷。

但三个人的判断出现了有趣的分裂：天杰认为模型能力超过预期，但产品化远远低于预期；藏师傅则说"整体都远超预期"——他在 500 天前无法想象自己现在可以维护几十万行代码的项目，也无法想象自己的所有工作流程都可以在 Agent 体系内自动化。

这种分裂本身就是信号：**会写代码的人已经进入了全新的效率范式，但产品形态还没有追上能力。**

## Headless：软件"没头了"

天杰三个月前在真格基金公众号发了一篇文章，标题很有冲击力——"我们或许不应该再投资 GUI 思维的软件"。

核心论点不难理解，但值得逐字引述：

> "GUI 本身是人类认知缺陷的补丁。基于人类注意力机制去优化——人只能同时记住七个并列的信息，到第八个认知负荷就陡增。所以像 Notion、Figma、Slack 这些产品，它们的用户体验是针对人类的认知局限打磨出来的。但当某件事不再需要人类参与的时候，它就不需要为人类的缺陷去服务。"

这不是说 GUI 不重要了。天杰特别强调，当人类自己使用产品时，GUI 依然至关重要——Open Cloud 和 Manus 能出圈，恰恰是因为它们提供了用户熟悉的、像跟人聊天一样的界面。但问题变了：**以前软件是设计给人用的，现在软件越来越多是设计给 Agent 用的。** 而 Agent 不需要按钮、不需要侧边栏、不需要色彩引导注意力——它只需要 API、CLI 和结构化的数据。

藏师傅举了一个自己的例子：他用 FFmpeg 剪视频，全程 CLI，没有界面。"很多 GUI 其实是反人类的，但我们当时没有办法。现在 AI 天生就理解这种复杂性——用户从来关注的不是点哪个按钮，而是'我现在就要这个结果'。"

一个正在发生的信号是消费品牌开始接入 CLI：肯德基、瑞幸、飞书、Gmail、Google Suite、Supabase、MongoDB——这些原本对象是人的公司，都在主动开放能力给 Agent。天杰认为，如果一个公司传递的价值可以通过 Agent 更高效地触达用户，"就应该开放你的 CLI"。

有意思的是，当被问到"最希望谁开放 CLI"时，藏师傅脱口而出："微信。"然后马上又说，"但感觉很难说服张小龙。"Koji 的观察更具体：他发现年轻人在抖音上聊天的频率已经非常高，而内容在哪里，聊天就在哪里。这可能是真正撬动微信的力量——不是 Agent，而是内容消费的迁移。

## Open Cloud 留下了什么

"龙虾"（Open Cloud 的中文花名）已经成了一个不好意思说出口的词——"就跟你在朋友面前说了一个很土的梗"。才 100 多天，热度就过去了。

但三个人都认为它留下的东西是真实的：**共识**。

在一月份，即便是投资圈和创业圈，对 Agent 的认知还是分裂的——Claude Code 和 Manus 几乎被混为一谈。Open Cloud 用最暴力的方式帮所有人完成了认知对齐：Agent 不是在 IDE 里补全代码，而是一个能在你熟悉的聊天界面里独立完成任务的实体。

藏师傅说，Open Cloud 至少证明了两件事：第一，CLI 对大部分用户还是太难用——用户想要一个自己熟悉的界面；第二，它第一次让人感觉"对话的不是一个工具，而是一个人"。

但问题是，安装的摩擦和稳定性问题导致很多人没有动力重新启动它。"这是一个被证明的方向，但还不是一个被解决的产品。"

## Skill 生态：散装的 App Store

藏师傅是当前中文 AI 社区里最活跃的 Skill 创作者之一。他的 PPT Skill 已经有六万 GitHub star。但他坦诚——**向 C 端用户收钱几乎不可能。**"用户已经花了 Token 的钱，为什么还要再给你钱？只有当他真正看到结果、跟其他 Skill 比较之后，才可能反过来觉得值得付费。"

这暴露了 Agent 时代的一个结构性矛盾：Skill 作者创造的价值是真实的——提高了成千上万人的工作效率——但捕获价值的方式还没有出现。天杰认为，从用户体验的角度看，让普通人理解"这个 Skill 和那个 Skill 有什么区别"本身就是过高的认知负担。最终用户信赖的不是 Skill，而是帮他们完成任务的那个 Agent。

藏师傅做了一个关键的区分：**中国还没有一个统治级的 Agent（像 Claude Code 那样），但已经有了统治级的 Skill。** 这些 Skill 安装在各种分散的 Agent 里，装机量客观存在，商业价值也客观存在——只是还没有人找到变现的方式。

天杰观察到的另一个信号是，有影响力的内容创作者开始把自己的知识资产打包成 Skill。比如 Gary Tan 的 Office Hour、Lenny's Podcast 的采访合集——本质上是一种信息平权，用对话形式承载过去需要付费咨询才能获取的内容。

## Token Grant：用 Token 替代天使投资

真格基金和《十字路口》联合发起了一个叫 Token Grant 的项目——给 AI 时代的创业者 5 万人民币的赞助，不占股份。

背后的逻辑是：在今天创业，缺的不一定是钱。"你可以自己写代码，不需要招聘——AI 可以帮你做太多事情了。但不管怎样，用 AI 把一个东西做出来，你都需要 Token。"

藏师傅的 Code Pilot 是受资助的项目之一。它是一个开源的 Agent 框架（GitHub 6000+ star），让用户的 Skill、Memory、CLI 在任何主流模型和框架上都能运行。而另一个受资助项目 UU Agent 更激进——它是一个"赛博数字生命"，从零行代码自主进化到十万行代码，已经运行了 100 多天。

天杰说，Token Grant 本质上是一种从"天使投资"到"支持从零到一"的模式扩展。当 AI 大幅降低了创造的门槛，传统的股权式投资可能不再是唯一的选择。

## 下一个 500 天

被问到未来 500 天最值得关注的问题，藏师傅的回答很实："拥抱变化。有时候你犹豫一两个月，就发现已经来不及了。"

天杰则抛出了一个更大的判断：**下一个抖音未必是别的形态——下一个抖音可能是十倍产能的抖音。** 就像电力让养猪从小作坊变成集约化养猪场，AI 也会让内容生产变成工业化。"也许 video 的形态还是 video，只是生产方式完全不一样了。"

Koji 追问"有什么事 500 天后一定会发生，但今天还没有"，藏师傅说："我觉得有一个 Agent 之间的网络一定会出现——它脱离人类网络存在。让每个人的需求和供给都有足够多的表达，让整个社会在某一类工种的匹配效率上变得更高。"

然后他又补了一句："我说今天的判断都是错的。"天杰接话："希望五百天后回看不会太尴尬。"

这大概就是 Agent 元年第 500 天最诚实的总结：方向是对的，速度是快的，但谁也不知道 500 天后的世界长什么样。

---

**核心判断：**

- GUI 是为人类认知缺陷而生的——当 Agent 成为软件的主要使用者，交互方式从"拖拽点击"变成了 CLI/API
- Open Cloud 虽然已经"过气"，但它完成了最重要的使命：让所有人（投资人、创业者、用户）对 Agent 的认知对齐
- Skill 生态已经出现了统治级的个体产品（装机量 6 万+），但商业模式尚未跟上——这是典型的早期平台信号
- 中国还没有 Claude Code 级别的 Agent 产品，但已经有 Claude Code 级别的 Skill——差异化可能在模型厂商自己的产品中诞生
- 下一个抖音可能不是新形态，而是新产能——AI 让内容生产从手工业进入工业化，但消费端的交互方式不会轻易改变

# Cerebras CEO：CUDA 不是护城河——从 GPU 切过来只需八个键

**这家公司把整片晶圆做成一颗芯片，完成史上最大的半导体 IPO，拿到 OpenAI 的 750 兆瓦订单。Andrew Feldman 谈速度为什么是 AI 的胜负手、卡住全行业的三大瓶颈，和 18 个月里每月烧掉 800 万美元的至暗时刻。**

"慢速搜索的市场有多大？拨号上网的市场有多大？"Andrew Feldman 给出同一个答案——"零。你会等一个网页加载八秒吗？没有人会等。AI 完全一样。"

在他看来，AI 行业正在经历它的"宽带时刻"。他拿 Netflix 打比方：网速慢的年代，Netflix 靠信封寄 DVD；当带宽上来之后，他们并没有把寄 DVD 这件事做得更高效——他们变成了一家电影制片厂。"速度让他们变成了完全不同的东西。"

Feldman 是 Cerebras 的联合创始人兼 CEO。这家公司的产品是一块餐盘大小的芯片——用一整片晶圆直接做成，面积 46,000 平方毫米，是此前史上最大芯片的 55 倍、典型 GPU 的 58 倍。今年 5 月 14 日，Cerebras 登陆纳斯达克，募资 55.5 亿美元，被称为美股历史上规模最大的半导体 IPO。而支撑这一切的判断只有一条：**当 AI 用来做事而不是聊天，速度就是一切。**

"再也不会有人开着笔记本电脑，干等着 Agent 跑完了。"他说多轮循环的 Agent 任务会把等待时间成倍放大，"所以你需要快如闪电的响应——这是 AI 的宽带时刻。"

## 把赌注押在 SRAM 上：18 个月、每月 800 万美元的至暗时刻

Cerebras 的技术选择，源于一个反直觉的观察：**AI 推理不是算力问题，是内存问题。**

做图形处理时，数据搬到 GPU 上、算很久、再送出去，计算占大头；而推理正相反——每生成一个词，都要把整套模型权重从内存搬到计算单元，只做一次计算，然后下一个词再来一遍。"所有权重从头搬一次。这就是 GPU 快不起来的原因。"

所以他们选了 SRAM——快得不可思议，但单位面积存不了多少东西。解决办法只有一个：把芯片做到史无前例地大，"像餐盘那么大"，把 SRAM 塞满。这就是晶圆级芯片的由来。代价是：供电、散热、封装，全都没有现成的供应商——"你造出来的东西跟以往任何东西都不一样。"

Feldman 用登山讲这段历史：第一支登顶珠峰的队伍回到大本营，跟刚失败的队伍喝茶，说"中间那个地方其实不是最难的——因为从来没人越过它，连该怕什么都不知道"。真正的魔鬼是封装：怎么把晶圆固定到主板上、怎么给它供电散热。"我们有过一段 18 个月的时期，每个月烧掉 800 万美元，却造不出来。"直到 2019 年 8 月，他们宣布解决了这个难题。

"我和联合创始人第一次成功的时候，机器就放在一个小小的实验室里。我们五个人站在那里盯着它看，跟看油漆变干一样无聊——但我们不敢相信它真的能工作。"

两年后上市，他们做了一件不太寻常的事：把所有从第一天就跟着的工程师、所有九年里一起走过来的人，还有他们的家人，一起请上台敲钟。"那是一种不一样的骄傲——我们是一起做成这件事的，而且我们居然没死掉。"

## "CUDA 不是护城河"

访谈里最锋利的段落，是关于英伟达的护城河。

Feldman 先讲了一个行业结构：CPU 一家独大的时代结束后，出现了 GPU（英伟达、AMD）、云厂商自研芯片（谷歌 TPU、AWS Trainium、微软 Maia），以及像 Cerebras 这样从零开始只为 AI 设计的晶圆级 ASIC。各种选择都是在"通用与专用"之间做取舍——TPU 做不了图形，但在矩阵乘法上极强。

然后他拆 CUDA："我不认为 CUDA 是护城河。两年前，每个最前沿的模型都在 CUDA 流程里训练；现在 Gemini 不用 CUDA，Anthropic 不用 CUDA，OpenAI 还在用。一两年时间里，英伟达在最前沿训练上的份额丢掉了七成。护城河的故事还在，但数据清楚地表明，它在变窄。"

而推理侧，他认为根本没有护城河：

> "在推理领域没有护城河。把流量从 GPU 切到我们，在云上只需要敲八个键——就八个键。"

最有力的证据反而是英伟达自己给的：去年 12 月，英伟达以约 200 亿美元拿下了快速推理赛道的第二名 Groq 的技术与核心班底——公司史上最大交易。"他们花两百亿美元买行业第二，这个决定本身让所有人看清了：GPU 架构做不了快速推理，而这个市场很大、增长很快。那天对我们是个好日子。"（这笔"授权+挖人"式交易，如今正被美国司法部审视是否刻意绕开了反垄断审查——那是另一个故事。）

Feldman 对自家护城河的表述也很 Kalanick 式："我们的护城河来自一个事实——我们做得到别人做不到的事。这不是多花钱能解决的，也不是用 GPU 多付钱能解决的。想要快，用 GPU 就是做不到。我们试过。"

## 三根卡住全行业的管子

Feldman 把当下算力短缺拆成三根管子，而 Cerebras 恰好都不从它们上面走：

**第一根是 HBM。**几乎所有的 GPU 和 ASIC 都用这种内存，而全球只有三家公司能生产——SK 海力士、三星、美光，"而且他们全卖光了"。扩产唯一办法是建新工厂，以年计。Cerebras 用 SRAM，绕开。

**第二根是台积电的 CoWoS 封装工艺。**把计算芯片和内存芯片放在硅基板上——NVIDIA、AMD 都在用，也卖光了。Cerebras 用自己的封装，绕开。

**第三根是台积电最先进的三纳米产能。**拥堵得厉害。"我们的芯片是五纳米，所以我们不用三纳米。"

"整个生态里到处是瓶颈，"他说，"这感觉不像泡沫。"在他看来，眼下是**所有人追着需求跑**，而不是历史上那种供给跑在前面、等需求慢慢跟上的泡沫结构。"全世界只有很小一部分人在用 AI，我们就已经有点被算力压得喘不过气了。"

他还提到一个新的紧张点：Agent 正在推高 CPU 的需求。"Agent 不只是给你答案，它会采取行动——访问网站、抓取数据、执行下一步。这些动作都由 CPU 完成。做 AI 时，AI 处理器是大脑，CPU 是身体。Agent 任务越多，CPU 需求越爆。"而 CPU 同样面临内存短缺。

## 750 兆瓦：为什么 AI 交易的计价单位变成了电力

Cerebras 与 OpenAI 的合作，是硅谷历史上最大的交易之一——"金额超过 200 亿美元"，而且计量单位不是芯片数量，是电力：**750 兆瓦**。

"数据中心现在的衡量标准就是兆瓦。"Feldman 拆解了这笔多年租约：2026 年先交付 250 兆瓦，2027 年再增加 250 兆瓦，2028 年继续。到那个规模，瓶颈已经不在芯片，而在数据中心本身能不能盖出来、电力能不能到位——这也是为什么 Cerebras 在北欧布局："那里有低成本的电力，不只是清洁能源，就是便宜的电、便宜的冷却。"

他也给出了技术层面的解释，为什么速度在 Agent 和推理时代变得更值钱：推理分两步——预填充（处理你的提示词，可并行）和解码（逐词生成，严格串行，快不了）。"你拿到答案的速度，取决于解码的速度。"而解码就是那个"把一百部高清电影从内存搬到计算单元、只为一个词"的环节——对 700 亿参数的模型，生成一千个词就意味着搬运一千次。"我们把这个环节的速度提高了约 2500 倍。"

商业形态上，Cerebras 既卖硬件也卖云：有数据中心的客户买系统装在自己机房，没有的按月租用他们的集群。收入结构正在变化——去年硬件与云大约五五开，上个季度硬件占到七成；随着 OpenAI 合作推进，"可能会变成三七开：三成本地部署，七成云服务"。跟 AWS 的合作则是一种"解耦"方案：AWS 的 Trainium 做预填充，Cerebras 做解码，直接部署在 AWS 的数据中心里。

## 泡沫、闪崩与称重机

六月初，市场闪崩过一次：1.5 万亿美元市值蒸发，英伟达单日跌掉约 3000 亿——48 小时内修复。"市场对这个概念似乎非常敏感。"主持人问，需求端大量来自拿风投、主权基金输血的实验室，不觉得脆弱吗？

Feldman 的回答分两层。第一层是把短期波动放一边："盯着公开市场天天看涨跌，那你看错地方了。短期是投票机，长期是称重机——我们作为上市公司能做的，是每周都比上周更好。"第二层是他对"泡沫"的定义：历史上泡沫是供给跑到需求前面，像九十年代铺光纤，铺完等六到八年才用上；而今天是反过来的——"我们在拼命扩大供给，去满足已经存在的需求。这不像泡沫。"

## 尾声：你今天用的，会是你用过最差的模型

访谈最后，Feldman 给了一个让在场所有人都愣一下的预测：

> "你今天用的模型——不管是 GPT-5 还是 GPT-6——都会是你用过的最差的模型。你现在觉得它多厉害，六个月后就会觉得它又无聊、又落后。"

他还观察到一件有意思的事：年轻工程师用 AI 的方式和他完全不同，"在这个阶段，你可以向团队里的年轻人学习"。而 SaaS 的冲击已经在发生——有人对着 AI 说"帮我做一个像 Salesforce 一样的工具"，三十秒后得到一个能用的版本；过去要跨五个系统（HR 系统、期权系统、股价数据）才能回答的问题——比如核心人才还留有多少未归属股票——现在一句话就能问出来。

速度打开的东西，往往不是"把今天的事做快一点"——Netflix 没有把 DVD 寄得更快，它变成了另一种公司。Cerebras 赌的就是同一个剧本：当 AI 快到无需等待，人们会开始做今天没人想得到的事。而 Feldman 的态度是乐观的："模型每六个月就让你觉得今天的自己很落伍——这太让人兴奋了。"

---

**文末要点**

- 推理是内存瓶颈，不是算力瓶颈：每生成一个词，整套权重都要搬一次——Cerebras 押注 SRAM + 晶圆级芯片，把这一环提速约 2500 倍。
- 速度是 Agent 时代的产品：多轮任务放大等待，"AI 的宽带时刻"会重演 Netflix 的故事——不是旧事做快，而是新事发生。
- CUDA 护城河在收窄：最前沿训练的英伟达份额两年丢七成；推理切换成本只有"八个键"——英伟达自购 Groq 就是佐证。
- 三大瓶颈（HBM 内存、CoWoS 封装、3nm 产能）全部与 Cerebras 无关；而全行业"追着需求跑"的结构不像泡沫。
- 算力交易的计价单位已从芯片变成电力：OpenAI 与 Cerebras 的 750 兆瓦多年租约，2026 年起分阶段交付。
- 二十五年造过几十款芯片的经验 + 18 个月每月 800 万美元的失败——深科技的护城河，是用"没人到过的关卡"换来的。

OiiOii 创始人闹闹：视频模型还没Ready，做Agent是不是太早了？

副标题：Seedance之后，如何在字节和快手的夹缝里做视频Agent？一个微信+字节背景的产品人的深度思考

在 Seedance 2.0 发布之后，整个视频 AI 赛道进入了一个微妙的节点：基础模型的能力大幅跃升，但同时创业公司的生存空间似乎被进一步压缩。闹闹——OiiOii 的创始人——可能是最适合谈论这个话题的人之一。

她在腾讯（微信）做过产品、在字节做过剪映特效和抖音电商，两次创业。现在做的 OiiOii 是一个视频 Agent 平台：用户可以上传人设、剧本或素材，由多个 AI Agent 协作生成完整视频。

"我觉得是一种妄想"

当卫诗婕问她"海量的视频 Agent 出现到底是需求爆发还是资本催生"时，闹闹的回答非常直接：

"我觉得是一种妄想。大家都以为这里头有利可图，但实际上未必有真的利可图。以前很多中转站会变成所谓的 Agent——包装一个概念好听，但本质上还是个中转站。"

她用了一个残酷的标准来判断什么是真正的 Agent："如果用了这个 Agent，实际上和我直接去用模型端口没有任何区别，那它就是纯套壳。"

她的判断是：市面上正儿八经做视频 Agent 的，"可能两三家"。

数据生态才是真正的壁垒

为什么最好的视频模型来自字节（Seedance）和快手（可灵）？闹闹的答案不是算法，而是数据和生态。

"视频这个领域是一个生态。字节把这个生态先做到了世界最领先的位置。"

这背后有三层：

第一层：趋势预判。 海外的内容热点往往是几年前中国已经火过的。"你要出一个视频模型，一定要有生态的土壤。这就是为什么我觉得很可惜的是 OpenAI——它有 Sora 2，是很好的模型，但它没有把它运营好的生态。"

第二层：数据运用能力。 同样的视频数据，不同模型解读的方式完全不一样。字节和快手在推荐系统里就有大量对视频内容的理解和标注经验。"做视频的这些公司，它是知道怎么去运用这些数据的。"

第三层：数据标注的规模壁垒。 "视频模型就不是创业公司该做的事。它的吞吐量巨大。你光标注数据的人就成千上万。创业公司有那么多人吗？"

这解释了 Seedance 为什么能起来——它背靠的是一个完整的短视频生态和多年积累的视频理解能力。"所有的外包水平无法保证。但在大公司，标准是可以有的——哪怕最开始不准，在实践中会慢慢准确，因为有大量数据来告诉它什么是好和不好。"

视频 Agent 的价值：模型到交付物之间的"最后一公里"

闹闹反复强调一个判断：模型本身和可交付的成品之间，还有巨大的鸿沟。

"哪怕强如 Coding，它也不是一个真正可以交互的东西。模型到可交付物这一层在很多行业里其实还是没有达标的。"

在视频领域，这个问题更突出——因为标准答案不是唯一的。"想象一个小狗走在海滩边，每个人的想象都不一样。很难收敛和约束。"

OiiOii 在做的，就是在这段鸿沟里建立多层能力：

第一层：Prompt Engineering 的系统化。 对模型底层的理解，决定了你知道在什么场景用什么 prompt 组合能降低抽卡率。"我们解决它 60%，它的概率就会低。同样的作品，用其他工具可能要抽卡六七次，用我们可能两次就解决。"

第二层：多 Agent 协作。 拆解视频制作中的七个角色（导演、编剧、美术、分镜、角色设计、配音、后期），每个角色由一个 Agent 承担。用户可以从任何一个环节进入。"你有人设进去，Agent 帮你编故事；你有剧本进去，Agent 帮你做人设。从任何一个制作环节进去都可以。"

第三层：并发生成。 支持同时生成40个镜头，大幅压缩时间成本。"学生赶作业的时候用我们。马上到截止时间了，赶紧先做一个片子出来。"

"现在做确实有点早——但早得好"

闹闹坦诚承认时机的判断：做视频 Agent 现在是早的。"我觉得现在看起来确实是有点早，但我现在不觉得这个早是不好的。"

她的逻辑有两个：

第一，积累无法速成。 "在这个时间段里，到它真的有用、真的能够爆发出实力的时候，我们能够有积累，知道什么东西是好和不好，和别人的差距在哪里。这个是追不上的。"

第二，先发者红利。 "Agent 类的产品只要一多，你就没有太多空间去发声了。哪怕它早了，但至少被人记住了。"

这是典型的"有意识的早进场"——不是盲目乐观，而是清楚地知道时机不完美但必须提前占位。

为什么不怕大厂碾压？

闹闹在大厂（微信+字节）的经历，给了她判断大厂能力的独特视角。

"我觉得大厂能做好的就是基模。应用一定是百花齐放的。大厂一定是多方探索，但对每个方向的资源是分散的。尝试心态代表着选中的人和做这件事的意志没有那么高。"

她举了一个很具体的对比：在字节，几千万 DAU 的产品有很多，但"在字节里头真的有价值吗？它是没有价值的。但一个创业公司几千万 DAU 一定是有价值的。"

所以她的策略是："我没有妄想一定要超过大厂。但我的独立性立在这里——哪怕那么多几万个用户，我能正向 run 起来，那也代表着这家创业公司是不差的。"

文末要点：

  • "海量视频 Agent 是需求爆发还是资本催生？——是一种妄想。"市面上真正做视频 Agent 的可能只有两三家
  • 视频模型的竞争本质是数据生态的竞争。字节和快手的优势不在于算法，而在于短视频生态中多年积累的视频理解能力和数据标注体系
  • Agent 的核心价值不在模型层，在"模型到可交付物"之间的鸿沟——降低抽卡率、拆分工作流、并发生成，三个层级的能力缺一不可
  • "现在做确实有点早——但早得好"：视频模型刚开始能产出"能看"的内容，积累无法速成
  • 大厂的尝试心态 vs 创业公司的聚焦——同样的 DAU 在字节无价值，在创业公司就是立身之本
  • Seedance 2.0 的启示："就是把东西做细。它非常不炫，不科幻，就是老老实实把该做的做了"

# 模型吃掉功能，吃不掉交付

副标题：从 Figma 跌掉 88% 市值、Canva 下调增速指引，到美图半年净利 6.35 亿——多模态战场上，AI 应用公司的两种命运，与一条共同的活路。

---

一张被反复使用的梗图：一辆校车行驶在铁路上，即将被飞驰而来的火车撞飞。移动互联网年代，校车是相机、尺子、天气、相册这些工具应用，火车是 iOS 和安卓的系统更新；AI 年代，校车变成了嫁接在大语言模型之上的应用公司，火车变成了模型本身。

这张梗图从 GPT-4 时代就开始流传，三年过去，讨论的共识迟迟没有形成。直到最近，共识才以另一种方式出现：知名媒体 Xwell 做了一张"2026 年 AI 应用全国统一考试"的试卷，其中一道选择题是——一家 AI 公司的业务包括"自研模型、帮别人训练模型、做 to C 产品"，它算什么公司？超过 60% 的人选了那个被当作吐槽的选项：New Lab——"意义是什么？其他都不是，你可以自己写"。

表面是玩笑，底层是认真：当开源模型能力到了一定程度、最新模型的价格超过阈值、上下文记忆和 Harness loop 变得越来越重要时，无论个人还是企业，似乎都要拥有自己的智能。模型公司、应用公司、开源、自研、魔改后训练——这些界限正在塌缩成一个统一的命题。这也是为什么本文要从 Figma、Canva 讲到美图：多模态战场上的两种命运，恰好能把这个命题讲透。

## 两个"底 bar"：业绩在涨，估值在跌

先看被市场抛弃的案例。Figma 在 2022 年曾与 Adobe 谈并购，开价约 200 亿美金，最终谈崩，Adobe 支付了巨额违约金，Figma 随后自己上市，市值从一两百亿美金一路涨到巅峰近 700 亿。然后叙事反转——"SaaS 已死""AI 将吞噬软件"，Figma 成了被点名批评的代表。今天它回到约 150 亿美金，距巅峰跌超 88%，甚至低于 IPO 发行价。

但纯看基本面，Figma 不差：已经连续三个季度收入同比增长超过 40%，增速还在往上走。收入在涨，市场却不给正向估值。

Canva 的处境类似：巅峰时期老股估值到过 500 亿美金，现在一级市场大约 320 亿；最近把 2026 年营收增速指引从 30% 下调到 20%——考虑到基数，这依然是优秀公司的增速，但指引调整本身透露了信号；原定 2026 年的上市传闻已经推迟到 2027 年，也可能被收购。

反过来，正向的 buff 全部集中在"新"公司身上：视频模型公司在过去半年疯狂拿钱，市场前十名都在融资，阿仕科技已在报港股；视频 Agent 领域，无论国内还是刚拿钱的美国公司，过去一两年 ARR、用户规模、品牌影响力都涨得很快；两家头部视频公司上半年拿了超大额融资，IPO 在望。

于是市场上形成了两个极端的二元暴论：AI native 的新公司优于老公司；模型公司的价值高于应用公司。但事情远没有这么绝对。

## 市场到底在怕什么

为什么同样在增长，估值命运截然不同？拆开看，市场对应用公司的恐惧有四层。

第一，单点功能会被吃掉。抠图、扩图、换背景、修图、模板化，对今天的多模态模型而言都已经是默认能力。凡是"一个功能一个按钮"的东西，都坐在铁轨上。

第二，成本先于收入。AI 应用公司今天毛利最低：模型调用、算力、产品重构、运营成本全部前置发生，真正产生收入在更晚的时间——商业化变现还可能因为竞争被继续推迟。

第三，尝鲜不等于留存。AI 带来的兴奋和焦虑让长线用户暴增，但一次爆款传播不等于重复使用。"一次爆款的生成会带来 Twitter 上的爆帖、抖音上的爆款视频，但很难让用户重复使用"——这在社交陪伴、多模态、所有 AI 板块都如此。

第四，增长不等于兑现。移动互联网年代，成熟应用可以靠网络效应、品牌、杠杆把增长变成现金流和定价权；AI 时代，应用公司至少在这个节点还很难证明 AI 投入能带来利润。

正因为这些恐惧，市场开始谈论另一套黑话：用户数据的沉淀（记忆、上下文）、场景落地、Harness 崛起后的流程控制、交付结果的可控可用、从个体到团队的协作、AI 品牌调性。这些其实是"很早之前就该关注的事"。

## 美图样本：成熟底盘 + 新交付范式

美图是观察这个议题的绝佳样本：刚刚公布季度财报，既有移动互联网年代成熟的美图秀秀、口袋相机底盘——巨大用户规模、强品牌心智、全球分发——又建立了新的 AI 原生产品矩阵，底层还有自研的多模态大模型。

产品形态的变化是最直观的。过去美图秀秀是单点功能：修一张图，一次编辑、一个效果、一个按钮，用户为功能付费。今天美图开始做 Agent、做工作流、做复杂交付：给电商商家的产品可以把一张商品图变成整套店铺装修、买量投放、视频素材；给内容从业者的产品把脚本、人物、场景、成片串成一个流程，"从最开始的源头到最后的交付，全部用一个软件实施"。

从功能走向交付，已经是这个时间点 AI 应用公司默认的产品范式。

一个值得注意的细节是美图新出的修图 App"Pich"，核心功能叫"学他修图"——里面有很多 COS 领域的摄影师和 COS 爱好者上传自己的一套修图方法，行业里管这叫 Skill，但产品里完全没有"Skill 应用商店""MCP"这些概念。"一个小女生想把自己的图修好看，需要知道什么是 Skill 吗？完全没必要。"用户只需要知道：我能得到什么体验，端到端的结果是什么，为什么样的东西付出什么样的成本。

这引出一个判断：今天很多 AI 产品让用户自己选模型，是一条弯路，是"这个时间点的无奈妥协"。"用户不承担这种复杂度——他不需要关心调用哪个模型，只需要关心能不能交付一份能用的东西。"应用要做的事，是把复杂度内化掉。常规的 AI 应用工作流因此是四步：选择模型（按任务场景调用不同的模型工具，这正是路由被强调的原因）、拆解任务（把一个模糊需求拆成脚本、画面、人物、尺寸、格式）、控制结果（保持人物、品牌、模板、风格一致性，同时允许过程中和结果层面的调整）、完成交付（输出一份能发布、能投放、能复用的视觉成果）。

## 数字说话：96% 的自研占比

美图的财报给出了具体答案。2026 年上半年收入 22.1 亿元，同比增长 22.1%；净利润 6.35 亿元，同比增长近 40%。生产力场景（与 AI 关联最深的场景）应用月活 3300 万，同比增长 43.5%；付费订阅用户 235 万，付费率约 8.7%，付费用户增长 29.8%；相关 ARR 6.2 亿元人民币——马上进入"一亿美金 ARR 俱乐部"。传统影像产品收入 17.7 亿，同样在增长：付费用户 1844 万，付费订阅率 6.5%。新产品 MV Land 上线不久，ARR 已突破 50 万美金。

两个数字尤其关键。市场最担心应用公司调用第三方 API 的 Token 成本吃掉毛利——美图第三方 API 调用占收入比重只有个位数百分比。原因是第二个数字：自研模型生成的内容占比达到 96%——用户拿到的交付结果，96% 由美图自己的模型生成，只有约 4% 用了外部模型。"这两个数字对得上。"

这也回应了开头的命题：狭义的应用公司概念已经过时。今天能活的应用公司也要有自己的模型、自己的 benchmark、自己的评估体系、自己的后训练强化学习环境——"牛 Lab 到底是什么"，答案正在这里。

## 第二曲线与四个待答问题

美图的组织结构可以作为模板来读：前端分图像、视频、设计三大品类（设计基于专业场景：电商、追星）；中层是美图 hub 技术中台；再往下是站酷这样的设计社区；最底层是自研的美图奇想大模型。CEO 郭兴仁最近一篇文章的标题是《美图像创业公司一样生存》，第一句话是："成熟的老产品不能给新产品倒流。"

但美图依然要回答四个问题，也是所有 AI 应用公司的共同考题。第一，生产力这个第二曲线是否足够大——现在收入占比约 18%，增速很快，但它会成为主曲线，还是"高增长的小业务"？第二，单位经济：Token 交易的增长不等于利润增长，要追问单位算力的收入成本、Token 定价、渠道分成和毛利。第三，产品孵化结构：产品越多试错机会越多，但人、钱、Token、算力、品牌、研发都会被分散，如何沉淀、少走弯路——任何有成熟业务并尝试 AI 孵化的公司都是同样的挑战。第四，全球化：MO 增长不等于付费与订阅，促销和营销能带来下载量的爆，但真正需要的是高 ARPU 地区用户的留存、续费和持续现金流。

回到最初的议题——模型到底吃不吃应用？答案不是一个二元结论。"模型更多吃掉的是功能；吃不掉的，是在反复场景下的结果交付。这件事模型远远不可能吃掉。"能留下来的公司，是把模型、场景、流程、支付组织成"用户愿意反复购买的结果"的公司。

对已经有成熟业务的公司，解法是"既要又要"——在成熟业务稳定的基础上，把积累的底盘变成孵化新 AI 应用工作流的优势，在中间不断形成正反馈，积累规模，形成第二曲线。"这听起来不可能，但似乎就是这样：动态持续，中间会有波折，但你需要坚持、不犹豫地走下去。"

## 最值得带走的五点

- 市场对 AI 应用公司的恐惧是四层的：单点功能被模型吃掉、成本先于收入、尝鲜不等于留存、增长不等于兑现——Figma 跌 88% 市值仍在涨收入，就是这四层恐惧的具象化。
- 模型吃掉的只是功能，吃不掉"反复场景下的结果交付"；能活下来的公司是把模型、场景、流程、支付组织成用户愿意反复购买的结果的公司。
- 让用户选模型是弯路：应用要把模型调用的复杂度内化掉，四步节奏是选择模型→拆解任务→控制结果→交付。
- 美图财报验证了"应用公司也要有自己的模型"：自研模型生成内容占比 96%，第三方 API 成本占收入仅个位数百分比，是毛利不被 Token 吃掉的关键。
- 成熟公司的出路是"既要又要"：老业务稳定 + 底盘变孵化优势 + 正反馈形成第二曲线；郭兴仁的告诫是"成熟的老产品不能给新产品倒流"。

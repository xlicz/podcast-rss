Kimi K3 背后的架构脉络：注意力谱系、"改良型机器模型"暴论与开源模型的边界

清华博士孙宇涛领读 K3 技术报告：为什么不用 sparse attention、MLA 会不会被淘汰、苏剑林与罗福莉的分歧，以及一个博士生为什么决定转向世界模型。

孙宇涛抛出的第一个判断不是技术，是哲学。他把 Transformer 比作忒修斯之船：2017 年这条船刚下水时，是"attention 加残差"拼起来的；行驶了八九年，部件一块块被换掉——线性注意力、门控、新的连接方式、新的归一化——到今天，这条船和当年的 Transformer 相似度已经很低了。

"你是否还把这个东西叫做 Transformer？"他自问自答："我的判断比较暴论——大模型可能没有本质的上限了，后面都是一些改良性的机器模型。"

注意力美学的三十年谱系

Kimi Delta Attention 是 K3 的招牌架构，但它的公式极其复杂。孙宇涛说，直接读公式会觉得"每一项背后都有一个历史因素"，不把谱系打开根本看不懂为什么长这样。

这条谱系是：最朴素的线性注意力（外积相加，比 ResNet 还简单）→ RetNet 引入与位置相关的衰减项（语言的特性就是近的位置权重大）→ Mamba 把位置无关衰减变成位置相关 → DeltaNet 提高线性注意力的上下文容量 → Gated DeltaNet 融合高容量与衰减 → KV Learner 把标量衰减变成 channel-wise 的细粒度控制，表达能力严格更强。

代价在 kernel：标量衰减一个 tile 只有一个变量，tensor core 上处理极容易；channel-wise 衰减写 kernel 的难度陡增。K3 的解决方案是给衰减加一个 lower bound——在 16-token 的 tile 窗口内限制最大衰减量，保证数值不超出 BF16 精度范围。这在数学上可以证明，也让整个 kernelized 计算路径顺畅。

"每一步都不是凭空来的，"孙宇涛说，"它每一项背后都是历史。"

为什么 K3 不用 sparse attention

这是一个直接回答"为什么三选二"的问题。孙宇涛给的理由相当具体：

第一，硬件现实。DeepSeek V3.2 和 GLM-5 用的 DeepSeek Sparse Attention，在 Blackwell 上 decode 加速极小——求 index 这一步极其昂贵，越先进的 index overhead 越大，甚至跟 full attention 没有显著加速差。GLM 团队为此做了 Index Cache（把求 index 的计算跨层共享），孙宇涛自己的团队做过更极端的方案（index 也全部 one-hot 分摊），结论一致：必须跨层复用 sparse 结果才能吃到收益。

但 K3 的 Hybrid Attention 是 interleave 结构——每层线性注意力和全注意力之间隔着很多层，跨层复用"是否有效、加速比是否够高，相当存疑"。

第二，训练不兼容。Sparse Attention 基本无法 from-scratch 预训练，业界通行做法是 post-train 阶段从全注意力转换。对 K3 来说，留一个接口以后再做是更务实的选择。

MLA 从来不是共识，只是一个选择

K3 沿用了 DeepSeek V2 起家的 MLA，并在其上叠加了千问团队引入的 Gated Attention——后者带来额外计算开销，但大幅提升训练稳定性，这也是"最 buy in 的一个点"。

但 MLA 的未来并不牢靠。孙宇涛转述罗福莉的判断：MLA 本质上就是大号 MQA，并没有带来新的东西，只是一个更好的 trick；它为了达到同样的计算效果需要更多 tensor 计算弥补；在推理阶段计算远大于实际能力，有浪费，而 MTP 恰好能利用这些剩余算力——两者收益"不是正交的，甚至互相冲突"。DeepSeek V4 不再用 MLA，用的是大号 MQA，本质区别不大。

"MLA 从来也不是共识，它只是一个选择。"孙宇涛说。K3 沿用它也是合理的选择——K2 当时 follow DeepSeek 把模型跑出来，K2 到 K3 之间是"能跑的东西不要动"。

Muon 与 outlier 之争：苏剑林一定会反对

K3 在 MLP 中间引入 C2GO——把 SwiGLU 的自由线性投影换成 tanh 门控，用 soft clip 把中间激活严格 bound 住，从数学上控制 activation explosion。孙宇涛点出争议：用 Muon 优化器更容易出 outlier，所以必须从架构上限制。

"如果我这么说，苏剑林一定会反对。"孙宇涛自己补了一句，"他肯定会说，对于任何优化器来说都一定会出现 outlier，因为你从模型架构上是控制不了的。想严格控制，必须直接从模型架构下手。"

这正是 Kimi 在 K2/Moonlight 时代就讨论过的老问题：Muon 下 QK cache 更容易爆炸，Moonlight 用特化的 QK 处理压制 outlier。孙宇涛的判断是：与其纠结优化器细节，不如直接在架构上把中间激活 bound 住——"也不需要去纠结更复杂的优化细节。"

工程取舍的细节，才是前沿模型的分水岭

孙宇涛特意讲了几个"paper 里一笔带过但实际决定成败"的取舍：

WSD 还是 cosine decay？ MiniCPM 的 WSD 把好数据放在 decay 阶段，且支持训练中途自由切换总 token 数。但 Kimi 选了更经典的 cosine decay，理由很实际：WSD 多一个超参（decay 比例），cosine 更容易找到 hyperparameter setting；而且 WSD"任意扩展 token 数"的优势被高估了——最优学习率本身就和 token 数相关。

NoPE 取代 RoPE。 这是孙宇涛最欣赏的设计之一：Hybrid Attention 里线性注意力部分已经引入了位置信息，全注意力部分可以干脆去掉位置编码。RoPE 只对短上下文建模有效，对长文"没有帮助甚至有负面影响"，扩展长度还要调参；NoPE 直接外推，不用调任何参数。他当时看到这篇论文"第二天就去复现了，很 work"，审稿时直接给了 strong accept——"我这几年都没给过几个。"

低精度训练何时引入。 DeepSeek V3 原生 FP8，V4 原生 W4A8；Kimi 反着来：高精度预训练，SFT 阶段再引入低精度 QAT。"从项目管理角度，高精度是更保险的方案——大规模训练出了问题不可控；从技术角度，from-scratch 引入低精度并不会带来能力提升，只要你过了足够多的训练量，结果都差不多。"

Vision encoder 不用现成初始化。 不用 CLIP 这类大规模训练好的 encoder 做初始化，而是 from-scratch 训。收敛慢、多用算力，但最后结果不损失甚至更好，且 norm 分布更稳定、兼容性更好。

infra 的确定性：把工程做到"不需要小道消息"

孙宇涛对 infra 章节的评价是"写得真详细"——这本身是稀缺品。"infra 上的事情本质上没有什么难的，它是高度确定性的东西。你写出来，大家就不需要找小道消息了。"

几个值得单拎出来的方案：

MoEP（动态 EP）。 传统 EP 每个 token 自由选专家，专家负载不均导致执行时间不等、通信多一个阶段。MoEP 的做法是加少量冗余专家，用 online planning 提前规划，从数学上证明只需小比例冗余就能让各卡 token 数完全对齐——"感觉像是一个经典的数据结构与算法问题。"

Linear Attention 的双层 chunk。 线性注意力的 chunk 可以任意拆分（数学上完全等价），所以可以做两层：机器间用大 chunk 并行，机器内 kernel level 再切小 chunk——这是 full attention 做不到的。

Latent MoE 带来通信红利。 K3 用 latent MoE 把 dispatch 通信量降下来后，通信可以被 shared expert 的计算在一个 batch 内部 overlap 掉，不需要 DeepSeek 那种跨 batch 的精细重排。PP 的不对称问题也处理得很轻巧：把 memory 占用大的 PP rank 的激活转存到轻的 rank 上，规避了 DualPipe 的复杂度。

大规模 offload。 K3 把中间结果大量 offload 到 CPU，所有可 offload 的东西用 FP8 存储省一倍内存，满足 CPU-GPU 通信不等式后才能做到计算与通信完全 overlap。

组织的判断：100B 激活的魄力与"不怕杨植麟"

被问到 K3 最 impressive 的地方，孙宇涛的回答不是任何技术："他们把计划搞到 100B 激活，比预期大。这个不依赖任何能力——你具体定多少激活本身不是技术性的东西，看你想达到什么效果。在已有开源模型基础上提升一个数量级，这个决定需要魄力。"

对 Kimi 的"科学方法"，他的解释落到组织："Kimi 是公开里最强调模型内科的团队——让不同行为的 trace 能可靠获取，让不稳定或 collapse 现象能明确归因。不科学是什么？基于利益需求把科学的方式干掉，就是不科学。"

他观察到 Kimi 的一个特征："所有人好像都不怕杨植麟。为什么要怕？有谁有道理谁说了算。它是一个集体的工作，不依赖于个人英雄主义。"

Kimi 与 DeepSeek 的分化，他判断会继续："DeepSeek 更强调性价比，flash 模型做得很好；Kimi 的首要精力是提升开源模型的能力上限，API 也比别人贵很多。技术上的东西不存在太多秘密，好就是好；组织的走向取决于人的选择。"

至于新团队还有没有机会重做一个模型："如果团队足够好、氛围足够好、单兵作战能力足够强，有机会。但这个条件大概率不存在——好的人和好的组织文化有历史局限，leader 的性格决定团队氛围。"

尾声：为什么一个架构研究者转向了世界模型

孙宇涛对未来的判断带着一种清醒的悲观：模型 size 会继续扩大，但"只要大家能定义一个能力，就能达到——AGI 最大的问题就是它没有被定义"。模型不可能无限大——人类互联网能集结的信息量是有限的，从数学上模型没有必要无限。具身智能是更大的 gap，"如果你把 AGI 定义为真实物理世界交互，差距大得多；但如果只在 language model 的 scope 里讨论，问题不大。"

而他本人已经决定转向世界模型。理由很个人："大模型没有太大的改进空间了，没有大的突破就没有 credit。从职业生涯上讲，这不是一个能做出太大贡献的领域了。世界模型问题更大，但至少是一个新的东西。"

一个把 Kimi Delta Attention 的每条脉络都拆开讲透的博士生，用"改良型的机器模型"总结这个行业，然后转身走向一个更大的问题——这大概就是 2026 年架构研究者的真实处境。

要点

  • K3 是架构的集大成而非突破：Kimi Delta Attention 是线性注意力三十年谱系（RetNet→Mamba→DeltaNet→Gated DeltaNet→KV Learner）的收敛点，每一项改动都有历史原因
  • 不用 sparse attention 是硬件判断：Blackwell 上求 index 开销极大、hybrid interleave 结构跨层复用不显然、且 sparse 无法 from-scratch 预训练——三选二时，务实胜出
  • MLA 是选择不是共识：本质是大号 MQA，罗福莉认为其推理计算浪费、与 MTP 收益冲突，DeepSeek V4 已弃用，K3 沿用是因为"能跑的东西不要动"
  • 架构 vs 优化器之争：Muon 更易出 outlier，Kimi 用 C2GO 从架构上 bound 中间激活；苏剑林的观点是任何优化器都会出 outlier，必须从架构下手——两边其实殊途同归
  • 工程取舍定成败：cosine decay 优于 WSD（少一个超参）、NoPE 取代 RoPE（长文外推免调参）、低精度训练放到 SFT 阶段（更保险且无损失）
  • 100B 激活是魄力不是技术：K3 最大的赌注是把开源模型激活量级提升三倍多，这是一个组织决定
  • 新团队的窗口大概率已关：好的人和好的组织文化有历史局限；孙宇涛本人因"大模型改进空间不大"转向世界模型

明年科技公司可能只招 AI 人才了

脉脉 CEO 林凡硅谷归来：AI 人才的三层定义、一小时分水岭，与程序员的下一站

OpenAI 用九个月完成了一次全员 AI 化：从只有程序员在用 Codex，到法务、财务人人上手，平均每个人让 Codex 自主工作的时长达到一个小时。脉脉创始人兼 CEO 林凡把这条时间线带回国内对照——脉脉启动同样的进程比 OpenAI 晚五个月，但他预计，走完全程只要十到十一个月。

带着这份对照，他先抛出一个"暴论"：明年，科技公司基本上只会招 AI 人才。这不是一句狠话，而是一整套具体标准：AI 人才分三层，一个人会不会用 AI，线划在"你的 agent 能不能自主工作超过一个小时"。

九个月，从程序员到全公司

林凡每年去一次美国，这次走了 OpenAI、Anthropic、Google 和 Meta。他此行的一手观察大多来自私下交流，未经公开报道——但足够具体，值得逐条记下。

OpenAI 的内部时间线是他反复引用的样本：最初只有程序员用 Codex，九个月后，法务、财务全部用上，平均每个人让 Codex 工作的时长约为一小时。这件事的本质不是工具推广，而是"生产力的普及过程"。他拿脉脉对照——脉脉启动比 OpenAI 晚约五个月（今年三月对去年十、十一月），内部预计走完全程需要十到十一个月，目前"人人都在用，只差最后一道强制考核"。

他由此给出的行业预测是：两到三年内，无论大公司还是小公司，都会完成这轮切换。快慢取决于一件事——公司有没有把足够多的 context 和数据"打开"给 AI。技术基建扎实的公司快，差的公司会慢很多。

一小时分水岭：AI 人才的三层定义

"AI 人才"在很多 HR 的语境里，指的是做大模型的高精尖。林凡把它拆成三类——

  • AI 技术底座人才：做预训练、后训练、infra 的人。标准很硬——论文、顶级开源项目的重要 contributor、竞赛成绩；
  • AI 应用开发人才：做 agent 的工具、infra、memory、function 的人。看真实案例：你有没有把模型接进业务流程，跑出过结果；
  • AI 业务效能人才：会用 agent 的人。标准只有一个问题：你能不能让你手下的 agent 自主、自动地工作超过一个小时？

他先补了一句直白的话："你如果不太擅长用 AI，就跟今天不会用电脑、不会用手机一样——你是不可能被这家公司需要的。"

为什么是一小时？他说这是"感觉"出来的一个阈值：普通复杂问题，agent 几分钟能想完；调研类任务，二十分钟到三十分钟能完成；翻一倍，就是一小时。"能让 AI 自动干一个小时的活，往往意味着它有一个清晰的目标，并且自己知道这个目标做没做对。"他自己有能跑十个小时、几百个 background task 的案例——秘密在两头：头是架构设计，尾是上百条约束（内部叫 test case）；中间全交给 AI，还要有耐心，别在它第一遍干得傻的时候就忍不住接管。

很多人没有意识到，自己其实是 agent 的阻碍。

他举了一个让全场安静的例子。一位运营同学做 agent 帮销售答疑：销售的问题丢给 agent，agent 给出答案，他看一眼，再贴回给销售，觉得自己用得不错——毕竟他把很多 skill 都交给了 agent。林凡反问他：为什么中间还要有"你"？没有你，agent 能同时服务五百个销售，甚至五千个；有了你，它只能服务一百个。"你把自己变成了 AI 能力的瓶颈。"

能力跳变的引擎：为什么先被攻破的是编程和数学

要理解岗位的重新分类，得先看技术路线上发生了什么。林凡的复盘是：预训练时代卡在数据不够；转折从 o1 和 DeepSeek R1 开始——重心从预训练转向推理的强化学习，再到下半年面向 agent 的强化学习。

"预训练和后训练只能让 AI 达到人类平均水平偏上一点；强化学习可以让它超过人类顶尖水平——因为搜索空间变大，它能泛化出比人更强的能力天花板。"而强化的效果取决于闭环的质量：闭环越短、评价越清晰，跳变越狠。所以他给出了一个残酷的排序——编程、数学这些"人类智力最难的部分"反而最先被攻破。在他看来，去年九月一度被认为追回来的 Google，问题恰恰在于路线还押在预训练上，"对 RL 的投入不够"。

一个数据点：在最前沿的实验室，大约 30% 的训练工作——无论预训练还是后训练——已经交给 AI 做优化，他们预计一年内做到 70%–80%。"这是大家普遍认为模型能力快速提升的核心原因。"

他还提到 OpenAI 的目标变化：去年还在意排行榜，今年已经不 care 了——他们盯着更大的东西：一年之内用 AI 冲击菲尔兹奖，以及可控核聚变、生物医药这类问题。"任何一个领域的突破，带来的社会价值和商业价值，都比替代几个岗位大得多。"

而数据侧的动作也很快：他提到一个案例，Google 花一千万美元收购破产的 Spirit 航空，拿到全部邮件、IM 聊天和薪资数据。"大模型公司拿数据的速度，可能比你想象的快。"

工作的重新分类：短闭环、长闭环、关系型

同一套逻辑，放到岗位上就是三种命运：

  • 短闭环且可验证：AI 自己干。哪怕是数学家，只要结果可验证，同样在射程内。他甚至有一个更激进的判断："这一届 PhD，可能是最后一届人类的 PhD"；
  • 长闭环：一个人带着一群 agent 干。原来是前端、后端、测试、运维、数据分析协作完成一次上线；现在"前端、测试、数据分析很可能回到后端手上"，一个强的人带着 agent 完成全过程；
  • 不可闭环、关系型：最难被替代。销售、需要人与人洞察的工作——"AI 没有 physical 的实体，没有好的跟人的交界面。"

脉脉平台的数据印证了第一波冲击：NLP、后端开发、直播运营、数据仓库、产品经理这些岗位在变少；三类 AI 人才的招聘则集中在 AI 算法工程师、AI 全栈工程师、AI Agent 工程师，非技术侧是 AI 产品经理、AI 运营这些新头衔。AI 人才从 2025 年起以每年同比十倍的速度增长，现在占比已到 30%–40%。"再往前走一步，明年就是八成到九成的公司在招 AI 人才。"

那被挤出来的程序员去哪？他的答案是"外流"。大厂留下最强的一小撮；985/211 的进中厂；其余流向小厂；然后继续向外——到物流、农业、外贸这些"以前绝对请不起程序员"的行业。上一轮（20、21 年）程序员外流只走到新能源、金融科技、高端制造这些高毛利行业；这一次不同，因为程序员带着 coding agent，一个人就是一个团队。

卫诗婕在这里泼了盆冷水：生产力提升不等于消费提升，"今天的问题不在供给侧，在消费侧"，这中间一定会有大量人员动荡。林凡接下话题，抛出他更远的一张图：人力资源会上云。从最早的信息撮合（HR 与候选人），到 AI 匹配，再到"劳动价值的匹配"——工作被碎片化，小时级、天级雇佣，由一个 AI 管理的灵活用工平台派活。"大家都有工作，但不需要去某一家公司工作。"他承认卡点也很实在：企业愿不愿意给数据（"大厂肯定不愿意"），以及最微妙的伦理问题——"如何保证收集的是 facts，而不是 judge。"他提到 Meta 蒸馏员工的例子："做太早，会造成恐慌；做太晚，服务不了市场。timing 很重要。"

内部实验：给每个工种定一条"AI 用好"的标准

林凡在公司推的事近乎激进：所有中高层，一轮一轮过他的 AI 面试（内部叫答辩）。他本人是面试官，标准事先并不存在——"面之前，我也不知道标准是什么。"

  • 研发最好定，因为他自己就是标准；
  • 运营的标准来自上面那个例子：不要让自己成为中间环节，能自动化的都要自动化；
  • 产品经理：不要讲"我生成了一个 demo"，要能用 AI 优化线上的业务指标；
  • 设计：让公司其他人用设计变成自动化过程，"不要来找你"。

这套标准的背景，是一次组织形态的回摆：移动互联网用二十年把工作拆碎、降低门槛；现在要用一到两年"把工种拼回一个人身上"。设计师开始做前端，部门之间快速融合。"人人都是管理者"的实质，是"你能不能让你手下的五到十个 agent 协同工作"——公司里已经有人自己搭框架解决 agent 之间的协作问题，"一年以后，这会变成必备技能"。

四层焦虑，与"判断力"神话

林凡难得地拆了自己焦虑的四层：作为技术人，"我学习的速度，不及它冒名词的速度"——一个 Anthropic 工程师甚至跟他说，AI 术语越来越不像人话，是个 bug：数理逻辑强化之后，语言的表达能力出现了退化。作为 CEO，是组织怎么学会 AI；作为行业（脉脉），是怎么帮 HR 定义和找到三类人才。第四层是终局："二十年后出生即退休"，但"这件事发生之前的十年，会是极其动荡、极其恐慌的十年"。

他还拆了一个流行说法：判断力是 AI 不可替代的。"那是因为它没有你的 context——有了你的 context，它可能判断得比你还准。"他所在的清华计算机系 AI 群（五百人）已经有了共识："今天 AI 的智能，已经超过我们了"——剩下的变量只是 context 还没给出去。

能被轻易蒸馏的，可能不够高价值

企业用 AI"蒸馏"人，林凡看到的是进行时。"例行工作自动化不可怕；每个人要清楚，你的核心工作是把自己能例行化的工作交给 AI，然后不断去探索新的边界。"他给个人的建议三条：掌握 AI 工具并拿出小结果；把作品展示出来（脉脉、GitHub 都行），"中国人太含蓄，不好意思讲——但 AI 时代是年轻人的时代，勇敢讲就好了"；不要被标签限制——C9、985、一本、专科的学历差会越来越不重要，"学习快、能用 AI 产出结果、愿意讲出来"才重要。

能被轻易蒸馏的，可能本质上就不够高价值。

对一家公司如此，对一个人也是。变革时代里最大的红利，大概就藏在这条线两边：一边是被抽走的例行工作，一边是被释放出来的、还没被定义过的新价值。

文末要点

  • OpenAI 用九个月把 Codex 从程序员推给全员，人均自主工作约一小时；脉脉是"晚五个月启动、预计十到十一个月完成"。
  • AI 人才分三层：技术底座、应用开发、业务效能。"能让 agent 自主工作超过一小时"，是业务效能人才的分水岭。
  • 能力跳变的引擎是强化学习：闭环越短、评价越清晰，跳变越快——编程、数学最先被攻破。
  • 替代顺序：短闭环 AI 独干；长闭环一人带一群 agent；关系型工作最安全；不能自闭环的岗位需求会萎缩。
  • 程序员不会消失，会外流：从大厂到中厂、小厂，再到物流、农业、外贸——"一个人就是一个团队"。
  • "判断力不可替代"可能是错觉：AI 缺的只是你的 context。
  • 不要让自己成为 agent 的中间环节——那正是"被轻易蒸馏"的姿势。

🔴 Cookie 过期阻断

EDITED CSV 最新日期 2026-07-25，距今天 2026-07-30 已 5 天，超过 3 天阈值。根据 SOP references/cookie-expiration-cron-blocker.md，cookie 极可能已过期。

阻断原因

强行下载的后果链：

  1. 第 1 页可能成功返回，第 2 页触发 Error 10022（需登录）
  2. 爬虫自动调用 get_cookie.py → EOFError（input() 在 cron 无 stdin）
  3. 进入无限重试循环 → 600s timeout 浪费

所需操作

需在 macOS GUI 环境手动刷新 cookie：

cd ~/Developer/xueqiu-crawler
./venv/bin/python download/get_cookie.py
# 或
python analyze.py --cookie

刷新后 cron 下次执行时自动恢复。

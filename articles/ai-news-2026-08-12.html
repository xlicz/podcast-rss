1. 宇树科技 IPO 战配落地，DeepSeek 战投并联合开发机器人 AI 模型 | 🟢 | [✅事实]

宇树科技（Unitree）IPO 定价 150.8 元/股，估值 600 亿元（约 90 亿美元），获 8288:1 超额认购；战略配售阵容含 DeepSeek（1.41 亿元，锁定期 3 年）、腾讯、社保基金。The Elec 8/11 报道 DeepSeek 与宇树联合开发机器人 AI 模型（"AI Brain for Humanoid Bots"）。投资人认购额达 1180 亿美元（Tech Times）。

  • 验证: ✅ 发行价/估值/战配名单多源一致（财新、华尔街见闻、Reuters、SCMP、Nikkei、CNBC）✅ DeepSeek 战投 1.41 亿元经 TechNode/Reuters 确认；🔴未证实 "联合开发机器人 AI 模型" 具体内容（仅 The Elec 单一来源） — 关注: 具身智能资本定价锚点，梁文锋×王兴兴绑定 3 年
  • 来源: Reuters / SCMP / Nikkei / 财新 / 华尔街见闻 / The Elec

2. Anthropic 未发布 Claude 模型推进黎曼猜想相关数学下界 | 🟢 | [✅事实]

Anthropic 官方博客（8/10）披露 Claude 数学能力进展：未发布模型将黎曼 zeta 函数零点占比下界从 41.6% 提升至 67.2%，打破该领域 37 年数学纪录（此前 1989 年以来的最优界）。TechCrunch 8/11 跟进报道"unreleased Anthropic model made progress on one of math's biggest unsolved problems"。

  • 验证: ✅ Anthropic 官方博客 + TechCrunch/36氪 多源一致；🔴未证实 模型具体代号与是否公开发布 — 关注: 未发布模型能力超预期，前沿推理进展
  • 来源: Anthropic 官方博客 / TechCrunch / 36氪

3. Meta 发布 Muse Code：正式进入 coding agent 战场 | 🟡 | [✅事实]

Meta 推出 Muse Code 终端 coding agent，基于 Muse Spark 1.2 模型，支持大型代码库；定价显著低于 Claude Code / Codex（数据 tier 价差最高 21 倍，Mac 版若同意 Meta 训练数据可再降 20 倍）。The New Stack 8/10 对比称"更便宜，但需权衡数据成本"。

  • 验证: ✅ CNBC/Reuters/TechCrunch/Engadget/Forbes 等 10+ 家独立媒体一致报道；🔴未证实 官方页面直接验证（ai.meta.com 抓取超时）— 关注: Meta 以低价策略搅动 coding agent 定价战
  • 来源: CNBC / Reuters / TechCrunch / Forbes / The Register

4. Manus 恢复独立运营，Meta 20 亿美元收购被中国监管阻止后拆解 | 🟢 | [✅事实]

Manus 官方博客（8/11）确认将恢复独立公司运营：因特定司法辖区监管要求，2025/12/29 后部分用户数据将于 8/23-24 删除，8/11-23 提供免费备份窗口，8/25 起恢复。此前 Meta 以 20 亿美元收购 Manus 的交易被中国监管阻止（CNBC/Reuters/Bloomberg 多源确认）。

  • 验证: ✅ 官方博客一手确认 + CNBC/Reuters/Bloomberg/The Information 10+ 家交叉验证 — 关注: 中国监管否决 Meta 收购中国 AI agent 公司，跨境并购风向标
  • 来源: manus.im 官方博客 / CNBC / Reuters / Bloomberg

5. NVIDIA 发布 Nemotron 3.5 Lightning + NeMo Switchyard 开源路由库 | 🟢 | [✅事实]

NVIDIA 8/11 官方博客发布 Nemotron 3.5 Lightning：30B 参数开源轻量模型，面向多 agent 系统中长时运行的专业子任务；同步开源 NeMo Switchyard 模型路由库，可在自有/专有/NVIDIA 模型间智能分发请求。Wccftech 实测：token 生成加速 4x，但 agentic 端到端任务仅提速 30%（编排是瓶颈）。

  • 验证: ✅ NVIDIA 官方博客一手确认 + HN 159 分热议 + Wccftech 实测数据 — 关注: 开源小模型+路由层是 agent 化部署的下一个效率杠杆
  • 来源: blogs.nvidia.com（官方）/ Wccftech / HN

视频 Agent 泡沫里，一个"非典型"女性创始人的冷思考

副标题：海量的视频 Agent 出现，到底是需求爆发还是资本催生？OiiOii 创始人闹闹的回答是："我觉得是一种妄想。"

闹闹做了一件反共识的事：在所有人都在喊"视频 Agent 井喷"的时候，她说大部分所谓的 Agent 根本就是"模型中转站"，套了个概念就想圈钱。更反共识的是——她自己就是做视频 Agent 的。

过去半年，国内视频 Agent 创业公司如雨后春笋。宣传语一个比一个夸张："一句话生成好莱坞大片""用 AI 超越人类创作"。但闹闹的判断很冷："大家都会宣传是一百分。有的人三四十分，有的人七八十分，但肯定没有一百分。包括我们。"

这不是谦辞，是一个在腾讯微信、字节剪映、B 站动画和大模型公司都待过的产品人，对这个赛道最诚实的判断。

为什么最好的视频模型都出自短视频平台？

一个反直觉的事实：做出最优秀视频生成模型的，不是 YouTube，不是腾讯视频，不是爱奇艺，而是字节和快手。

这不是偶然。

"做过创作和没做过创作，有很大的区别，"闹闹说。短视频平台天然有创作算法的基因——变老人变小孩、一键变漫画、特效 Lab……这些看起来像是"玩具"的功能，背后是大量图形图像算法和创作数据的积累。"现在很好的视频模型的人，之前都是做特效里头的 AI Lab 的。CDS（C-Dance）的主力原来也是做创作的，可灵里头的核心算法团队也是原来 VTech 的人。"

YouTube 在做什么？播放。播放只需要推荐算法。创作才需要 AI 技术——分割、合成、风格迁移、人脸重建。这些短视频平台已经迭代了十年。

"这是一个生态，"闹闹说，"字节把这个生态先做到了业界领先。在海外火的很多热点，都是很多年前中国火过的。这些内容趋势是在一个生态里不断迭代出来的。"

这也是为什么 Open AI 有 Sora 这么好的模型，却没能把它运营好。"很可惜。它真的是一个好模型，很长时间没有竞争对手。但凡它先做 API 不做 App，可能也会好。"

视频 Agent 的本质：一座"模型电路"

很多人以为视频 Agent 就是"调用一个视频模型的 API，包装一下"。闹闹说这是彻底的误解。

"它不是一个视频模型的问题，它是一个电路上所有模型的综合模型的最优解问题。"

具体来说，用户输入一句话"小兔子回家"，Agent 要做的事包括：

  • 剧本拆解：用语言模型把一句话扩展成完整的叙事结构，包括分镜、情节起伏、情绪节奏
  • 角色设定：用图片模型生成角色形象、道具、场景，每个模型的 prompt 规则完全不同
  • 分镜切分：决定什么镜头用什么视角、什么节奏——长剧本和短剧本的切分逻辑完全不同
  • Prompt 优化：针对每个具体模型写定制化的 prompt，一个镜头可能上千字
  • 并发生成和抽卡：同时跑几十个镜头，从中挑选最优的

"今天模型就有几十个，而且你还要不停地 follow 最新的模型。所以必须同时有三个角色：模型产品（搭电路）、效果设计师（视觉评测）、算法（保证稳定性）。"

这才是真正的 Agent——不是调一个接口，是搭一座电路。而且这座电路必须不断重搭，因为底层模型在快速迭代。Sora Two 出来，之前基于首尾帧的路线就要全部淘汰。C-Dance 出来，所有 prompt 规则又要重新调。

"做 Agent 类产品，距离模型第一次出现越久，你的积累就越有价值。你知道什么好什么不好，知道跟别人差距在哪。但如果你等模型完全成熟再下场，早就没有空间了。"

"海量 Agent 出现，是一种妄想"

这句话是整场访谈中闹闹最尖锐的判断。

她的逻辑很朴素：很多人觉得这个赛道有利可图，就挤进来了。"有各种牛鬼蛇神，说一分钱也不收，免费用 C-Dance 这种方式来骗钱。实际上挂的根本不是 C-Dance，圈一波钱就走了。"

还有一种更隐蔽的"伪 Agent"——本质上是模型中转站，套一个 Agent 的概念。"包装一个概念，听起来好听。但本质上还是个中转站。Agent 现在变成了一个热点标题。"

闹闹说，目前市面上正儿八经做视频 Agent 的"可能就两三家"。为什么这么少？"因为它真的很难。"

难在什么地方？不是技术难度——多模模型大家都能调。难的是一层叫"审美"的东西，一层叫"把审美翻译成机器能理解的语言"的东西。

"在内容创作领域，标准答案不是唯一的。小兔子在海滩上走，每个人的想象都不一样。这才是 Agent 真正难的地方——你要在一个没有唯一正确答案的领域里，去收敛、去约束、去逼近一个'相对好'的结果。"

模型越强，Agent 越有价值——前提是你别躺在大厂的车辙上

投资人最常问的问题：底层模型持续进化，会不会把应用层全部吃掉？

闹闹的回答出人意料地冷静："如果这个推演是对的，那我们就不做了。我们不会强硬地去证明自己有价值。如果真的没有价值，就承认，就不做。"

但她同时认为，至少在视频领域，模型吃掉 Agent 的可能性"大概只有百分之二十"。

原因有二。第一，大厂做应用有天然劣势。"大厂是多个团队并发，每个项目资源分散，而且是尝试心态。尝试心态代表他选中的人和做这件事的意志没有那么高。可能对于创业公司有价值的规模，对于大厂来说没有价值。"

第二，视频模型的"交付物"不是一行代码或一个法律文件——它是一段有信息量的、有人愿意看的视频。模型可以做出来东西，但做出来的是否"可消费"？"哪怕是 coding 这么强的领域，模型也不是一个真正可以交付的东西。视频比 coding 还多一个维度。"

那么模型层的竞争会不会碾压 Agent 层？闹闹的比喻很精妙："做 Agent 的团队就像一个餐馆，做模型的就像食材的批发商。食材再好，做成一道菜的还是厨师。"

厨师的优势在哪？"对食材的把控、选择，还有调味。"在 AI 时代，这些都对应着 Agent 层的 prompt 工程、模型路由、效果评测、风格调校。

"而且我们不需要跟任何大厂的利益绑定。哪个模型在这个场景下最好，我们就用哪个——除非它不让中国人用。"

模型涨价怎么办？

这是一个正在发生的现实问题。C-Dance 二点零出来后，推理成本大幅上升。OiiOii 不得不从免费转向收费，用户结构也从 UGC 为主变成了 PGC/Pro 为主。

"这会为一个工具花钱的，还得是从这件事能获得收入的准专业用户。"闹闹承认这让她"有点小小的失落"——那些有创意但不愿意付费的普通用户流失了。

但她对模型持续涨价持怀疑态度。"如果涨价会让更多人赚不到钱，那它是不可持续的。字节是一个精明的公司——如果能涨且不伤害绝大部分利益，它一定会涨。它不涨，就代表这可能已经是一个最优解了。"

更深一层：视频模型目前还远没有到"真正好用的状态"。用闹闹的话说，"AI 产品在 C 端不好跑的一个很大原因是推理成本巨高"。以前拍视频的成本是一次性的——买个相机几千块，可以反复用。AI 生成的成本是无限的——每生成一次付一次钱。

"这是一个无底洞。而且你在这个投入范围内，不能保证自己一定能出一个爆款。这真的是在赌。"

AI 时代的产品经理：谦逊比才华更稀缺

访谈进行到后半段，话题从行业判断转向了人。主持人问她："你觉得移动互联网时代，你是最顶级的产品经理吗？"

"我觉得不是。我是一个学徒。"

这不是客套。闹闹在采访中多次表现出一种近乎"反创业叙事"的克制：她不谈"改变世界"，不谈"重新定义"，不谈"顶级"。问她怎么定义自己的目标，她说"我只想做出来一个让大家还比较 respect 的产品就可以了"。

问她 AI 时代顶级产品经理需要什么能力，她的回答是：对新的知识保持好奇，敢于挑战新的东西，有审美的标准，能把审美翻译成机器可理解的语言——然后加了一个在创业圈几乎"反直觉"的品质："谦逊。"

"谦逊代表着你能学习。你能够看到别人的好，也能够看到自己的不足。如果你缺乏这个东西，你会觉得自己完全没有错，或者自己就是最好的。那不是自信，它可能导致出来的东西是一个盲目。"

"承认自己的不足反而是一种勇气。因为我不怕袒露出来自己的错误。这其实是一种非常自信的表现。"

一个在腾讯微信看过张小龙八小时内部演讲的产品人，在字节经历过数据驱动最极致的公司，又在大模型公司亲眼目睹了"从零到一"的艰难——她说自己是"学徒"，未必只是谦虚，更可能是一种方法论上的自觉：在 AI 时代，知道自己不知道什么，比知道自己知道什么更重要。

长期主义，但要先活下来

闹闹对 AI 产品的终极想象出人意料地"极端"——比她说过的任何话都更理想主义。

"我觉得最好的一个状态是，它不是手机，也不是眼镜。它是一个内容在里头真正产生交互的东西，有点像模拟一个世界。它的视听语言是通过神经在传导的——只要在大脑里产生一些刺激信号。因为人所有的五官感知都是这些信号产生的。你能干扰到这些信号，才比较本质。"

"这不就是真正意义上的元宇宙？"主持人问。

"对，可能吧。"

但她随即把自己拉回地面："我现在能做的就是，在这个时间段里，当视频模型真的爆发出来的时候，我们有积累，知道什么东西是好和不好。"

她对创业公司的定位很清醒——不是要跟大厂正面竞争，而是找到自己的独立性。"我没有那么大的妄想，一定要超过大厂。但我的独立性立在这里，一定有独立的用户人群可以 run 起来。哪怕只有几万个用户，能正向 run 起来，就代表这只创业公司是不差的。"

这种"克制中藏着野心，务实中透着理想"的特质，或许恰恰是视频 Agent 赛道最稀缺的东西。在一个人人都在喊"我们将用 AI 重新定义视频创作"的时代，一个会说"这是一场妄想"、会说"我可能会判断错"、会说"如果模型真的吃掉 Agent 那我就不做了"的创始人，反而让人更愿意相信她能走得更远。

📌 核心要点

  • 最好的视频模型来自短视频平台，不是传统的影视/播放平台。因为创作算法（特效、编辑、风格迁移）是视频模型的前身——这是字节和快手积累了十年的能力
  • 视频 Agent 不是"调一个 API"，而是协调几十个模型、三个角色（产品/效果/算法）、层层优化 prompt 和路由的复杂"电路"——大厂有资源但缺意志，创业公司可以做得更深
  • 市面上绝大多数"视频 Agent"是伪概念——要么是模型中转站套壳，要么是 API 包装器。真正在做这件事的可能只有两三家
  • 模型不会吃掉 Agent，因为视频创作是一个"没有唯一正确答案"的领域。模型越强，越需要 Agent 来收敛、约束、优化——就像好食材更需要好厨师
  • 模型涨价是约束，但不是终点。如果涨价导致生态不可持续，精明的平台会选择降价。Agent 公司的机会在 Pro/B 端——那些能从创作中获得收入的人
  • AI 时代最稀缺的产品经理品质是谦逊——愿意承认自己不知道，才能持续学习。盲目自信在技术剧烈迭代的时代反而是负资产

# 最好的延迟，就是没有延迟

**当 AI Agent 开始一次运行数小时甚至数天，推理市场的北极星指标从"快"变成了"便宜"——Neil Movva 把整家公司押在这个判断上**

"当你早上醒来的时候，工作已经在夜里完成了。"Neil Movva 描述他理想中的 AI Agent 使用方式时，用的不是"更快"这个词，而是"不用等"。

他是这家推理公司的创始人。公司做的事情听起来简单：提供一个 API，任何人都能向它发送请求，用开源大模型处理任务，然后以市场上极具优势的价格拿到 token。他还托管一种叫 cell box 的云上虚拟机，专为运行数小时、数天甚至数周的 Agent 设计。他把公司主题定为"充裕"——把智能这种全新商品，以几乎所有行业都能承受的成本交付出去。

在这场对话里，他给出了一个和主流叙事反着来的判断：低延迟不是 Agent 的未来，长周期任务才是；而支撑这个未来的，是一整套关于芯片、电力和软件套利的生意逻辑。

## 延迟退场：Agent 不是搜索引擎，是同事

过去几年，整个推理市场被一个方向牢牢拽住：低延迟。Base、Fireworks、Together 这些模型服务商全都围绕"每秒吐多少 token"做优化，而它们是被一个重要客户群拉向那个方向的——Cursor 这类实时编码工具。对交互式编程来说，快确实是第一诉求。

但从大约半年前开始，Movva 观察到情况在变：低延迟可能不是 Agent 的唯一诉求了。你开始想要持久性，想要长周期任务——让机器一次运行好几个小时甚至好几天。

"它是不是以每秒一百个 token 的速度吐字，其实并不重要，只要能带来相应的效率优势，也许十个 token 就完全够了。"

他的核心论点是：只要你在等待 Agent 回复，你就成了它做多少工作的瓶颈。你不会每隔五分钟就去管一次你的同事，你让他们去完成一个宏观任务，然后每天、甚至每周回来跟进一次。人与 Agent 融合的未来，是"更接近人类的时间尺度"。

这个判断的底气来自测试时计算扩展——给 Agent 更多时间，它就给你更好的答案。这个概念大约两年前在理论上被提出，直到 OpenAI o4.5 出现才真正值得关注：它是第一个稍微能胜任长周期任务的模型，刚出来时还挺平庸，但更新的模型加上开源生态的进展，如今 Agent 已经能一次运行一小时。"不需要几个数据点，你就能画出指数曲线。"

## 便宜十倍，就是一个新品类

Movva 把公司的北极星指标说得很直白：在行业里拥有遥遥领先的最低单 token 成本。

他不认为 token 是工作或智能的最终度量单位，但它是眼下唯一可用的度量。而且趋势正在强化这个指标的意义：未来会越来越多地让 Agent 去完成某个单位的工作，让它尽可能多地去尝试——Agent 自己管理 token 预算，而不是公司给工程师每月分配 token 额度。消耗多少 token 变成因变量，取决于任务本身。

为什么这个位置有机会？两个顺风因素。第一是开源的兴起：越来越多的客户关心"拥有智能的所有权"——始终拥有权重、始终有权随心所欲部署模型，这种主权需求催生了定制模型的稳固市场。第二是现有服务商的结构性盲区：它们被低延迟客户群锁定，而长周期任务市场刚露出头。

"只要你把某样东西便宜十倍，它就会成为一个全新的产品品类。"他说，机器能够思考是一件影响极其深远的事，现在的任务就是让世界上尽可能多的机器为思考而运转。

## 榨干芯片：真正的瓶颈是功耗，不是软件

一个反常识的细节：当 GPU 做它最擅长的事——大维度矩阵乘法时，性能优化其实已经很高了，"哪种运算能跑到峰值利用率的百分之七十、八十"，限制它的不是软件，而是功耗。峰值 FLOPS 的数字过于乐观，因为功耗墙会强制降频，你根本跑不到那个数。

所以这家公司的活法，是"围绕芯片搭建引擎，让 GPU 随时都能吃上大批次任务"。

这涉及算子工程——GPU 上运行的任何程序的通称。传统上算子被放进库里，每个算子有明确用途：矩阵乘法一个、张量加法一个。现在越来越流行的是算子融合：做完一次矩阵乘法紧接着做加法，直接在片上完成，不把数据写回 DRAM 再读回来。有趣的是，主持人问了一个直击要害的问题：为什么算子工程还是人类在做？这难道不是 AI 擅长的事吗？

Movva 的回答带着一种正在发生的转变感："我们是在白板上写算子——走到白板前，用自然语言向模型描述我们认为机器应该做什么，输入输出是什么、如何调度到 GPU 上，然后由模型去实现。"他不认为算子工程是护城河："我相信六个月后就会有在算子工程上好得多的模型。"

另一层变化是编程的单位。过去一年 GPU 领域最深刻的转变之一，是不再针对单张 GPU 编程，而是考虑整机架、整个机群、整个数据中心。英伟达开始交付整套机架系统——GB300 按七十二台一组的整机架出货（NVL72），大家都在公开竞争，看谁能最高效地对整机架规模的计算机编程。

## 没有坏的芯片，只有不合理的价格

Movva 有一个贯穿全场的捡漏哲学："没有坏的芯片，AMD 只有不合理的价格。只要价格合适，任何芯片我都能让它发挥作用。"

AMD 的芯片在他看来整体非常棒，难点在于大家不太清楚怎么给它们编程。英伟达在自家芯片上把开箱即用的算子做得很好，你能挤出一些超额收益；但在其他芯片上，"能做的事要多得多"——更妙的是，别人还抱着 AMD 不如英伟达的看法，这种低估"对我来说简直是天籁之音，我非常乐意看到他们看清这款芯片，而我自己能买多少就买多少"。

不过他承认局面在变化：AMD 在大买家中间其实挺受欢迎，Meta 和 OpenAI 都买了一大堆 AMD 芯片，AMD 的供应也快被分完了。至于新兴芯片公司，他们的主要挑战是规模——能不能从台积电拿到足够的晶圆配额，大量造出芯片推向市场。他对待新芯片的态度很主动："如果市面上有新芯片，我想尽快了解，评估一下我们能不能买下其中很大一部分供应。"

这本质上是一门套利生意：更擅长从那些不受关注的芯片里榨出性能，带着利润转售出去。他自称团队在"利用多种芯片架构、在别人想不到的地方挖掘性能"方面大概是全球顶尖之一，而且没有历史包袱，愿意多快围绕一款新芯片搭起技术栈都可以。

## 英伟达的政治经济学

谈到最顶级芯片市场，Movva 没有回避那个流传的比喻："现在就像毒品市场一样，为了尽可能多搞到一些芯片，各种离奇的事情都在发生。"

他讲了英伟达的两个深层逻辑。其一，英伟达明白算力在今天就是权利：如果只让财力最雄厚的买家买走所有芯片，那个客户最终积聚过多权力，长远会损害英伟达自己，所以他们在分配算力时相当讲究策略。其二，人脉和关系极其重要——一家才成立几个月的初创公司说要租一万张 Blackwell、租期三到五年，谁都得掂量它付不付得起钱。

那么，英伟达为什么不干脆一路做到底，自己去卖 token？Movva 的看法是：英伟达非常聪明，不跟自己的客户竞争。"Jensen 特别擅长让身边的朋友变成亿万富翁——他把 CoreWeave 做成一家十亿美元、几十亿美元的公司。他完全没有必要去破坏这种善意。"他要的是一个由云厂商和推理提供商组成的多元生态，大家都争先恐后为英伟达创造需求；就算其中某一家决定垂直整合或转向其他选择，他手头还有另外三家抢着补位。"让买家之间形成竞争是件大好事。"

## 四个瓶颈，和一句给创业者的忠告

如果房间里有一百位创业者都想创办算力公司，Movva 的建议只有一个方向：理解供应链的瓶颈，然后做套利。

他列出的瓶颈非常具体：台积电的晶圆产能、HBM 产能、先进封装——第四个是电力。你得对这四个瓶颈以及你打算怎么绕开它们有非常好的答案，"因为归根结底大家都是在做套利。你之所以做芯片，是因为你觉得英伟达做了一些他们自己很难改变的选择"。

英伟达并不完美，只是各方面平衡得非常好。你要做的是"有突出的棱角"——选定一个点，判断他们低估了某个方向的未来，然后猛攻。他点出的候选是 HBM：想要大幅增加存储芯片的晶圆厂，并没有什么容易的办法，存储行业不喜欢为周期性业务投入巨额资本开支，他们吃过很多亏。而短缺的代价会传导到整个系统——"iPhone 会缩减内存配置，iPhone 的售价也会跟着涨上去，大家只能硬着头皮接受"。

这场对话的收尾比生意更柔软。被问到"别人为你做过的最善良的一件事"，Movva 讲了他的导师们：大二时他是个特别急躁的学生，跑到教授的答疑时间说"我想造 AI 芯片，干嘛要把时间浪费在计算机、网络和操作系统这些基础课上"。教授把整个技术栈摊开给他看，告诉他：极少有人能真正搞懂从门级芯片一直到超大规模互联网服务的完整技术栈，你应该立志成为那种在一生中达到这种理解深度的人——"这种深度的专业能力是非常高尚的追求"。

这段话放在一家赌"智能充裕"的公司的故事里，恰好是完整的注脚：当机器开始批量思考，真正稀缺的从来不是某一个算子或某一块芯片，而是对整条链路——从硅到电、从算子到 Agent——的完整理解。

## 要点

- Agent 的未来是长周期任务：数小时、数天、数周的后台运行，让"低延迟"让位于"低成本"；最好的延迟是完全没有延迟
- 北极星指标是单 token 成本行业最低——便宜十倍就会诞生一个全新品类
- GPU 性能的真正瓶颈是功耗墙而非软件，批量任务编排和算子融合才是榨取空间；算子工程正在被自然语言编程取代，不是护城河
- 捡漏式套利：AMD 被系统性低估（Meta、OpenAI 已在大量采购），新芯片公司的生死线是台积电晶圆配额
- 英伟达不卖 token 是战略选择：不跟客户竞争、让买家互相竞争，算力分配本身就是政治
- 算力创业的本质是识别四个瓶颈（晶圆/HBM/先进封装/电力）并选一个英伟达难以转身的点猛攻

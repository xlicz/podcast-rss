[⭐⭐⭐] a16z — Aaron Levie on Why Open AI Wins

发布时间: 2026-09-05 | 时长: 00:31:05 | 链接: https://a16z.simplecast.com/episodes/aaron-levie-on-why-open-ai-wins-YUnuv_hR

背景: 同系列（mts）8/29 剧集为 Redwood Research 的 Ryan Greenblatt 谈 1200 AI agents 攻击 HuggingFace 事件；本集新闻钩子为 Jensen Huang 的 open-weights 公开信，Box 联创/CEO Aaron Levie 谈开源权重经济。

🧠 嘉宾主张（结论）

  1. Open-weight 与 closed-weight 不是零和：开源模型增加使用场景、倒逼闭源厂商加速，整个生态受益者更多。
  2. 蒸馏（distillation）不该被当作"窃取"：模型用公开互联网训练与用另一模型输出训练的伦理边界站不住；封禁中国只会加速其自建硬件栈并催化其生态被世界采用。
  3. AI 的钱在 inference：token 成本长期收敛到基础设施成本 + 20-40% 毛利（不是 70-90%）；开源与否长期看是 wash，钱最终流向算力基础设施提供方。
  4. 闭源前沿实验室（OpenAI/Anthropic）仍拿走绝大多数利润；但多模型世界下，模型路由层（applied layer：Cognition/Factory/Cursor/Replit 等）价值持续上升。

📊 支撑论据

  1. Anthropic 因蒸馏 API 调用赚到的钱比当年原始训练 run 还多 — [行业观察/推理]
  2. 中国断供场景推演：中国视 AI 为战略必争，拥有人才+芯片工业+数据生成手段（10万人造数据），封锁无法阻止训练，只会让训练发生在不同硬件栈上并部署进主权云 — [推理]
  3. K3 等中国模型发布显示中美差距在收窄而非扩大 — [行业观察]
  4. Box 内部评测 Opus 5（约2周）：相较 Opus 4.8 在知识工作两大轴（行业深度理解 + 通用工具/长文档处理）均有实质提升；"闭源实验室几乎在所有情景下仍拿走大部分利润" — [亲身经历]
  5. Box 因 AI 启动了数十个此前不会做的项目，"多年期项目不再是多年期"，反而在扩招工程师 — [亲身经历]
  6. 美国模型玩家约5家（SpaceX/xAI、Google、Anthropic、OpenAI、Meta）同时在压成本与推前沿 → 企业侧的"选择瘫痪"由路由层解决 — [行业观察]

🔗 论证过程 开源权重增加使用场景 → 使用场景增多 → 生态扩大、闭源也被推快（非零和） → 蒸馏伦理论不成立（训练数据边界本就模糊）→ 政策重点是"美国自己也该做开源"而非封中国 → 推论：token 价格收敛到 infra 成本+20-40% → 无论开源闭源，利润在 inference/infra 层 → 因此 OpenAI/Anthropic 也应对前代模型做 fast-follow 开源以圈住生态内的 inference → Box 作为 applied 层直接受益于多模型路由趋势 → 软件工程扩招不缩编

[⭐⭐⭐] 高能量 — Vol.233 媒体、社区与投资：与张鹏聊极客公园的发展史和宇树投资往事

背景: 极客公园创始人张鹏（媒体老兵，2017 乌镇组织雷军看王兴兴机器狗）与主播对谈。极客公园第一期基金（2017-18）约第2/3个项目即投宇树（ASR:"语数/王星星/王兴/王云兴"均为王兴兴）。历史对照：晚点聊 6/11 #168 美团龙珠王新宇也详述过投宇树的决策（2023底走访斯坦福/MIT/伯克利发现全在用宇树机器狗）——不同出资方视角互补。

🧠 嘉宾主张（结论）

  1. 创投时代由"技术变量+环境"共振驱动：移动互联网的"连接性红利"2018 左右拉满，之后是算不清账的 O2O/物理世界（"阻力衰减到七"）；2019-2022 的"布朗运动"期反而是小基金的非共识窗口。
  2. DeepSeek 2023 是分水岭：此前 AI 公司被要求"幼儿园就扛活"（项目制交付撑估值）毁掉成长性；此后投资界统一思想"把模型做好就是一切"。
  3. 今天创业者的正确姿势是"做提上限（挑战天花板）的事"，这才是撑住最高估值的最高效率路径；但未来2年+，已上市的具身公司/模型公司（宇树、智谱等）与美国 Anthropic/OpenAI 都会面临"交付结果"的现实检验——"融资本质上是面向未来借钱，终须创造价值还回去"。
  4. 泡沫必然且必要（创新是涌现，需要浪费基数），关键是创业者"怎么用这个泡沫"；对二级市场超级共识要谨慎，机会在共识之下的非共识细节。

📊 支撑论据

  1. 极客公园一期基金全部非共识项目（无明星创业者）：硬科技（今天没有但未来会被需要的）+ 中国出海生态服务 — [亲身经历]

  3. 技术判断：液压路线必败于电驱；力控算法从"一行行手写代码"变为可用数学系统训练（约2015-16）→ 机器人走向通用性的可能 — [行业观察/推理]
  4. 松果出行翟光龙案例：共享单车算不过账退出城市→县城电单车"算得过账"→最丧气几年成长最好（环境决定考验创业者的核心要点不同）— [行业观察]

  7. 一级定价被二级"超级共识对标"绑架（"你能做它的三分之一"）→ 爬坡项目需要"累进确定性"而非一把梭；地平线于凯（2020募巨资+预判芯片洗牌）是"驾驭别人误解"的正例 — [行业观察]

🔗 论证过程 连接性红利拉满 → 数字世界低阻力机会填满 → 资本转向高阻力物理世界但"算不过账" → 小基金只能投非共识硬科技/出海 → 2015-16 力控算法数学化 + 电驱成熟 = 机器人通用性的技术窗口 → 宇树式"手搓"创业者在这个窗口涌现（非低概率） → DeepSeek 2023 统一"模型优先"共识 → 优秀创业者不必再被变现过早稀释 → "提上限"成最高估值路径 → 但泡沫必然 → 关键在创业者用泡沫的方式 + 累积确定性 → 二级超级共识处反而要谨慎

如果 vLLM 失败，我们会后悔一辈子

一个清华特奖得主，为什么花了三年时间从算法研究拐向系统工程，又为什么赌上一切相信开源

导语

游凯超说过一句话，让整个伯克利 Sky Lab 的创业团队沉默了好几天："你如果不跟我们一起创业，你赚到了很多钱。但十年之后，vLLM 项目失败了，你是开心还是不开心？"

这句话是问给 Woosuk Kwon 的——vLLM 的第一行代码是他写的，核心架构是他设计的。当时 Woosuk 已经拿到了大厂的 offer，犹豫要不要加入这个"从开源社区变成公司"的冒险。游凯超和周汉（Zhuohan Li）等了他几个月。最后，Woosuk 回来了。

2026 年初，Infraact（vLLM 背后的公司）宣布了 1.5 亿美元种子轮融资。这个从伯克利校园开源项目演化而来的推理引擎，如今被 Red Hat 打包进企业 Linux 发行版，被称作"AI 推理领域的 Linux"。游凯超说这话时毫不谦虚——"我觉得我们已经可以这样说了。"

但这个故事真正值得写的地方，不是 1.5 亿，也不是"下一个 Linux"。而是游凯超这个人——一个清华特奖得主，花了将近三年时间，从一个算法研究者，把自己"重装系统"成一个系统工程人。他放弃发论文、放弃学术界那条更体面的路，因为他看到了一个比算法更深的结构性变化：在后摩尔定律时代，能活下来的算法，不是最优雅的那个，而是能被系统高效实现的那个。

从"擦线进清华"到 36 门课全 A：他不是卷，他是真的想学

游凯超高考分数只比清华录取线高了 2 分。他自己形容是"勉强擦着分数线上去的"。

但进清华之后，他做了一件让很多人不理解的事：大一发了 100 多封邮件给老师请教问题，看了 1 万多页学习资料，精读笔记在校史馆展出，36 门课程拿到 4.0 满绩。

"这不是卷，"他说，"十多门课，每门课每周给老师发个邮件请教，加起来就 100 多封了。这是一个坚持的过程，不是拿字数当目标去优化。"

他从高中就在学堂在线上自学大学物理、微积分和 Python——不是因为高考要考，而是因为"我不喜欢无意义的重复劳动，不喜欢刷题，更喜欢学习新知识"。高考那年题简单，他的能力没体现在分数上，但他觉得"学到知识比较满足"。

他后来拿了清华特等奖学金——那个被称为"一年一度神仙打架"的评选。但他现在对特奖的看法非常冷静："把一个入学三年的本科生过度曝光在聚光灯下，很容易对正常学习科研产生不必要的干扰。特奖只是一个奖学金，不应该被赋予过多含义。"

学术界"礼乐崩坏"：论文变成抽彩票

真正改变游凯超研究方向的，是他在博士期间目睹的学术生态恶化。

"一八年的时候，一届学术会议大概几百篇论文，审稿质量是高的，审稿人会认真告诉你哪里做得好、哪里不好、应该怎么改进。"他说，"但后来投稿数呈几何级数增长，审稿人的数量和质量远远跟不上。你的论文中不中，跟工作质量已经没有很大关系了，就像抽彩票一样。"

他用了一个很重的词：礼乐崩坏。

但他不是那种抱怨完继续混的人。他分析了更深层的原因：算法研究的天花板人物是 Kaiming He（何恺明），ResNet 的作者。"每次恺明老师的主页有变动，或者挂了一篇新 arXiv 论文，我们就感觉收到了神谕——又有一个新方向可以做了。"

但私下讨论时，大家都感到困惑：为什么类似的想法，自己在组会上也提过、甚至做过小实验验证过，最后成功的却是恺明？

游凯超的结论是：恺明做的事情，不仅是方法简洁有效，而且做了大规模实验。 实验室里的小团队只是在"螺丝壳里做道场"，在小数据集上玩出花来，但一旦需要规模化实验，支撑实验的机器学习系统和数据，才是决定成败的关键。

系统才是决定算法能否落地的那个变量。算法是锦上添花，系统是生死线。

2022 年的一次对话，让他彻底转向

2022 年，游凯超在 VALSE 大会上遇到张强宇（旷视首席科学家）。他本以为对方会聊目标检测的最新算法突破，结果张强宇说的是另一件事：旷视的工程师最头疼的，不是调参数，而是英伟达 cuDNN 代码里的各种坑，以及为特定硬件写算子时数据在芯片多级缓存之间怎么流动。

"这对我的触动非常大，"游凯超说，"一个算法大佬，最关心的其实是硬件对软件带来的挑战。"

另一个关键影响来自 Ion Stoica（伯克利 Sky Lab 主任，Spark、Ray 等项目的孵化者）。2019 年，游凯超在伯克利做暑期研究时，向 Stoica 问了一个很学生气的问题："我想做一个机器学习系统，但怕做出来没人用，这个时间是不是浪费了？"

Stoica 告诉他："只要你做的是一个好的软件，总会有人用的。"

四年后，当游凯超再次申请去伯克利交流时，他重提了这个问题——告诉 Stoica，这四年他一直在践行这个建议。Stoica 很感动，批准了他的申请。

"四年前那个青涩少年，四年后还是同一个人，在走同一条路。"

把 Woosuk 拉回来：vLLM 商业化背后的博弈

vLLM 诞生于 2023 年中，最初只是 Sky Lab 的一个科研项目。创始团队的核心是三个人：Woosuk Kwon（第一作者，vLLM 核心架构设计者）、周汉（Zhuohan Li）和游凯超。

但要把一个开源社区变成公司，最难的其实是说服 Woosuk 加入。他当时已经拿到了大厂 offer，犹豫了很久。

"我们找他逼供，"游凯超回忆，"问了他那个问题——你如果不做，我们自己做。你赚到了很多钱，但十年后 vLLM 失败了，你会快乐吗？"

Woosuk 想了几天，回来了。

为什么一定要把 Woosuk 拉回来？游凯超的解释很直接："很多历史上的技术抉择是他做的，他来做有最好的延续性。对社区来说，他就是那个根——根正苗红。"

不得不商业化的时刻：连 NDA 都没人签

很多人以为 vLLM 商业化是主动选择。游凯超说，其实是被逼的。

到 2025 年，vLLM 面临两个用开源社区模式无法解决的问题。

第一个是人力资源的不确定性。 做大规模集群级别的部署，需要长期稳定地推进一个 feature。但开源社区的贡献者来去自由，"有人来、有人走，你没有办法依靠这种模式做重要的事情。"

第二个是法务问题。 很多芯片和模型公司在发布前需要 vLLM 做适配，但对方要求签 NDA（保密协议）。开源社区不是一个实体，没人能签。"对方法务会问：你背后是哪些人？这些人里有我的竞争对手吗？要不要做背景调查才能接触我们的信息？"

还有机器资源的问题。到了集群级别优化，"别人给你一台机器已经是顶天了。我可能要先花一个月劝对方给我机器，拿到了还得马不停蹄地规划——因为这些机器一个月后就到期了，而且不是 promised 的。对方可能一三五自己用，二四六给你用，甚至紧急通知你接下来一小时马上要用。"

"我们已经很明确地看到，没有一个公司的支持，这个项目已经无法继续往下发展。"

Token 不等于电：大模型的真正壁垒是什么

游凯超有一个反复出现的比喻——token 不是电。

"电是通用的，你可以调制它的电压和频率。所有家电只需要满足 220V 的国家标准，就能接入使用。但 token 不是这样的——你没有办法把一个 DeepSeek 模型的 token 转化成一个 Kimi 模型的 token。每一个 token 都带着模型的烙印。"

这个比喻背后是他的核心观点：模型不是核武器——你研究出来、爆炸一次给别人看，就可以藏着用于威慑。模型是民用技术，必须被大规模使用。一旦被大规模使用，用户就能收集到自己的数据，模型就能被复制出来。

"我觉得一般一个月左右，一个公司级别的机构就能收集到足够训练自己模型的数据。到那个时候，内部的飞轮就能转起来。"

正因为如此，游凯超下了一个赌注：开源模型最终会赢。

"这不是立场，是从第一性原理推导出来的——模型就不是一个能够长期藏得住的东西。"

开源模型最终会赢——不是因为理想主义，而是因为物理定律。

模型-Infra 的联合设计：DeepSeek 为什么能领先一个身位

游凯超在技术判断上最鲜明的立场是：后摩尔定律时代，AI 的上限取决于系统，而不是算法。（虽然他声明这是 David Patterson 的判断，他认同。）

他最常举的例子是 Flash Attention。当 Attention is All You Need 出来后，无数论文在研究如何近似计算 softmax attention 来提高长上下文效率。但 Flash Attention 用工程手段证明了：精确的 softmax attention 可以被高效实现。 于是那些"高效近似"的论文全部作废。

"系统有一个彩票效应：你的算法能不能被系统高效实现？只有被高效实现的算法才能活下来。"

DeepSeek 是游凯超眼中做得最好的案例。他以 FP8 量化为例：Hopper 架构的 FP8 算力比 FP16 快两倍，但直接用全局 FP8 量化会损失精度。DeepSeek 的解法是分块量化——对权重做 block-wise quantization，对 activation 做 per-channel quantization。但这还不够，他们探索出了"矩阵乘法后拿向量单元做累加"的思路，利用芯片上两部分计算单元同时执行的特点，在精度不损失的情况下做到了计算效率领先。

"这些故事都写在 DeepSeek 的技术报告里。只是看的人多少的问题，不同的人会画不一样的重点。"

对 MOE（混合专家架构），他总结了三大挑战：细粒度专家导致矩阵乘法维度低（不友好）、动态路由对 GPU 数据依赖的挑战、以及万亿参数下的专家并行通信。而 DeepSeek 在 2025 年用 DeepEP 和 DeepGemm 分别处理了通信和计算问题——"这一波 DeepSeek 引领了时代潮流。"

Test-Time Scaling 的三个阶段

游凯超把 test-time scaling 分成三个阶段：

  1. 集成学习时代（早期 ML）：同一个问题让不同模型回答多次，取最优结果。Scale 的是"尝试次数"。
  2. 长思考时代（O1 风格）：让模型对困难问题思考更久，输出几十万 token。Scale 的是"单次输出的 token 数"。
  3. Coding Agent 时代（2026 年主流）：让 agent 持续与环境交互，每次思考只有几百 token，但不断了解环境。Scale 的是"模型与环境交互的次数"。

第三阶段的爆发，让他特别关注 Harness 框架和推理引擎的联合设计。"前缀缓存非常重要——你必须保持请求前缀的稳定，推理引擎才能复用前面的计算结果。"

他举了一个让人啼笑皆非的例子：有些 Harness 框架把当前时间戳精确到秒，放在 system prompt 前端，而且定时任务总是设在整点。"一到整点，推理系统就收到一大波巨大的流量。芒校（伯克利）的同学有一个非常形象的说法——一群小龙虾一到整点就集体出动攻打月球。"

更优雅的解法很简单：把日期当作工具，让模型按需查询；不要让经常变化的东西出现在请求前端。

中美两条路线：效率 vs 效果

"欧美的模型更重视效果，中国的模型更重视效率。"这是游凯超和全球主流开源模型合作后的整体感受。

他认为这反映了两边的资源禀赋差异：美国高端算力充裕但土地和电力供应紧张，中国算力紧缺但数据中心基建条件更好。"各有各的局限和掣肘，不是竞争。"

但中国开源生态的崛起让他印象深刻。"在美国走向闭源之后，中国扛起了开源的大旗。"

他最新的 bet：百万级上下文已经足够，不需要再往上大幅增加。 "与人类打交道的模型，上下文不需要无止境扩张。长程任务和终身学习可以通过外部工具实现——记忆模块、技能模块、sub-agent 模块。"

第一性原理：在噪音中辨认主线

谈到对年轻研究者的建议，游凯超反复说一句话：从第一性原理的角度思考。

"AI 行业非常火热，每个月每个话题都有十个层出不穷的新技术。你需要从第一性原理出发，判断哪些技术有用，哪些是花拳绣腿。"

他举了一个亲身经历：在学习 GPU kernel 编程时，他第一件事是搞清楚 GPU 编程模型提供了哪些设计空间。理解了这一点之后，他确信 GPU 驱动应该支持一种叫 CUDA core dump 的技术来调试"非法内存访问"——一个在 AI infra 圈里几乎没人知道的工具。他持续追问英伟达团队，最终对方确认这个工具早已存在，只是不为人知。他在社区推广后，"解决了非常多的疑难杂症。"

"在一个快速发展的阶段，看清时代发展的主线，屏蔽噪音，持续在一个有用的方向投入——这是最重要的。"

结尾：人类提供灵感，硅基提供执行力

这次访谈的最后，游凯超被问到硅基和碳基如何共存。他的回答出乎意料地克制。

"硅基的智能更多是一个 summary——从它学到的语料里总结出来的。人类还是能提供一些 insight，一些我们所谓的灵感。"

他说他的理想画面是：人类驾驭硅基智能，硅基提供大规模执行力，人类利用这些能力让世界变得更好。

当被问到生命中重要的地点时，他说是伯克利——"两次重要的人生转变都在那里。"喜欢的音乐是李宗盛的《山丘》，"想说却还没有说的还很多，所以我们之后如果还有时间可以再聊。"

在一个 3 小时的深度访谈里，一个 28 岁的清华博士、1.5 亿美元公司的联合创始人，用"山丘"来收尾——这可能比任何技术判断都更能说明他是什么样的人。

文末要点

  • 游凯超从算法转向系统，不是因为算法不重要，而是因为在后摩尔时代，算法能否落地越来越取决于系统的实现效率——"系统决定生死线"
  • AI 学术界投稿数爆炸、审稿质量急剧下降，论文中稿变成"抽彩票"，这是他离开算法研究的直接诱因
  • vLLM 的商业化是被逼的：集群级部署需要稳定的团队，NDA 需要法人实体，机器资源靠"乞讨"无法持续
  • Token 不是电——每一个 token 都带有模型的烙印，无法像电压一样调制。因此长期来看，模型无法被隐藏，开源会赢
  • DeepSeek 在模型-Infra co-design 上领先一个身位的秘诀：从第一性原理出发，不追逐热点，持续深挖
  • Agent 时代的推理优化关键：Harness 框架必须和推理引擎联合设计，前缀缓存是瓶颈，不要把时间戳放在 system prompt 里
  • 百万上下文已经够用，不需要无止境扩张——长程任务和终身学习应该通过外部工具实现

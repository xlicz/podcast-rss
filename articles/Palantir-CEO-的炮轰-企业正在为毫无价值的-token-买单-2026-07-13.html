Palantir CEO 的炮轰：企业正在为毫无价值的 token 买单

Alex Karp 罕见开火：美国企业界已经"气炸了"，Frontier Labs 的商业模式是"财富税"，而客户真正想要的是控制权

"我们的客户说他们对 Frontier Labs 不满——那都算客气了。那种不适和信任崩塌的程度，真的非常非常严重。"

Palantir CEO Alex Karp 在这场罕见的坦率访谈中，几乎没有给任何人留情面。他说 OpenAI 和 Anthropic 在过度炒作、说美国企业界已经受够了、说投资人根本不懂技术。但在这通火力全开的输出之下，有一条清晰的逻辑链：AI 行业正在经历一场关于谁拥有商业价值的深层博弈，而 Palantir 赌的是客户终将夺回控制权。

信任崩塌的根源

Karp 的核心指控可以概括为一句话：Frontier Labs 的商业模式建立在对客户知识产权的系统性侵蚀之上。

"这些模型通常的卖法是：我就躺平，把时间浪费在 token 上，我得不到任何价值，而他们会拿走我的知识产权。"

他不是在抽象地谈数据隐私。他的论点触及了一个更具体的商业恐惧：如果你用 Frontier Labs 的模型来处理你的核心业务——无论是制药公司的临床数据、国防部的作战规划、还是投行的交易策略——你怎么保证明天这些"智能"不会被整合进模型本身，然后卖给你的竞争对手？

"如果这东西真这么值钱——假设我明天能帮你赚十亿美元——那我难道不会说'我帮你赚十亿，我要拿 30%'？如果真这么值钱，他们为什么还要按 token 收费？"

这个质疑的尖锐之处在于它击中了 Frontier Labs 商业模式的潜在矛盾：如果他们卖的是"改变世界"级别的智能，按 token 计费太便宜了；如果他们卖的只是 API 调用，那客户为什么要冒知识产权泄漏的风险？

Ontology：Palantir 的答案

Palantir 的应对方案是一个叫"ontology"的应用层——这个词在 Karp 嘴里出现的频率远超其他任何技术术语。

"关键基础设施不会在没有应用层的情况下直接跑这些模型。那个应用层就是我们的 ontology。这是事实，而且是有原因的。"

Ontology 在 Palantir 的语境下是一个数据建模和治理框架。按 Karp 的描述，它的核心功能是确保 AI 模型在访问企业数据时，不触碰非学习数据、不缓存客户信息、不复制客户的业务逻辑。换句话说，它是模型和企业数据之间的一道防火墙——但不是传统意义上的安全软件，而是一个深度嵌入业务流程的操作系统级抽象。

"我们能让你用前沿应用达到和前沿模型完全一样的效果，却不用承担把生意的商业价值转移给别人的风险。"

Karp 特别强调 Palantir 的产品是"模型无关的"——客户可以在不同模型之间切换。"我们完全保持中立。我们需要重建信任，而这种信任会建立在每个人都能问清楚、答清楚一些基本问题的基础上：数据归谁？缓存在哪？提示词安全吗？"

"这个国家的企业都气炸了"

访谈中最值得注意的不是 Karp 说了什么技术词汇，而是他不断强调的一个判断：美国企业界的愤怒远比公开表达的严重。

"我告诉你，在这个国家，我接触的每一家企业，这些人都气炸了。他们的想法是：我在为毫无价值的 token 付费。这些人在偷走我生意的权重和商业价值，他们在制造一种财富税。"

他甚至建议怀疑他的人去验证："私下里给一位 CEO 打个电话，别公开打。打给两三个人，就问'疯子 Karp 上电视说我们都气炸了'，然后你看看——他们比我还要气两倍。"

这是一个大胆的赌注：如果他是对的，那么我们现在看到的 AI 企业订阅收入中，有相当一部分来自那些"敢怒不敢言"的客户——不是因为产品好，而是因为没有更好的替代方案。一旦有，流失可能比市场预想的更快。

但如果他是错的呢？那就意味着大多数企业客户其实对 Frontier Labs 的隐私承诺是满意的，而 Karp 只是在为他自己的应用层生意做宣传。访谈中主持人直接追问了这个角度："那这是不是给 Palantir 创造了更多机会？你们是不是已经看到政府在取消跟 Anthropic、OpenAI 的合同？"

Karp 的回答绕开了具体的合同数据，转而抛出财务数字："大概两年后你能看到 150 亿到 180 亿美元的自由现金流。"

投资人的盲区

Karp 还顺便给了投资圈一刀。

"投资人其实并不真的懂技术。他们以为自己智商很高，懂一些东西，就以为自己懂正在用的产品。投资人的通病通常是'我在用，所以它有价值'。但企业用它来做复杂的制造、药理研究、投弹，或者把特种部队安全带回家，这跟你自己用完全是两码事。"

这段话指向一个更深的问题：目前 AI 公司的估值很大程度上建立在"我也用 ChatGPT/Claude，所以这公司值钱"的类比推理上。但当客户是五角大楼或辉瑞时，需求、风险、决策逻辑和普通消费者完全不同。Karp 认为这个估值框架存在系统性偏差。

与 NVIDIA 的合作逻辑

Karp 对 NVIDIA 的态度和对 Frontier Labs 截然不同。"我对 NVIDIA 和 Jensen Huang 非常敬重。"

这笔合作的核心逻辑是控制权——NVIDIA 提供计算和开放模型，Palantir 提供应用层，客户掌控自己的数据、权重和商业价值。"技术客户真正想要的，就是对自己的计算模型、数据站和商业价值的控制权。他们想知道自己拥有生产资料，而不是被转移给别人。"

这种"计算 + 模型 + 应用层"的组合，Karp 认为才是真正在改变历史进程的东西。"去问问乌克兰人，问问以色列人，问问我们的国防部，问问那些正在用我们产品的企业。我们根本不需要吹嘘——我们有真东西。"

文末要点

  • Karp 的核心指控不是"模型不够好"，而是"客户不知道自己会失去什么"——数据主权、业务权重、知识产权，在目前的 Frontier Labs API 模式下面临系统性风险。
  • Ontology 在 Palantir 体系中的角色不是锦上添花的安全层，而是连接模型与企业核心业务的操作系统级抽象——没有它，关键基础设施根本不应该直接跑大模型。
  • 美国企业界的愤怒据 Karp 描述远超公开表达——如果企业订阅的"被迫消费"成分真如他所说那么高，AI 行业的收入质量需要重新评估。
  • NVL72、开放模型、应用层——Karp 描述的"计算+模型+应用"三件套，意味着未来的 AI 部署不是选一个模型供应商，而是构建一个客户完全可控的技术栈。

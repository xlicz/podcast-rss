📋 详细条目

1. Anthropic 发布 Claude Opus 5：半价追平 Fable 5 的编程旗舰 | 🟢 | [✅事实]

7 月 24-25 日，Anthropic 正式发布新一代旗舰模型 Claude Opus 5 并全平台上线。API 定价每百万 token 输入 $5、输出 $25，与前代 Opus 4.8 完全一致，仅为被下架的 Fable 5 的一半。

[✅事实] Opus 5 在 Frontier-Bench v0.1 登顶，ARC-AGI 3 得分达次优模型的 3 倍。CursorBench 3.2 以一半成本逼近 Fable 5（差距仅 0.5%）。OSWorld 2.0 以三分之一成本反超 Fable 5。SWE-bench 较 Opus 4.8 提升 22%。Claude Code v2.1.219 同步将其设为默认 Opus 模型，提供 1M 上下文窗口，并将嵌套子 Agent 派生深度从 1 放宽至 3。

[💬观点] Anthropic 称 Opus 5 "在编程和工作知识评估上达到新的 state-of-the-art"。

  • 验证: ✅ Anthropic 官方博客已验证 — 关注: AI Coding 性价比公式被重写，$5/$25 定价可能引发新一轮 Agent 部署成本下降
  • 来源: Anthropic 官方博客, VentureBeat, Fast Company

2. Open Dreamer：Dreamer 4 世界模型 JAX/Flax 完整复现并开源 | 🟡 | [✅事实]

7 月 25 日，AI 研究小组 Reactor 发布 Open Dreamer，首次完整复现 Dreamer 4 世界模型训练流水线，采用 JAX + Flax NNX 框架，两个仓库同步开源（next-state/open-dreamer，183★）。

[✅事实] 发布内容包含完整训练配方、配置文件、稳定性工程经验总结。核心创新：用 Masked Autoencoder 替代传统 VAE 作为 tokenizer，实现约 100× 压缩且无需 KL 散度或对抗损失。团队报告 57-58% 模型 FLOPs 利用率。同时提供浏览器端 Minecraft 实时世界生成演示，支持 Game ⟷ Dream 一键切换。

[💬观点] 研究团队认为 MAE tokenizer 的掩码机制使模型学到更鲁棒的表示，"不需要像 VAE 那样在压缩率和重建质量之间做痛苦权衡"。

  • 验证: ✅ GitHub 仓库已确认（next-state/open-dreamer），MarkTechPost 独立报道 — 关注: 首个 Dreamer 4 完整复现+训练配方公开，为世界模型研究提供可复现基线
  • 来源: MarkTechPost, GitHub

3. DeepSeek 暂停融资：梁文锋投资人会议承认中美算力差距 | 🟡 | [📰推测]

[💬观点] 纪要中梁文锋表示："算力差距不是短期能追上的，需要更长周期的投入和基础设施建设"。

4. Humanoid 获 $1.52 亿 A 轮融资，估值 $13.5 亿成欧洲机器人独角兽 | 🟡 | [✅事实]

7 月 21-23 日，英国具身智能公司 Humanoid 宣布完成 $1.52 亿 A 轮融资，投后估值 $13.5 亿，成为欧洲最新机器人独角兽。Forbes、Yahoo Finance、SiliconANGLE、The Robot Report、FinSMEs 等 5+ 家独立媒体同时报道，多源交叉验证通过。

[✅事实] Humanoid 的目标是将通用人形机器人带入工厂和物流场景。本轮融资将用于扩大团队、加速产品迭代和部署基础设施。

[🔮预测] The Robot Report 分析认为，这标志着欧洲在具身智能领域的追赶进入加速期，"Humanoid 可能成为欧洲版 Figure AI"。

  • 验证: ✅ Forbes/Yahoo Finance/SiliconANGLE 等 5+ 独立源同时确认 — 关注: 欧洲最大具身智能单笔融资，人形机器人赛道资本密集度持续攀升
  • 来源: Forbes, Yahoo Finance, SiliconANGLE, The Robot Report

5. WAIC 2026：AGIBOT 发 4 款新机器人，具身智能从"秀肌肉"转向"晒工单" | 🟢 | [✅事实]

7 月 17-20 日，2026 世界人工智能大会（WAIC）在上海举办，具身智能站上主舞台：

[✅事实] 智元（AGIBOT）集中展示全套"三智一体"产品架构，发布 4 款新机器人及具身基座大模型 GO-2，其世界模型 GE-2 登顶 2026 World Arena 总分冠军。腾讯 Robotics X 实验室联合混元发布 Hy-Embodied-VL 等三大具身基座模型，首次打通"感知—身体—行动"闭环。极智嘉发布统一具身智能框架 Gravity 及 Gravity 4D 模型。国家地方共建人形机器人创新中心与华为联合打造全国首个具身智能实训场样板点。

[💬观点] 清华大学苏航："近两年具身智能迎来重要变化，核心因素在于基座模型的快速发展"。腾讯张正友："今天最聪明的人工智能本质上仍是'缸中之脑'"。

  • 验证: ✅ 新华网、中国新闻网、腾讯新闻等多方官方媒体报道 — 关注: 中国具身智能从实验室全面转入产业部署态，世界模型+具身基座成标配
  • 来源: 新华网, 中国新闻网, 羊城晚报

# OpenAI 内部视角：那个"想按就按"的额度重置按钮，和它背后的算力逻辑

## 他管着 Codex 和 ChatGPT，解释了为什么补偿用户、提前两年押注算力、用模型优化模型，是同一套逻辑

"我想什么时候按就什么时候按，觉得合适了就按。"Tibo 指的是 OpenAI 那个著名的额度重置按钮——当产品出故障或体验不够好时，给用户补偿算力额度的机制。他补充了一句："背后没有层层审批，不是跟市场部或者财务部商量着来的。"

这不是营销话术。这个前 DeepMind 研究员、现 OpenAI 产品负责人（负责 Codex 和 ChatGPT 产品线）在接受播客访谈时，把 OpenAI 过去两年最反直觉的三个决策——频繁的额度重置、被质疑过的算力重注、用模型优化模型——串成了同一套逻辑：文化、算力前置、递归自我改进。

## 谷歌为什么"自己绊倒了自己"

Tibo 在 ChatGPT 出现前一年就参与过 DeepMind 的内部聊天产品 LM Chat。那是模型第一次能输出连贯、有用的文本——"一开始更多是搞笑而不是有用，然后慢慢变得越来越有用"。他当时发过一条推文：谷歌太紧张了，不敢发布 DeepMind 被禁止推出可能颠覆谷歌的产品。

"在很多方面，谷歌都是自己绊倒了自己。"他把这段经历当作反面教材带进了 OpenAI："我会从团队的文化、OpenAI 自身的文化来思考，保留哪些好的部分，什么事情不能做。"

对比很直接：DeepMind 的机制"就不是为了发布产品而设的"，而 OpenAI 是研究和产品团队"超级紧密"地绑在一起，共同设计、倾向发布、倾向让所有人用上。"当你有一头正在疯狂印钱的摇钱树，而另一边有一个可能很酷的新东西"时，多数成熟公司会保守——OpenAI 的选择是"非常非常往前看"，不在乎未来一两个月内建了什么，而在于能不能赶上下一波浪潮。

这种文化有一个具体的执行方式：愿意颠覆自己。"我们一直在提出新的研究、新的想法，能够识别什么时候是投入它们的正确时机，即使这意味着要从主业重新调配资源。"他评价这是谷歌做不到的事。

## 额度重置：是文化，不是增长黑客

额度重置在社区里被反复解读为营销手段，Tibo 给出的版本更朴素："最开始，当我们快速迭代把东西弄坏了，或者配置出了问题、效果不如预期时，去给用户做些补偿，感觉就是对的。"就像在说：嘿，谢谢你试用，我们不小心弄崩了大概三十分钟，送你一些额外额度。

他甚至把这事类比成亚马逊的退货政策——"只要你有任何不满意，尽管退回来就是了"。目的是建立同一种公众认知：如果我们犯了错，会弥补。

"我觉得这确实在很大程度为社区积累了善意，也许至少在很小程度上促进了增长。"注意他的排序：善意在前，增长在后。他承认自己几乎不关注竞争对手："我真正关注的是我们有什么独特的优势，我们的价值观是什么，以及怎么以最快的速度朝这些目标推进。"

但额度重置有一个隐藏前提，也是整段对话里最值得注意的一句话："做了所有这些额度重置，只有在你做好了大规模算力规划的前提下，你才真正能这么做。你必须有足够的算力才能送出所有这些重置额度。"

## 两年前的算力重注，现在开始兑现

Tibo 回忆，两年前 OpenAI 因为算力投入过大被质疑过——"那些疯狂却极其成功的押注之一"。现在他们庆幸拥有很大一部分算力，用于研究、投资未来，以及提升现有模型的效率。

效率提升是实实在在的数字：他们把 Luna 的价格降低了 80%，"整体速度大概比三个月前快了 60% 左右"，方法是一一优化技术栈的每一个部分，针对现有工作流做最合理的架构设计和工程实现。更关键的是归因——他明确说这"几乎都算不上取舍"："我们基本可以用同样的算力上限来支撑吞吐量非常显著的增长。"也就是说，效率收益不是从别处挤出来的，而是真金白银地摆在那里。

他们的承诺是"不会把这些效率收益自己揣进兜里，而是分享给客户和用户"——所以降价、所以送额度。效率、普及、善意，在这里闭环。

## 递归自我改进：已经在发生，但在基础设施层

当主持人问"用模型训练下一个模型、观察 Luna 的运行方式取得效率提升，是不是递归自我改进的初期阶段"时，Tibo 给出了一个更精确的版本：

"大家最常把递归自我改进用在研究、模型开发其他模型上。但我们看到取得巨大成功的地方，是用这些模型去开发位于使用模型关键路径上的基础设施——推理技术栈、硬件、我们用到的 kernel、CUDA kernel，还有开发新产品、与模型交互的更高效的新方式。"

换句话说，最前沿的模型正在被用来重构承载它们自己的技术栈。这是一个飞轮：把最先进模型的能力边界往前推，然后用这些模型"非常非常快地弄清楚如何部署、如何重构、如何重新设计技术栈"，获得显著效率提升，再用省下来的算力推下一个模型。他提到"正是我们最强大的那些模型，让我们能用非常小的团队把这件事做成"。

一个自我设限的细节：OpenAI 员工理论上能用光所有生产 GPU 和超快模式算力，"我们本来能全用完的，但我们没有"。他们把大部分算力留给外部客户，只保留"合理的量"用于理解产品、持续改进产品——"从而享受递归自我改进带来的好处"。

## 超快模式：一两年内接近默认配置

关于速度，Tibo 的预测很直接："我觉得，在一两年内，这种速度就算不是默认配置，也会非常接近默认配置。"理由不是单一维度的推理加速，而是 token 利用效率的持续提升："比如新一代模型的 token 利用效率就明显比 Terra 高。正如你能预料到的，下一个模型的 token 效率又会高得多。"

他也指出了速度的边界条件：14 倍加速只在特定工作负载上兑现。"比如你想做个网站或电子游戏的原型，只需要写大量代码，那它会做得非常非常快，快上十倍。但如果是大量的工具调用，开销都在网络或 agent 执行轨迹的其他地方，你可能只能感受到三四倍的加速。"

他最期待的速度用例是延迟敏感的非文本交互：在同一块共享画布上操作、生成想法和图片、像"选择你自己的冒险故事"一样快速出原型，然后通过语音或文字实时引导调整。"作为一名工程师，有时候你得把整个系统都设计出来，考虑各种权衡。但也许你一分钟就能把它做出来，看看实际效果到底怎么样——然后更顺畅地进入心流状态。"

## 六个月前的前沿模型，现在便宜得离谱

访谈最后，主持人问他对担心 AI 的人说什么。Tibo 的回答落回了他反复强调的那个点：效率是普及的路径。

"Luna 是一个小得多的模型，效率极其高。但如果倒退回六个月前，它当时也算得上是最前沿的模型。再看看 Luna 的成本——便宜得离谱。现在不管处于什么前沿水平，六个月后运行起来都会便宜得多得多。"

他的未来图景不是某个杀手级应用，而是一个递推关系：持续死抠效率 → 服务成本下降 → 使用价值上升 → 顶尖智能的获取机会变得无处不在。"获得这种顶尖智能的机会将会变得无处不在，而这只有在你一个月接一个月、一年接一年地去死抠效率时才有可能实现。"

这正是额度重置按钮、算力重注和递归自我改进共享的底层信念：OpenAI 赌的不是某个产品，而是"效率会持续变便宜"这件事本身——而它把公司文化的每一部分都押在了这上面。

---

**要点**

- 额度重置是补偿文化而非营销：OpenAI 把"弄坏了就送额度"当作亚马逊式退货政策来经营，前提是算力储备足够厚
- 谷歌的教训被当成组织反面教材：DeepMind 机制不为发布产品而设，OpenAI 把"研究+产品紧密耦合、倾向发布"当作文化底线
- 两年前被质疑的算力投入已兑现：Luna 降价 80%、整体速度比三个月前快 60%，且"几乎不算是取舍"
- 递归自我改进已经发生在基础设施层：用最前沿模型重构推理技术栈、CUDA kernel 和部署流程，而非只停留在研究环节
- 效率收益"不揣进兜里"：降价、送额度、把算力留给客户，是同一套"效率→普及"逻辑的执行
- 超快模式一两年内接近默认配置：判断依据是 token 利用效率的持续提升，而非单纯的推理加速
- 速度的收益不均匀：代码密集任务快 10 倍以上，工具调用密集任务可能只有 3-4 倍

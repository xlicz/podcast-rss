1. OpenAI 发布自研推理芯片 Jalapeño | 🟢 | [✅事实]

OpenAI 在 Hot Chips 2026（8/25）公布与 Broadcom 合作的自研推理 ASIC + 系统 Jalapeño，定位"推理平台"而非裸加速器：700W TDP（对比 NVIDIA GB200 1.2kW、GB300/MI355X 1.4kW），围绕 time-to-last-token 与 tokens/joule 两项指标设计，采用 HBM4 与空间编程模型。项目节奏极快：2024 年底架构概念 → 2025 年 RTL freeze → 2025 年底 tapeout → 2026 年初 Codex 已在其上运行，随后 ChatGPT 上芯片。SemiAnalysis 以 InferenceX 功率归一化基准评价"优于 NVIDIA Blackwell"；Tom's Hardware 报道其每千瓦吞吐量达 NVIDIA 1.4kW 旗舰的 1.9 倍。CNBC 称定制芯片对 NVIDIA 利润率构成新威胁。

  • 验证: ✅OpenAI 官方博客 + Bloomberg/CNBC/Axios/SemiAnalysis/ServeTheHome 多源一致 — 性能数字为厂商自测，独立复测未出 🔴未证实（1.9x per kW 为 Tom's Hardware 转述官方声称）
  • 关注: 推理 ASIC 9 个月走完流片，agentic 推理成本曲线将被改写
  • 来源: openai.com / SemiAnalysis / CNBC / ServeTheHome

2. Z.ai 揭晓神秘模型 Ox Alpha = GLM-5.3-Flash | 🟢 | [✅事实]

Z.ai（智谱）8/26 发布 GLM-5.3-Flash：GLM-5 系列首个原生多模态模型，320B 总参数/18B 激活（对比 GLM-5.2 的 744B/40B），混合稀疏+线性注意力架构 + mHC 连接，30T token 多模态语料。AI Index v4.1.1 得分 57 @ $0.045/task（约 1/10 价格），DeepSWE v1.1 63.4 vs GLM-5.2 的 46.2，编码/agentic 基准接近 Claude Opus 4.8。发布前以 "ox-alpha" 匿名在 OpenCode/OpenRouter 测试并成为当周最热模型——关键点是该流量全部由中国 AI 芯片集群承载：数万颗国产加速器 + 自研 EPD 分离式推理栈，端到端性能较基线提升 3×，每 token 成本与主流 NVIDIA GPU 相当。权重 MIT 协议开源（HF）。

  • 验证: ✅Z.ai 官方博客 + TestingCatalog（MIT license）+ Wccftech 独立确认 Ox Alpha 对应关系；性能数字为官方自测 🔴未证实独立复现
  • 关注: 国产芯片承载前沿模型推理已经济可行，中美算力脱钩加速
  • 来源: z.ai/blog/glm-5.3-flash / TestingCatalog / Wccftech

3. 阿里开源 Qwen3.8-Flash-Next | 🟢 | [✅事实]

Qwen 团队 8/26 发布 Qwen3.8-Flash-Next 开源权重：125B 总参数 + 51B N-gram Embedding、每 token 仅激活 6B 的多模态 MoE，作为 Qwen4 架构先导预览（Gated DeltaNet + Gated Attention 混合结构，四项系统升级：Attention/Residual 四分支/Embedding 可卸载/优化器分工）。训练开销约为 Qwen3.7-Plus 的 1/9，编码与办公任务反超。原生 262K 上下文，YaRN 可扩 1M。生产版 Qwen3.8-Flash 已在千问平台以输入 1 元/输出 3 元每百万 tokens 开放（默认 1M 上下文）。DeepSWE 1.1 58.7、SWE-bench Pro 62.5，具身智能基准 ERQA 72.3。

  • 验证: ✅Qwen 官方博客 + Reuters + NVIDIA Developer 博客多源一致；基准为官方自测 🔴未证实独立复现
  • 关注: 6B 激活成本直逼 1 元/百万 tokens，Flash 级模型价格战下探
  • 来源: qwen.ai/blog / Reuters / the-decoder.com

4. 小鹏机器人单元 Dogotix 首轮融资超 $9 亿 | 🟢 | [✅事实]

XPENG 官方确认机器人单元 Dogotix（人形机器人 IRON）完成首轮融资超 $9 亿（约合人民币 64 亿+），Reuters 报道该轮后估值超 $6.3B，为具身/人形赛道近年单笔最大融资之一。SCMP 称小鹏在季度亏损扩大背景下仍加码人形；华尔街（CnEVPost 转述）视机器人融资为集团价值解锁催化剂。

  • 验证: ✅XPENG 官方公告 + Reuters（$6.3B 估值）+ The Robot Report/SCMP 多源一致
  • 关注: 车企分拆机器人独立融资逻辑再获验证，与华为车BU/云鲸模式同构
  • 来源: xpeng.com / Reuters / The Robot Report

5. 深圳 AIRS 开源具身智能框架 AIRSEAI 加入 Linux 基金会 | 🟢 | [✅事实]

LF AI & Data Foundation 8/26 宣布接纳 AIRSEAI：由深圳市人工智能与机器人研究院（AIRS）发起的开源具身 AI 项目，旨在解决机器人生态碎片化——专有平台、硬件绑定软件栈、孤立数据集。三阶段路线图：模块化单机器人智能 → 数据驱动双臂操作（AIRSEAI 2.0，含视觉触觉感知与弹性模型库）→ 异构机器人分布式协作（3.0）。发起人为 AIRS 具身智能主任 Shaoshan Liu。

  • 验证: ✅Linux Foundation 官方新闻稿 + HPCwire 转载
  • 关注: 开源中立标准若成气候，或重塑具身软件栈与数据互操作格局
  • 来源: linuxfoundation.org / HPCwire

📋 详细条目

1. 宇树科技上海 IPO 首日暴涨，估值最高 $66B | 🟡 | [✅事实]

宇树科技 8/19 在科创板上市，首日股价大涨。SCMP 报道涨 629%、估值达 660 亿美元；CNBC 报道涨 542%；Guardian/CoinDesk 报道涨约 600%；融资规模约 $0.9-1.3B（Bloomberg/AFR）。Reuters 称其为"中国人形机器人行业的里程碑"。报道普遍强调该上市发生在美国对华机器人禁令背景下，被视为中国科技"本土融资"战略的典型。

  • 验证: ✅ 10+ 独立媒体（Reuters/CNBC/WSJ/Bloomberg/FT/AP/Guardian/SCMP）一致确认事件；🔴 涨幅/估值各源区间分歧（542%-629%，$50B-$66B），未核验交易所收盘原始数据 — 关注: 人形机器人首个标杆 IPO，为赛道估值定锚
  • 来源: Reuters / CNBC / WSJ / Bloomberg / SCMP 等（8/18-20）

2. 第 2 届世界人形机器人运动会北京开幕，2000+ 机器人参赛 | 🟡 | [✅事实]

8/22 第 2 届世界人形机器人运动会在北京开幕（首届 2025 年），2000+ 台机器人、16 国选手参赛，设短跑、足球、格斗等项目。BBC 报道百米赛跑中机器人成绩超越博尔特人类纪录（机器人赛道成绩口径）；Global Times 报道开幕式机器人射箭手点燃主火炬。China Daily/CGTN/Bloomberg 均以显著版面报道，称"机器人奥运会"。

  • 验证: ✅ 10+ 独立媒体（BBC/Bloomberg/China Daily/Global Times/CGTN/LATimes 等）一致确认；"破博尔特纪录"为机器人组别成绩口径，非与人类同场竞技 — 关注: 具身智能年度最大展示场，量产进度集中检阅
  • 来源: BBC / Bloomberg / Global Times / China Daily（8/22）

3. 宇树 CEO：机器人"ChatGPT moment"仍需数年 | 🟡 | [🔮预测]

宇树 CEO 王兴兴 8/20-21 接受多家媒体采访，称机器人大脑正接近"ChatGPT moment"，但各家引述时间表分歧明显：Reuters/Next Web 称"接近"；TrendForce 引述"2-3 年最早"；Business Insider 称"最多 5 年"；CNBC 引述"可能 10 年"。共识指向：VLA/具身大模型尚未到临界点，数据与模型能力仍是瓶颈。

  • 验证: ✅ 发言真实（Reuters/CNBC/BI/Fortune 多家独立报道）；🔴 各源引述时间表差异大，无法确定原始完整语境 — 关注: 行业龙头对具身智能落地节奏的官方预期
  • 来源: Reuters / CNBC / Business Insider / TrendForce（8/20-21）

4. DeepSeek 发布 MIT 许可 agent harness：Everything is a Plugin | 🟢 | [✅事实]

DeepSeek 8/17 发布 DeepSeek Harness developer preview——MIT 许可的开源 agent 框架，核心设计"一切皆插件"。GitHub 官方仓库 deepseek-ai/deepseek-harness 已确认存在（8/21 仍有更新，18.5 万 stars），描述为 "DeepSeek Harness: Everything is a Plugin"。MarkTechPost 等多家报道其架构为模块化插件体系，目标降低 agent 工具链构建门槛。

  • 验证: ✅ GitHub API 直接核验仓库存在/许可/活跃度；MarkTechPost/KDnuggets 等媒体报道一致 — 关注: DeepSeek 补齐 agent 工具链，开源生态竞争加剧
  • 来源: GitHub（deepseek-ai/deepseek-harness）/ MarkTechPost（8/17）

5. MCP 官方发布新路线图 | 🟢 | [✅事实]

Model Context Protocol 官方博客发布 "The New MCP Roadmap"，更新规范路线图与未来版本重点方向（HN 首页 170+ 分热帖）。Roadmap 聚焦 upcoming specification releases 的优先领域，MCP 生态已从 Anthropic 内部标准扩展为行业协作治理。具体版本条目未逐条核验。

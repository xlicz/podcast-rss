# 你真的信 WorkBuddy 有 2000 万月活？

## 一个被媒体反复引用的数字，可能连 PV 都算不上

2026 年 7 月，易观发布《中国桌面端 AI 原生办公智能体平台访问量》Q2 报告，一个数字很快传遍全网：腾讯 WorkBuddy 的月访问量是 2097 万。媒体把它翻译成"2000 万月活"，成了国产 AI Agent 出圈的标志性证据。

屠龙之术的明浩在 8 月 1 日的演讲里专门拆了这个数字。他的结论很直接：这份报告自己就在图例的统计说明第一条写清楚了——"访问量"指的是用户与 Agent 的交互次数，是对话和点击的次数之和。这不是 MAU，不是 UV，甚至不是 PV。

> 真实的 UV 或者说 MAU 数字，应该是图表里这个数字的十分之一，甚至几十分之一。

## 为什么现在大家都在盯 Agent 的数字

这个质疑出现在一个特殊的时点。2026 年 8 月，行业对模型进展的追踪已经细化到"按月，甚至按半天"——白天中国这边收工，晚上美国那边发布，每半天就是一个新的时间节拍。GPT-5.6、Kimi K3，以及马斯克 Grok 与 Meta 的更新，挤在同一个月的新闻流里。连"Gemini 4 什么时候来"都成了悬而未决的期待。

但比模型迭代更重要的信号是产品形态的切换：GPT 把 Codex 并入了 ChatGPT，原入口旁边多出一个叫 Work 的选项；原来的 ChatGPT 变成了 "Classical"。改名后一周内，Codex 的周活跃用户从 600 万涨到 1000 万——这是明浩口中"第一次提到千万级"的数字，也是整场讨论的参照系。

范式从 Chatbot 换成了 Agent：能用工具、能调不同模型、能多 Agent 并行。如果这一轮 AI 需要一个"时刻"，明浩认为应该以 2025 年 Claude Code 发布为界——"从 Claude Code 到 Code Work"，Agent 时代正式开场。

## 中国大厂全部下场，产品名字已经装不下了

共识形成得极快。明浩在现场数了一圈：

- 阿里：Coder、MoonRun、悟空三款合并为"千问办公"，已经上线；新钉钉负责人陈宇森接手，三款智能体整合进钉钉
- 腾讯：WorkBuddy、QCloud、Marvis 等全线布局，马化腾几乎从不缺席 WorkBuddy 产品会，内部按"超级项目"规格推进——圈内戏称"腾讯新太子"
- 字节：豆包与飞书持续加码
- 360：放出纳米 Work，"很久没见过这样的阵仗了"
- 智谱有 AutoGLM，Kimi 有 Kimi Code、Kimi Work，知乎有 Z Code

Agent 的中场组件也成了独立生态——Harness 中间件、工具调用、MCP、系统提示词，甚至开始反向影响模型训练过程。蚂蚁开源的上半年 Agent Infra 项目盘点里，无论是 Coding Agent 还是 OpenClaw 这类 Personal AI Assistant，都拿到了大量关注。

## 2097 万访问量，到底代表什么

明浩用三个数据源交叉验证 WorkBuddy 的真实规模。

第一，易观报告本身。它统计的所有桌面端 AI 产品 6 月访问量加在一起是 6000 多万——但同样的逻辑，这些全部是交互次数，要除以人均交互次数才能得到用户数。

第二，Quest Mobile 的 2026 上半年 AI 行业报告，把中国 AI 应用分成五类：AI 原生 App 4.99 亿（千问、元宝这类），AI 应用插件 6.44 亿（跑在微信、支付宝等大流量 App 里的 AI 功能），以及终端厂商的 AI 应用。这里有个关键细节：豆包、千问、元宝都有 PC 端，终端厂商那 1800 万桌面数字里，一大部分其实是这些产品的 PC 端贡献，而非独立 AI Agent 产品。

第三，SimilarWeb 数据：6 月 WorkBuddy 加 Copilot 的 Web 访问量是 731 万。

至于网上流传的"WorkBuddy 1200-1300 万 DAU"——明浩说那是某个投行初级分析师记录的笔误，被自媒体标题党放大，真实数字与他自己推算的百万级吻合。

## 漏斗推演：中国桌面 Agent 用户的天花板

明浩给出了一个可复核的估算框架：

- CNNIC 统计的中国生成式 AI 用户是亿级，但绝大多数停留在 Chatbot（豆包、千问、元宝的活跃加总，大几亿）
- 真正每天用电脑的"泛白领"人群，刨掉制造业和线下服务业，是 1-2 亿规模——这是桌面 Agent 的天花板
- Agent 产品从春节爆火到现在不满两个季度，仍有使用门槛，覆盖率按乐观算也只有 10%-20%

乘出来：当前中国真正在用各类桌面 Agent 产品的用户规模，是小几千万（1000 万到 4000 万之间）。

关键的交叉验证来自晚点 LatePost 对腾讯 AI 一号位姚顺宇的报道——他入职腾讯 300 天，原文明确说 WorkBuddy"如今有上百万日活跃用户"。这篇文章大概率经过腾讯公关审核，数字可信度反而更高。

> 全网都在误传 1200-1300 万 DAU，其实也就是一百多万。所有口径对得上：一百多万才是对的数字。

## 指标失灵之后，只剩钱

明浩顺带清算了两个正在失效的行业指标。去年大家每两周就要看 Google 追上 GPT 多少个百分点，进入 2026 年没人关心了；token 量也不是好指标——"没有人再研究今天你耗费了十亿还是二十亿 token"。token maximizing 时代的竞争叙事已经结束。

剩下的标准很赤裸：ARR。所有人都在看 Claude 的 ARR 到多少，如果不是 Codex 并入 ChatGPT，没人会关心它的活跃用户。AI 应用层肉眼可见的商业模式，似乎只剩收费一条路。

但回看中国，情况并不理想——豆包是纯 AI 应用里少数有资格尝试收费的产品，目前的结果也谈不上乐观。明浩跟潘乱等人在直播里聊豆包与飞书时得出的结论基本一致：中国的 AI 应用收费路径，还远没跑通。

## 记住百万 DAU 就够了

回到开头那个 2097 万：它不是月活，是交互次数；WorkBuddy 的真实日活是百万级，与腾讯官方口径一致。行业里每个"千万级"的 Agent 数字，都值得先问一句：这是用户数，还是次数？

但对普通从业者，明浩的建议很朴素：别管那么多，先把各种工具用起来。数字会继续失真，产品会继续迭代，而这一轮真正稀缺的，是用 Agent 完成实际工作的人。

- "1200-1300 万 DAU"源于投行初级分析师笔误，被自媒体标题党放大
